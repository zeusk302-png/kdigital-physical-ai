# Python 심화 쉬운 용어

| 용어 | 뜻 |
| --- | --- |
| 함수 | 이름 붙여 여러 번 부를 수 있게 묶은 작업 |
| 매개변수 | 함수 정의에서 받을 값에 붙인 이름 |
| 인자 | 함수를 부를 때 실제로 전달하는 값 |
| 반환값 | 함수가 호출한 곳으로 돌려주는 결과 |
| 경로 | 파일의 저장 위치를 나타내는 주소 |
| 예외 | 실행을 계속할 수 없는 상황을 알리는 신호 |
| try/except | 작업을 시도하고 특정 오류가 날 때 할 일을 정하는 구조 |
| 검증 사례 | 입력과 기대 결과를 미리 정해 비교하는 한 경우 |

용어 이름만 외우기보다 활동의 값·파일·출력에서 무엇을 가리키는지 짚습니다. 같은 숫자 모양이라도 의미와 저장 자료형을 구별합니다.
