원본은 그대로 두고 work 폴더의 지정한 파일을 수정하세요. 계정이나 실제 장비 없이 합성 자료로 진행합니다.

## 오늘의 연결

어제 읽은 조건과 반복을 함수 안에 묶고 파일을 처리하는 데 사용합니다.

## 먼저 구별할 화면

- 파일 탐색기는 저장한 파일의 위치를 찾습니다.
- 텍스트 편집기는 코드와 데이터를 읽고 고칩니다.
- 터미널은 명령을 입력하고 실제 실행 결과를 확인합니다.
- 웹 교안은 설명·원문·출력 예를 제공합니다. Python 실행기는 아닙니다.

## 참여 순서

1. 압축을 일반 폴더에 풀고 data·code·work의 위치를 유지합니다.
2. lesson의 개념을 읽고 activity-guide의 해당 활동 입력을 엽니다.
3. work의 답칸에 예상과 이유를 먼저 쓰고 지정한 값을 수정합니다.
4. 저장 후 정확한 work 파일을 실행하거나 강사 출력·제공 예와 수동 비교합니다.
5. 확인 방식을 기록합니다. 개인 실행을 하지 않았으면 실행 성공으로 적지 않습니다.

## 수업 전, 이 세 가지부터 확인하세요

앞선 수업을 기억하지 못해도 아래 질문과 풀이부터 다시 읽으면 됩니다. 먼저 자기 말로 답한 뒤 풀이와 비교하세요.

### 함수의 입력과 결과

질문: 함수 안에서 print만 했다면 호출한 곳이 그 숫자를 계산에 쓸 수 있나요?

풀이: 화면 표시와 return으로 돌려주는 결과를 구분합니다. 호출 결과를 다른 계산에 쓰려면 필요한 값을 돌려줘야 합니다.

### 파일 읽기

질문: CSV 칸에 28.0이 적혀 있으면 자동으로 float인가요?

풀이: 일반적인 CSV 읽기는 문자열 값을 줍니다. 공백·누락·변환 실패를 확인한 뒤 숫자로 바꿉니다.

### 미측정

질문: 빈 온도를 0으로 바꾸면 평균은 어떻게 되나요?

풀이: 측정하지 않은 기록이 실제 0도처럼 계산되어 평균을 낮춥니다. 측정 여부와 정상 숫자를 따로 기록합니다.
