# A02 · def로 정의하고 이름으로 호출하기

show_notice를 정의한 뒤 준비를 출력합니다. 함수 호출 때 안내가 나오고 호출에서 돌아온 뒤 끝이 나옵니다. 함수 본문의 줄 번호가 위에 있다고 가장 먼저 출력되는 것은 아닙니다.

## 전체 시연 코드


```python
def show_notice():
    print("점검을 시작합니다")
print("준비")
show_notice()
print("끝")
```
