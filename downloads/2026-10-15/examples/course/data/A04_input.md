# A04 · print와 return의 차이

add_offset은 받은 두 수를 더해 반환합니다. result가 23.5를 받고 다음 계산에서 사용합니다. 더하는 값은 수업 계산 예이며 실제 장비 교정값으로 사용하지 않습니다.

## 전체 시연 코드


```python
def add_offset(value, offset):
    return value + offset
result = add_offset(22.5, 1.0)
print(result)
print(result + 1)
```
