- advanced/sample_helpers.py·price_helpers.py: 함께 사용하므로 같은 폴더에 두세요.

## 저장과 실행

ZIP을 모두 추출하고 course 폴더에서 터미널을 엽니다. 편집기에서 .py 파일을 작성·수정하고 Ctrl+S로 저장한 뒤 다음 명령을 실행합니다.

```text
python --version
python -X utf8 advanced/D01_01_normal.py
```

코드와 터미널 명령은 다른 위치에 적습니다. python 대신 py 명령만 사용할 수 있다면 py로 바꿉니다. 파일 확장자가 .py.txt가 아닌지 확인하세요. 웹 코드 상자는 실행기가 아닙니다. 두 번째 완성 예제는 D01_02_normal.py처럼 실행합니다. 의도한 오류는 _broken.py, 직접 작성은 _starter.py입니다.

추가 패키지 설치·계정·실물 장비는 필요하지 않습니다. work의 같은 결과 파일은 다시 실행하면 덮어씁니다. 원본 data를 수정할 때는 사본부터 만드세요.
