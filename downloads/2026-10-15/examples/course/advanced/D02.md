# D02 · 함수 입력·기본값·변수의 범위

## 무엇을 하는 개념인가요?

같은 계산법이라도 할인율이나 기준값은 달라질 수 있습니다. 함수가 바뀌는 값을 입력으로 받게 하면 계산법을 다시 작성하지 않아도 됩니다. 값을 생략했을 때 사용할 기본값과 함수 안에서만 사용하는 이름도 구분합니다.

**앞에서 확인할 것:** D01 함수 입력과 반환를 먼저 확인하세요.

## 구성요소와 기호

| 요소 | 뜻과 사용 위치 |
|---|---|
| 여러 매개변수 | 쉼표로 받는 자리를 구분합니다. 자리 순서로 전달하면 함수 정의 순서와 맞아야 합니다. |
| 기본값 | rate=0.1은 생략했을 때 0.1을 사용한다는 뜻입니다. 기본값 없는 매개변수를 먼저 씁니다. |
| 키워드 인수 | rate=0.2처럼 이름을 지정해 전달하면 어떤 값인지 읽기 쉽습니다. |
| 지역 변수 | 함수 몸통에서 만든 계산용 이름은 그 호출 안에서 사용합니다. 다른 호출의 값을 기억하는 저장소가 아닙니다. |
| docstring | 함수 첫 줄의 삼중 따옴표 설명은 입력과 반환값의 약속을 적는 문서입니다. |

괄호 `()`는 호출할 값을 묶고, 콜론 `:` 다음 들여쓴 줄들은 함수·조건·반복의 몸통입니다. 대괄호 `[]`는 목록 또는 위치·키로 값 찾기, 중괄호 `{}`는 딕셔너리 또는 f-string 안 값을 넣을 자리에 사용합니다. 같은 기호도 사용 위치에 따라 의미가 다릅니다.

## 실행 과정

discounted_price(10000)은 price=10000, rate=0.1로 실행되어 9000을 반환합니다. rate=0.2를 지정하면 기본값 대신 0.2를 사용해 8000을 반환합니다.

## 예제 1 · 기본값과 이름을 지정해 함수 호출

**준비:** 키보드 입력 없이 실행합니다. 아래 명령은 터미널에, Python 코드는 편집기에 적습니다. 코드 전체를 UTF-8로 저장하세요.

```text
python -X utf8 advanced/D02_01_normal.py
```

[코드 파일 받기](D02_01_normal.py)

```python
# D02 · 함수 입력·기본값·변수의 범위
# ====================================================================
# 이 파일은 사람이 읽는 설명과 컴퓨터가 실행할 코드를 함께 담습니다.
# # 뒤는 주석입니다. 코드에 초록색이 표시되는지는 편집기 설정에 따라 다릅니다.
# 저장: course/advanced/D02_01_normal.py
# 실행: course 폴더의 터미널에서 python -X utf8 advanced/D02_01_normal.py
# 편집기에 명령을 적지 않습니다. 코드 수정 후 Ctrl+S로 저장합니다.
# 파일 전체는 실행 가능하며, data와 함수 파일은 advanced 폴더에 함께 둡니다.
# 입력 파일 data는 읽고, 생성 결과는 work에 저장합니다.
#
# 무엇을 배우나요?
# 같은 계산법이라도 할인율이나 기준값은 달라질 수 있습니다. 함수가 바뀌는 값을 입력으로 받게 하면 계산법을 다시 작성하지
# 않아도 됩니다. 값을 생략했을 때 사용할 기본값과 함수 안에서만 사용하는 이름도 구분합니다.
#
# 구성요소와 기호
# 여러 매개변수: 쉼표로 받는 자리를 구분합니다. 자리 순서로 전달하면 함수 정의 순서와 맞아야 합니다.
# 기본값: rate=0.1은 생략했을 때 0.1을 사용한다는 뜻입니다. 기본값 없는 매개변수를 먼저 씁니다.
# 키워드 인수: rate=0.2처럼 이름을 지정해 전달하면 어떤 값인지 읽기 쉽습니다.
# 지역 변수: 함수 몸통에서 만든 계산용 이름은 그 호출 안에서 사용합니다. 다른 호출의 값을 기억하는 저장소가 아닙니다.
# docstring: 함수 첫 줄의 삼중 따옴표 설명은 입력과 반환값의 약속을 적는 문서입니다.
#
# 이 단원의 첫 예제 실행을 따라가기
# discounted_price(10000)은 price=10000, rate=0.1로 실행되어 9000을 반환합니다.
# rate=0.2를 지정하면 기본값 대신 0.2를 사용해 8000을 반환합니다.
#
# 한 부분 바꾸고 확인하기
# 두 번째 예제의 기본 할인율을 0.1에서 0.15로 바꾸세요. 기본값으로 호출한 결과만 바뀌고 rate=0.2 결과는
# 그대로인지 비교하세요.

# D02 · 기본값과 이름을 지정해 함수 호출
# 파일 전체를 복사해 UTF-8로 저장합니다. # 뒤의 글은 실행하지 않는 주석입니다.
# 배울 내용: 인수, 기본값, 키워드 인수, 지역 변수
# 실행: course 폴더에서 python -X utf8 advanced/D02_01_normal.py
# print(...)의 괄호는 출력할 값을 묶고, 문자열 양끝 따옴표는 글자의 범위를 나타냅니다.
# 먼저 입력값을 보고 결과를 예상한 다음, 실제 출력과 비교하세요.

def calculate_total(price, quantity, delivery=0):
    # price와 quantity는 호출할 때마다 새로 받는 함수 안의 이름입니다.
    # delivery를 생략하면 기본값 0을 사용합니다.
    subtotal = price * quantity
    total = subtotal + delivery
    return total

# 같은 계산 규칙을 서로 다른 입력에 적용합니다.
pickup = calculate_total(2000, 3)
shipped = calculate_total(2000, 3, delivery=1000)
# 이름을 지정하면 인수 순서를 바꿔도 뜻이 드러납니다.
named = calculate_total(quantity=2, price=1500, delivery=500)
print(f"방문 수령: {pickup}")
print(f"배송: {shipped}")
print(f"다른 주문: {named}")
# subtotal은 함수 안의 지역 변수이므로 바깥에서 바로 읽을 수 없습니다.
# 반환값을 pickup처럼 받아 다음 업무에서 사용하세요.
# 직접 작성: 할인 금액 discount=0을 인수로 더하고 계산하세요.
```

**예상 출력:**

```text
방문 수령: 6000
배송: 7000
다른 주문: 3500
```

## 예제 2 · 기본 할인율과 지정 할인율 비교

**준비:** 키보드 입력 없이 실행합니다. 아래 명령은 터미널에, Python 코드는 편집기에 적습니다. 코드 전체를 UTF-8로 저장하세요.

```text
python -X utf8 advanced/D02_02_normal.py
```

[코드 파일 받기](D02_02_normal.py)

```python
# D02 · 함수 입력·기본값·변수의 범위
# ====================================================================
# 이 파일은 사람이 읽는 설명과 컴퓨터가 실행할 코드를 함께 담습니다.
# # 뒤는 주석입니다. 코드에 초록색이 표시되는지는 편집기 설정에 따라 다릅니다.
# 저장: course/advanced/D02_02_normal.py
# 실행: course 폴더의 터미널에서 python -X utf8 advanced/D02_02_normal.py
# 편집기에 명령을 적지 않습니다. 코드 수정 후 Ctrl+S로 저장합니다.
# 파일 전체는 실행 가능하며, data와 함수 파일은 advanced 폴더에 함께 둡니다.
# 입력 파일 data는 읽고, 생성 결과는 work에 저장합니다.
#
# 무엇을 배우나요?
# 같은 계산법이라도 할인율이나 기준값은 달라질 수 있습니다. 함수가 바뀌는 값을 입력으로 받게 하면 계산법을 다시 작성하지
# 않아도 됩니다. 값을 생략했을 때 사용할 기본값과 함수 안에서만 사용하는 이름도 구분합니다.
#
# 구성요소와 기호
# 여러 매개변수: 쉼표로 받는 자리를 구분합니다. 자리 순서로 전달하면 함수 정의 순서와 맞아야 합니다.
# 기본값: rate=0.1은 생략했을 때 0.1을 사용한다는 뜻입니다. 기본값 없는 매개변수를 먼저 씁니다.
# 키워드 인수: rate=0.2처럼 이름을 지정해 전달하면 어떤 값인지 읽기 쉽습니다.
# 지역 변수: 함수 몸통에서 만든 계산용 이름은 그 호출 안에서 사용합니다. 다른 호출의 값을 기억하는 저장소가 아닙니다.
# docstring: 함수 첫 줄의 삼중 따옴표 설명은 입력과 반환값의 약속을 적는 문서입니다.
#
# 이 단원의 첫 예제 실행을 따라가기
# discounted_price(10000)은 price=10000, rate=0.1로 실행되어 9000을 반환합니다.
# rate=0.2를 지정하면 기본값 대신 0.2를 사용해 8000을 반환합니다.
#
# 한 부분 바꾸고 확인하기
# 두 번째 예제의 기본 할인율을 0.1에서 0.15로 바꾸세요. 기본값으로 호출한 결과만 바뀌고 rate=0.2 결과는
# 그대로인지 비교하세요.

def discounted_price(price, rate=0.1):
    """원 단위 정수 가격과 0~1 할인율을 받아 최종 가격을 반환합니다."""
    # 10%는 숫자 10이 아니라 0.1로 전달한다는 약속입니다.
    discount = price * rate
    # 지역 변수 discount는 이 함수 호출의 계산에 사용합니다.
    result = int(price - discount)
    # 이 예제는 최종 금액의 소수 부분을 버리는 약속을 사용합니다.
    return result

# 인수가 하나면 rate는 함수 정의의 기본값 0.1을 사용합니다.
print(f"기본 할인: {discounted_price(10000)}")
# 이름을 지정하면 입력의 의미를 읽기 쉽습니다.
print(f"지정 할인: {discounted_price(price=10000, rate=0.2)}")
print(f"할인 없음: {discounted_price(10000, rate=0)}")
```

**예상 출력:**

```text
기본 할인: 9000
지정 할인: 8000
할인 없음: 10000
```

## 값을 바꾸고 비교하기

두 번째 예제의 기본 할인율을 0.1에서 0.15로 바꾸세요. 기본값으로 호출한 결과만 바뀌고 rate=0.2 결과는 그대로인지 비교하세요.

변경 전 예상 → 변경 후 실제 결과 → 차이가 난 이유를 주석에 적으세요.

## 직접 작성하기

discounted_price(price, rate=0.1)를 직접 작성하세요. 할인율은 0~1의 소수입니다. 20000원의 기본 할인은 18000, rate=0은 20000, rate=0.25는 15000이 되어야 합니다.

**확인할 결과:** 20000, 기본값 → 18000 / rate=0 → 20000 / rate=0.25 → 15000
