# D01 · 함수로 일을 나누고 결과 돌려받기

## 무엇을 하는 개념인가요?

같은 계산을 여러 곳에서 반복한다면 계산 방법에 이름을 붙여 두면 편합니다. 함수는 필요한 값을 받아 정해진 일을 한 뒤 결과를 돌려주는 코드 묶음입니다. 커피 주문에서 주문 내용이 입력, 만드는 과정이 처리, 완성된 커피가 반환값인 것과 비슷합니다.

**앞에서 확인할 것:** 기초의 변수·조건·반복·함수와 반환값을 먼저 확인하세요.

## 구성요소와 기호

| 요소 | 뜻과 사용 위치 |
|---|---|
| def와 함수 이름 | def classify_temperature(...)는 함수를 정의합니다. 정의할 때는 몸통을 실행하지 않습니다. |
| 매개변수 | 괄호 안 이름은 들어올 값을 받을 자리입니다. temperature는 함수 안에서 쓰는 이름입니다. |
| 호출과 인수 | classify_temperature(28)은 함수를 실행하며 28을 전달합니다. |
| return | 호출한 곳에 결과를 돌려주고 그 함수 실행을 즉시 끝냅니다. print는 화면에 보여주는 일입니다. |
| None | 값이 없음을 나타내는 별도 값입니다. 문자열 "None"이나 숫자 0과 다릅니다. |

괄호 `()`는 호출할 값을 묶고, 콜론 `:` 다음 들여쓴 줄들은 함수·조건·반복의 몸통입니다. 대괄호 `[]`는 목록 또는 위치·키로 값 찾기, 중괄호 `{}`는 딕셔너리 또는 f-string 안 값을 넣을 자리에 사용합니다. 같은 기호도 사용 위치에 따라 의미가 다릅니다.

## 실행 과정

28을 전달하면 temperature가 28이 됩니다. 미측정 검사를 지나 28 이상 조건에 도달합니다. return "경고"가 실행되면 그 아래 조건은 확인하지 않고 호출한 곳으로 돌아갑니다.

```python
# 같은 계산을 여러 곳에서 반복한다면 계산 방법에 이름을 붙여 두면 편합니다. 함수는 필요한 값을 받아 정해진 일을 한 뒤
# 결과를 돌려주는 코드 묶음입니다. 커피 주문에서 주문 내용이 입력, 만드는 과정이 처리, 완성된 커피가 반환값인 것과

#

# def와 함수 이름: def classify_temperature(...)는 함수를 정의합니다. 정의할 때는 몸통을

# 호출과 인수: classify_temperature(28)은 함수를 실행하며 28을 전달합니다.
# return: 호출한 곳에 결과를 돌려주고 그 함수 실행을 즉시 끝냅니다. print는 화면에 보여주는 일입니다.

# 첫 예제의 경고 기준을 28에서 29로 바꾸세요. 28의 결과가 경고에서 주의로 바뀌고 25의 결과는 그대로인지

# D01 · 반복되는 온도 판단을 함수로 묶기
# 파일 전체를 복사해 UTF-8로 저장합니다. # 뒤의 글은 실행하지 않는 주석입니다.
# 배울 내용: def, 매개변수, return, 조기 반환
# 실행: course 폴더에서 python -X utf8 advanced/D01_01_normal.py
# print(...)의 괄호는 출력할 값을 묶고, 문자열 양끝 따옴표는 글자의 범위를 나타냅니다.
# 먼저 입력값을 보고 결과를 예상한 다음, 실제 출력과 비교하세요.

# 함수는 입력을 받아 결과를 돌려주는 이름 붙은 코드 묶음입니다.
def classify_temperature(temperature):
    # None은 비교 전에 처리합니다. None >= 28은 할 수 없습니다.
    if temperature is None:
        return "미측정"  # 여기서 함수 실행이 끝납니다.
    if temperature >= 28:
        return "경고"
    if temperature >= 25:
        return "주의"
    return "정상"

# 함수를 정의하는 것만으로 결과는 출력되지 않습니다. 아래에서 호출합니다.
for value in [None, 0, 25, 28]:
    result = classify_temperature(value)
    print(f"{value}: {result}")
# print는 화면에 보여 주고 return은 호출한 코드에 값을 줍니다.
# 두 일을 섞지 않아야 다른 함수에서도 결과를 이용할 수 있습니다.
# 경고 임계값을 29로 바꾸면 28의 결과는 주의가 됩니다.
```

**예상 출력:**

```text

25: 주의
```

## 예제 2 · 배송비와 최종 결제 금액 나누기

```python
# ====================================================================
# 이 파일은 사람이 읽는 설명과 컴퓨터가 실행할 코드를 함께 담습니다.

# 비슷합니다.

# 구성요소와 기호
# def와 함수 이름: def classify_temperature(...)는 함수를 정의합니다. 정의할 때는 몸통을
# 실행하지 않습니다.
# 매개변수: 괄호 안 이름은 들어올 값을 받을 자리입니다. temperature는 함수 안에서 쓰는 이름입니다.
# 호출과 인수: classify_temperature(28)은 함수를 실행하며 28을 전달합니다.

# None: 값이 없음을 나타내는 별도 값입니다. 문자열 "None"이나 숫자 0과 다릅니다.

# 확인하세요.

# 결제 금액과 배송비 계산을 따로 나누면 각 계산을 시험하기 쉽습니다.
def delivery_fee(amount):
    # amount는 함수에 전달된 주문 금액을 받는 매개변수입니다.
    if amount >= 30000:
        # 무료 배송이어도 숫자 0을 반환합니다. None을 반환하는 것과 다릅니다.
        return 0
    # 위에서 반환하지 않았을 때만 이 줄에 도착합니다.
    return 3000

def payment(amount):
    # 함수의 반환값을 다른 계산에 사용할 수 있습니다.
    fee = delivery_fee(amount)
    return amount + fee

# 호출할 때 전달하는 실제 값 25000과 30000을 인수라고 합니다.
for amount in [25000, 30000]:
    fee = delivery_fee(amount)
    total = payment(amount)
    print(f"주문 {amount} / 배송 {fee} / 결제 {total}")
```

변경 전 예상 → 변경 후 실제 결과 → 차이가 난 이유를 주석에 적으세요.

## 직접 작성하기
