# D11 · 코드를 파일로 나누고 다시 사용하기

## 무엇을 하는 개념인가요?

한 파일에 모든 기능을 넣으면 찾고 수정하기 어려워집니다. 계산용 함수는 별도 파일에 두고 실행 파일이 가져와 사용하게 만들 수 있습니다. Python에서는 가져와 쓰는 코드 파일을 모듈이라고 부릅니다.

**앞에서 확인할 것:** D02 함수 정의와 호출를 먼저 확인하세요.

## 구성요소와 기호

| 요소 | 뜻과 사용 위치 |
|---|---|
| 모듈 | 함수를 담은 .py 파일입니다. 이 수업에서는 같은 폴더에 둡니다. |
| import | 파일에 있는 기능을 현재 코드에서 사용할 수 있게 합니다. |
| from … import … | 특정 함수를 이름으로 가져옵니다. import 줄에는 .py 확장자를 적지 않습니다. |
| __name__ | 직접 실행할 때는 "__main__", 가져올 때는 모듈 이름이 됩니다. |
| 실행 가드 | if __name__ == "__main__": 아래 시연은 직접 실행할 때만 동작합니다. |
| 이름 충돌 | csv.py·json.py처럼 기본 모듈과 같은 이름을 새 파일에 붙이지 않습니다. |

괄호 `()`는 호출할 값을 묶고, 콜론 `:` 다음 들여쓴 줄들은 함수·조건·반복의 몸통입니다. 대괄호 `[]`는 목록 또는 위치·키로 값 찾기, 중괄호 `{}`는 딕셔너리 또는 f-string 안 값을 넣을 자리에 사용합니다. 같은 기호도 사용 위치에 따라 의미가 다릅니다.

## 실행 과정

실행 파일이 price_helpers에서 함수를 가져옵니다. 모듈의 함수 정의는 준비되지만 실행 가드 안 시연은 실행하지 않습니다. 실행 파일이 호출한 결과만 표시됩니다.

## 함께 저장할 함수 파일 · price_helpers.py

이 파일은 두 번째 예제와 같은 폴더에 둡니다. 이 코드도 별도 파일로 저장해야 복사한 예제를 실행할 수 있습니다. [함수 파일 받기](price_helpers.py)

```python
# 계산용 함수 파일입니다. 실행 파일과 같은 폴더에 둡니다.
def delivery_fee(amount):
    # 반환값을 다른 계산에 쓸 수 있도록 화면 출력과 분리합니다.
    return 0 if amount >= 30000 else 3000

def payment(amount):
    return amount + delivery_fee(amount)

# 이 파일을 직접 실행할 때만 아래 시연을 실행합니다.
# 다른 파일에서 import하면 함수 정의만 준비하고 시연은 건너뜁니다.
if __name__ == "__main__":
    print(f"모듈 시연: {payment(25000)}")
```

## 첫 예제에서 사용하는 함수 파일 · sample_helpers.py

첫 예제와 같은 폴더에 두세요. 값이 미측정인지 검사하고 평균을 계산하는 함수 모음입니다. [함수 파일 받기](sample_helpers.py)

```python
# 함께 사용하는 함수 모음. sample_helpers.py로 같은 폴더에 저장합니다.
# import는 이 파일의 함수 이름을 다른 코드에서 사용할 수 있게 합니다.
# 함수 정의만 있으며 파일을 가져오는 순간 입력이나 파일 저장은 하지 않습니다.
import math

def normalize_active(raw):
    # CSV의 상태 글자를 Python 불리언으로 바꿉니다. bool(raw)를 쓰지 않습니다.
    text = raw.strip().lower()
    if text == "true":
        return True
    if text == "false":
        return False
    raise ValueError("true 또는 false가 필요합니다")

def summarize_values(values):
    total = 0
    count = 0
    missing = 0
    for value in values:
        if value is None:
            missing += 1
            continue
        # True/False, 문자열, 무한대와 NaN은 평균에 넣지 않습니다.
        # math.isfinite는 유한한 숫자인지 검사합니다.
        if type(value) not in (int, float) or not math.isfinite(value):
            raise ValueError("유한한 숫자 또는 None이 필요합니다")
        total += value
        count += 1
    average = None if count == 0 else round(total / count, 2)
    return {"count": count, "missing": missing, "average": average}
```
