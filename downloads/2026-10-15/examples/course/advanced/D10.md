# D10 · 항목별로 묶어서 합계·평균 구하기

## 무엇을 하는 개념인가요?

전체 평균 하나만으로는 어느 구역에 값이 몰려 있는지 알기 어렵습니다. 같은 구역 기록을 묶고 각 묶음의 합계·측정 개수·미측정 개수를 따로 계산합니다. 딕셔너리의 키를 구역 이름으로 사용합니다.

**앞에서 확인할 것:** D09 기록 검사를 먼저 확인하세요.

## 구성요소와 기호

| 요소 | 뜻과 사용 위치 |
|---|---|
| 그룹 딕셔너리 | groups["A"]처럼 구역마다 누적 자료를 저장합니다. |
| 초기화 | 새 구역을 처음 만났을 때 합계·개수·미측정을 0으로 시작합니다. |
| 누적 | 정상 측정 한 건은 개수 1과 그 값을 합계에 더합니다. |
| 미측정 | None은 측정 개수와 합계에서 제외하고 미측정 개수만 늘립니다. |
| 평균과 빈 그룹 | 측정 개수가 0이면 나누지 않고 평균을 None으로 둡니다. |

괄호 `()`는 호출할 값을 묶고, 콜론 `:` 다음 들여쓴 줄들은 함수·조건·반복의 몸통입니다. 대괄호 `[]`는 목록 또는 위치·키로 값 찾기, 중괄호 `{}`는 딕셔너리 또는 f-string 안 값을 넣을 자리에 사용합니다. 같은 기호도 사용 위치에 따라 의미가 다릅니다.

## 실행 과정

A의 10과 12가 들어오면 합계 22, 개수 2가 되어 평균은 11입니다. B가 None만 가지면 측정 개수는 0이므로 평균을 계산하지 않습니다.

```python
# 파일 전체를 복사해 UTF-8로 저장합니다. # 뒤의 글은 실행하지 않는 주석입니다.

# 먼저 입력값을 보고 결과를 예상한 다음, 실제 출력과 비교하세요.

records = [
    {"zone": "A", "temperature": 22},
    {"zone": "A", "temperature": 0},
    {"zone": "B", "temperature": None},
    {"zone": "B", "temperature": 30},
]
groups = {}
for record in records:
    zone = record["zone"]
    if zone not in groups:
        groups[zone] = {"sum": 0, "count": 0, "missing": 0}
    temperature = record["temperature"]
    if temperature is None:
        groups[zone]["missing"] += 1  # += 1은 현재 값에 1을 더해 저장합니다.

    groups[zone]["count"] += 1

        average = None
    else:
        average = group["sum"] / group["count"]
    print(f"{zone}: 측정 {group['count']}, 미측정 {group['missing']}, 평균 {average}")
```

```python
# 확인하세요.

def group_summary(rows):
    groups = {}
    for row in rows:
        area = row["area"]
        if area not in groups:
            # 새 구역마다 별도의 딕셔너리를 만듭니다.
            groups[area] = {"total": 0, "count": 0, "missing": 0}
        value = row["value"]
        if value is None:
            groups[area]["missing"] += 1
        else:
            groups[area]["total"] += value
            groups[area]["count"] += 1
    for group in groups.values():
        if group["count"] == 0:
            group["average"] = None
        else:
            group["average"] = group["total"] / group["count"]
    return groups

rows = [{"area": "A", "value": 10}, {"area": "A", "value": 12},
        {"area": "B", "value": None}]
groups = group_summary(rows)
for area, group in groups.items():
    print(f"{area}: 측정 {group['count']} / 미측정 {group['missing']} / 평균 {group['average']}")
```
