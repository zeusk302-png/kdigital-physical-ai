# D09 · 중복·누락·잘못된 기록 따로 모으기

## 무엇을 하는 개념인가요?

기록을 검사할 때 원본을 덮어쓰거나 문제가 난 행을 조용히 버리면 나중에 이유를 알기 어렵습니다. 사용할 기록과 문제 기록을 나누고, 원본 위치와 사유를 함께 남깁니다.

**앞에서 확인할 것:** D05 값 검사와 기초 반복를 먼저 확인하세요.

## 구성요소와 기호

| 요소 | 뜻과 사용 위치 |
|---|---|
| set | 이미 본 번호를 저장하는 집합입니다. 같은 값은 한 번만 들어갑니다. |
| in과 add | 이미 있는지 확인하고 새 값을 집합에 기록합니다. |
| continue | 현재 행의 처리를 끝내고 다음 행으로 넘어갑니다. |
| 검사 순서 | 번호 누락·중복·값 오류처럼 어느 규칙을 먼저 적용할지 정합니다. |
| 오류 기록 | 번호, 원본 줄, 사유를 함께 보관하면 수정할 위치를 찾기 쉽습니다. |

괄호 `()`는 호출할 값을 묶고, 콜론 `:` 다음 들여쓴 줄들은 함수·조건·반복의 몸통입니다. 대괄호 `[]`는 목록 또는 위치·키로 값 찾기, 중괄호 `{}`는 딕셔너리 또는 f-string 안 값을 넣을 자리에 사용합니다. 같은 기호도 사용 위치에 따라 의미가 다릅니다.

## 실행 과정

첫 S01을 확인한 뒤 seen에 넣습니다. 두 번째 S01은 이미 있으므로 중복 사유를 남기고 다음 기록으로 넘어갑니다. 빈 번호는 집합에 넣기 전에 누락으로 분리합니다.

# D09 · 번호 중복과 잘못된 기록을 따로 모으기
# 파일 전체를 복사해 UTF-8로 저장합니다. # 뒤의 글은 실행하지 않는 주석입니다.
# 배울 내용: 집합 set, 목록, 검수 순서, continue
# 실행: course 폴더에서 python -X utf8 advanced/D09_01_normal.py
# print(...)의 괄호는 출력할 값을 묶고, 문자열 양끝 따옴표는 글자의 범위를 나타냅니다.
# 먼저 입력값을 보고 결과를 예상한 다음, 실제 출력과 비교하세요.

records = [
    {"id": "S01", "temperature": 22.5},
    {"id": "S02", "temperature": 0},
    {"id": "S01", "temperature": 24},
    {"id": "", "temperature": 20},
    {"id": "S03", "temperature": None},
]
seen = set()  # {}는 빈 딕셔너리입니다. 빈 집합은 set()으로 만듭니다.
accepted = []
issues = []
for record in records:
    sensor_id = record["id"]
    if sensor_id == "":
        issues.append("번호 누락")
        continue
    if sensor_id in seen:
        issues.append(f"중복 {sensor_id}")
        continue
    seen.add(sensor_id)  # 처리한 식별자를 기억합니다.
    accepted.append(record)
print(f"받은 기록: {len(records)}")
print(f"사용 기록: {len(accepted)}")
for issue in issues:
    print(f"문제: {issue}")
# 여기서는 '한 센서당 한 기록'이라는 교육용 약속을 사용합니다.
# 실제 시간별 측정 로그는 같은 센서 번호가 반복될 수 있습니다.
# 직접 작성: 문제 목록에 원본 줄 번호도 넣으세요.

# ====================================================================
# 이 파일은 사람이 읽는 설명과 컴퓨터가 실행할 코드를 함께 담습니다.

# 저장: course/advanced/D09_02_normal.py
# 실행: course 폴더의 터미널에서 python -X utf8 advanced/D09_02_normal.py
# 편집기에 명령을 적지 않습니다. 코드 수정 후 Ctrl+S로 저장합니다.
# 파일 전체는 실행 가능하며, data와 함수 파일은 advanced 폴더에 함께 둡니다.

#
# 무엇을 배우나요?
# 기록을 검사할 때 원본을 덮어쓰거나 문제가 난 행을 조용히 버리면 나중에 이유를 알기 어렵습니다. 사용할 기록과 문제
# 기록을 나누고, 원본 위치와 사유를 함께 남깁니다.
#
# 구성요소와 기호
# set: 이미 본 번호를 저장하는 집합입니다. 같은 값은 한 번만 들어갑니다.
# in과 add: 이미 있는지 확인하고 새 값을 집합에 기록합니다.
# continue: 현재 행의 처리를 끝내고 다음 행으로 넘어갑니다.
# 검사 순서: 번호 누락·중복·값 오류처럼 어느 규칙을 먼저 적용할지 정합니다.
# 오류 기록: 번호, 원본 줄, 사유를 함께 보관하면 수정할 위치를 찾기 쉽습니다.
#
# 이 단원의 첫 예제 실행을 따라가기
# 첫 S01을 확인한 뒤 seen에 넣습니다. 두 번째 S01은 이미 있으므로 중복 사유를 남기고 다음 기록으로 넘어갑니다.
# 빈 번호는 집합에 넣기 전에 누락으로 분리합니다.

# 한 부분 바꾸고 확인하기

def validate_products(rows):
    accepted = []
    issues = []
    seen = set()
    for number, row in enumerate(rows, start=1):
        name = row["name"].strip()
        if name == "":
            issues.append(f"{number}: 이름 누락")
            continue
        if name in seen:
            issues.append(f"{number}: 이름 중복")
            continue
        if row["quantity"] < 0:
            issues.append(f"{number}: 음수 수량")
            continue
        # 정상으로 채택한 이름만 기록한다는 약속입니다.
        seen.add(name)
        accepted.append(row)
    return accepted, issues

rows = [{"name": "볼트", "quantity": 3}, {"name": "볼트", "quantity": 4},
        {"name": "", "quantity": 2}, {"name": "너트", "quantity": -1},
        {"name": "너트", "quantity": 5}]
accepted, issues = validate_products(rows)
print(f"정상: {len(accepted)} / 오류: {len(issues)}")
for issue in issues:
    print(issue)
```

3: 이름 누락
4: 음수 수량
```
