# D03 · 여러 기록을 담는 구조와 원본 복사

## 무엇을 하는 개념인가요?

한 사람의 기록은 이름표로 값을 찾는 딕셔너리로, 여러 사람의 기록은 리스트로 묶을 수 있습니다. 리스트 안에 딕셔너리나 리스트가 들어간 구조를 중첩 구조라고 합니다. 사본만 수정하려면 안쪽 자료까지 독립적인지 확인해야 합니다.

**앞에서 확인할 것:** D02와 기초 리스트·딕셔너리를 먼저 확인하세요.

## 구성요소와 기호

| 요소 | 뜻과 사용 위치 |
|---|---|
| 리스트 안 딕셔너리 | records[0]["name"]은 첫 기록을 고른 다음 name 값을 읽습니다. |
| 대입 | working = original은 자료를 복사하지 않고 같은 자료에 이름을 하나 더 붙입니다. |
| 얕은 복사 | original.copy()는 바깥 통을 복사하지만 안에 든 리스트·딕셔너리는 함께 가리킬 수 있습니다. |
| 깊은 복사 | copy.deepcopy는 이 예제처럼 안쪽 자료까지 수정하는 작업본을 만들 때 사용합니다. |
| 원본 확인 | 작업본을 수정한 뒤 원본도 출력해 비교해야 보존 여부를 확인할 수 있습니다. |

괄호 `()`는 호출할 값을 묶고, 콜론 `:` 다음 들여쓴 줄들은 함수·조건·반복의 몸통입니다. 대괄호 `[]`는 목록 또는 위치·키로 값 찾기, 중괄호 `{}`는 딕셔너리 또는 f-string 안 값을 넣을 자리에 사용합니다. 같은 기호도 사용 위치에 따라 의미가 다릅니다.

## 실행 과정

원본의 첫 행에서 readings 목록을 꺼냅니다. 얕은 사본에서도 같은 안쪽 목록을 사용하므로 원본이 함께 바뀝니다. 깊은 사본에서는 안쪽 목록까지 별도로 만들어 원본이 유지됩니다.

## 예제 1 · 중첩 자료를 고칠 때 원본 보존

**준비:** 키보드 입력 없이 실행합니다. 아래 명령은 터미널에, Python 코드는 편집기에 적습니다. 코드 전체를 UTF-8로 저장하세요.

```text
python -X utf8 advanced/D03_01_normal.py
```

[코드 파일 받기](D03_01_normal.py)

```python

# ====================================================================
# 이 파일은 사람이 읽는 설명과 컴퓨터가 실행할 코드를 함께 담습니다.
# # 뒤는 주석입니다. 코드에 초록색이 표시되는지는 편집기 설정에 따라 다릅니다.

# 파일 전체는 실행 가능하며, data와 함수 파일은 advanced 폴더에 함께 둡니다.
# 입력 파일 data는 읽고, 생성 결과는 work에 저장합니다.
#
# 무엇을 배우나요?
# 한 사람의 기록은 이름표로 값을 찾는 딕셔너리로, 여러 사람의 기록은 리스트로 묶을 수 있습니다. 리스트 안에 딕셔너리나
# 리스트가 들어간 구조를 중첩 구조라고 합니다. 사본만 수정하려면 안쪽 자료까지 독립적인지 확인해야 합니다.
#
# 구성요소와 기호
# 리스트 안 딕셔너리: records[0]["name"]은 첫 기록을 고른 다음 name 값을 읽습니다.
# 대입: working = original은 자료를 복사하지 않고 같은 자료에 이름을 하나 더 붙입니다.
# 얕은 복사: original.copy()는 바깥 통을 복사하지만 안에 든 리스트·딕셔너리는 함께 가리킬 수 있습니다.
# 깊은 복사: copy.deepcopy는 이 예제처럼 안쪽 자료까지 수정하는 작업본을 만들 때 사용합니다.
# 원본 확인: 작업본을 수정한 뒤 원본도 출력해 비교해야 보존 여부를 확인할 수 있습니다.
#
# 이 단원의 첫 예제 실행을 따라가기
# 원본의 첫 행에서 readings 목록을 꺼냅니다. 얕은 사본에서도 같은 안쪽 목록을 사용하므로 원본이 함께 바뀝니다.
# 깊은 사본에서는 안쪽 목록까지 별도로 만들어 원본이 유지됩니다.
#
# 한 부분 바꾸고 확인하기
# 두 번째 예제의 deepcopy(original)을 original.copy()로 바꾸고 실행하세요. 원본의 점수 목록까지
# 바뀌는지 비교한 뒤 깊은 복사로 복구하세요.

# D03 · 중첩 자료를 고칠 때 원본 보존
# 파일 전체를 복사해 UTF-8로 저장합니다. # 뒤의 글은 실행하지 않는 주석입니다.
# 배울 내용: 얕은 복사, 깊은 복사, deepcopy
# 실행: course 폴더에서 python -X utf8 advanced/D03_01_normal.py
# print(...)의 괄호는 출력할 값을 묶고, 문자열 양끝 따옴표는 글자의 범위를 나타냅니다.
# 먼저 입력값을 보고 결과를 예상한 다음, 실제 출력과 비교하세요.

# copy는 Python에 기본으로 들어 있는 모듈입니다. 별도 설치하지 않습니다.
from copy import deepcopy
original = [{"id": "S01", "tags": ["입구"]}]
# 원본 안에 딕셔너리와 목록이 들어 있어 내부까지 복사해야 합니다.
working = deepcopy(original)
working[0]["tags"].append("점검")
working[0]["id"] = "S99"
print(f"원본 번호: {original[0]['id']}")
print(f"원본 태그: {original[0]['tags']}")
print(f"작업 번호: {working[0]['id']}")
print(f"작업 태그: {working[0]['tags']}")
# original.copy()는 가장 바깥 목록만 새로 만듭니다.
# 내부 딕셔너리는 공유하므로 원본 번호와 태그가 함께 바뀔 수 있습니다.
# 실제 파일을 지우지 않고 메모리 안의 원본과 작업 사본을 비교합니다.
# 직접 작성: 태그를 두 개 추가하고 원본 태그 길이가 1인지 확인하세요.
```

**예상 출력:**

```text
원본 번호: S01
원본 태그: ['입구']
작업 번호: S99
작업 태그: ['입구', '점검']
```

## 예제 2 · 성적 작업본만 수정하기

**준비:** 키보드 입력 없이 실행합니다. 아래 명령은 터미널에, Python 코드는 편집기에 적습니다. 코드 전체를 UTF-8로 저장하세요.

[코드 파일 받기](D03_02_normal.py)

```python
# ====================================================================
# 이 파일은 사람이 읽는 설명과 컴퓨터가 실행할 코드를 함께 담습니다.
# # 뒤는 주석입니다. 코드에 초록색이 표시되는지는 편집기 설정에 따라 다릅니다.

# 무엇을 배우나요?
# 한 사람의 기록은 이름표로 값을 찾는 딕셔너리로, 여러 사람의 기록은 리스트로 묶을 수 있습니다. 리스트 안에 딕셔너리나

# 구성요소와 기호
# 리스트 안 딕셔너리: records[0]["name"]은 첫 기록을 고른 다음 name 값을 읽습니다.

# 깊은 복사: copy.deepcopy는 이 예제처럼 안쪽 자료까지 수정하는 작업본을 만들 때 사용합니다.
# 원본 확인: 작업본을 수정한 뒤 원본도 출력해 비교해야 보존 여부를 확인할 수 있습니다.

# 이 단원의 첫 예제 실행을 따라가기
# 원본의 첫 행에서 readings 목록을 꺼냅니다. 얕은 사본에서도 같은 안쪽 목록을 사용하므로 원본이 함께 바뀝니다.

# 바뀌는지 비교한 뒤 깊은 복사로 복구하세요.

from copy import deepcopy

# 리스트는 여러 학생을, 딕셔너리는 한 학생의 항목을 나타냅니다.

# 안쪽 scores 목록까지 독립적인 작업본을 만듭니다.
working = deepcopy(original)
# [0]으로 첫 학생, ["scores"]로 그 학생의 점수 목록을 찾습니다.
working[0]["scores"].append(90)
# 원본과 작업본을 모두 확인해야 원본 보존을 확인할 수 있습니다.
print(f"원본: {original[0]['scores']}")
print(f"작업본: {working[0]['scores']}")
# 값을 추가하는 append는 목록을 변경합니다. 새 목록을 반환하지 않습니다.
```

```text

```

## 값을 바꾸고 비교하기

두 번째 예제의 deepcopy(original)을 original.copy()로 바꾸고 실행하세요. 원본의 점수 목록까지 바뀌는지 비교한 뒤 깊은 복사로 복구하세요.

변경 전 예상 → 변경 후 실제 결과 → 차이가 난 이유를 주석에 적으세요.
