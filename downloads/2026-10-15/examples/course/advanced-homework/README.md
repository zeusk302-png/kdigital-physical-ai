
## AH01 · 문자 도형 제작기

**사용할 개념:** 함수·반복·JSON 읽기·텍스트 저장·입력 검사

JSON 설정을 읽어 트리 또는 다이아몬드를 만들고 텍스트 파일로 저장하세요. 크기가 바뀌어도 가운데 정렬이 유지되어야 합니다. 모양을 고정 문자열로 미리 적지 말고 반복문으로 계산하세요.

**입력:** Python 파일 옆 data/shape.json을 읽습니다. shape는 tree 또는 diamond, height는 정확히 정수 3~15, char는 *, #, @ 중 하나입니다. true를 정수 높이 1로 인정하지 않습니다. 필요한 키 누락·잘못된 자료형·범위·JSON 문법·없는 파일은 설정 오류로 처리합니다.

**출력:** 정상이면 work/shape.txt를 UTF-8로 저장하고 도형 저장 완료를 출력합니다. 각 줄 오른쪽 공백과 빈 줄은 없으며 마지막 줄 끝에는 줄바꿈이 있습니다. 오류면 설정 오류만 출력하고 기존 결과 파일을 덮어쓰지 않습니다.

### 필수 구현

- 설정 읽기·검사, 도형 줄 목록 만들기, 파일 저장을 함수로 분리하세요.
- tree는 잎 H줄 뒤 가운데 | 하나를 출력합니다. 잎은 1·3·5·…·2H-1개입니다.
- diamond는 위 H줄이 1·3·…·2H-1개, 아래 H-1줄이 2H-3·…·3·1개입니다. 가장 넓은 줄을 두 번 출력하지 않습니다.
- 입력은 data에서 읽고 결과는 work에 저장하세요. 높이 3·4·15와 두 모양을 시험하세요.

### 실행 예시

data/shape.json:

```text
{
  "shape": "diamond",
  "height": 3,
  "char": "*"
}
```

work/shape.txt:

```text
  *
 ***
*****
 ***
  *
```

## AH02 · 다시 실행해도 유지되는 예약 관리

**사용할 개념:** 함수·리스트·반복·JSON 저장과 복원·자료형 검사

기초의 좌석 예약 프로그램을 파일 저장 방식으로 확장하세요. 프로그램을 종료하고 다시 실행해도 예약이 유지되어야 합니다. 학생이 실제로 파일을 삭제하거나 고치기 전에는 임의로 초기화하지 않습니다.

**입력:** 명령을 한 줄씩 입력합니다. 1: 현황, 2: 예약, 3: 취소, 0: 종료입니다. 2·3 다음 줄은 좌석 번호 1~5입니다. 상태 파일은 Python 파일 옆 work/seats.json입니다. 파일이 없으면 빈 좌석 5개로 시작합니다. 기존 파일이 있다면 길이 5의 bool 리스트인지 검사합니다.

**출력:** 현황은 1:O 2:O 3:O 4:O 5:O 형식이며 예약 좌석은 X입니다. 예약 완료·이미 예약·취소 완료·빈 좌석·메뉴 오류·좌석 오류·종료 문구는 기초 과제와 같습니다. 잘못된 상태 파일이면 저장파일 오류만 출력하고 종료합니다. 잘못된 상태 파일을 덮어쓰지 않습니다.

### 필수 구현

- 불러오기·저장·현황·예약 또는 취소 기능을 함수로 나누세요.
- 성공한 예약·취소 직후 JSON을 저장하세요. 중복 예약과 오류 입력으로 상태를 바꾸지 않습니다.
- JSON 문자열 "false", 숫자 0·1은 bool로 인정하지 않습니다.
- 실행 1에서 3번 좌석 예약 후 종료하고 실행 2에서 예약 상태를 확인한 뒤 취소하세요.

### 실행 예시

실행 1의 키보드 입력:

```text
2
3
0
```

실행 1의 출력:

```text
예약 완료
종료
```

### 실행 예시

실행 2의 키보드 입력:

```text
1
3
3
0
```

실행 2의 출력:

```text
1:O 2:O 3:X 4:O 5:O
취소 완료
종료
```

두 예시는 같은 폴더에서 연속으로 실행합니다. 실행 1 뒤 seats.json은 `[false, false, true, false, false]`, 실행 2의 취소 뒤에는 모두 false입니다.

## AH03 · 센서 기록 검사와 구역별 보고서

**사용할 개념:** CSV·JSON·함수·집합·오류 목록·그룹 집계

CSV를 읽어 정상 기록과 문제 기록을 분리하고 구역별 평균과 경고 목록을 JSON 보고서로 만드세요. 입력 파일을 수정하지 않고 잘못된 행의 줄 번호와 이유를 남깁니다.

**입력:** Python 파일 옆 data/sensors.csv를 읽습니다. 필수 열은 id, area, temperature입니다. id·area는 공백 제거 후 비어 있으면 안 됩니다. 이미 채택한 id가 다시 나오면 중복입니다. 온도 빈칸은 None, 그 외 값은 유한한 숫자로 변환합니다. 열 개수 오류·번호 누락·구역 누락·번호 중복·온도 오류를 각각 분리합니다. 필요한 열 또는 파일이 없으면 입력파일 오류만 출력하고 기존 보고서를 유지합니다.

**출력:** work/sensor_report.json에 input_count, accepted_count, measured_count, missing_count, average, alerts, areas, issues를 저장합니다. average는 유효 측정 평균을 소수 둘째 자리로 반올림한 숫자이며 측정이 없으면 null입니다. alerts는 온도 28 이상인 기록 id 목록입니다. areas는 구역마다 measured_count, missing_count, average를 담습니다. issues는 line과 reason을 가진 객체 목록입니다. 화면에는 입력 N / 정상 A / 오류 E를 출력합니다.

### 필수 구현

- 읽기·행 검사·구역 집계·보고서 저장을 함수로 분리하세요.
- None은 평균과 측정 개수에서 제외하되 채택 기록과 미측정 개수에는 포함하세요.
- 온도 0은 실제 측정값입니다. NaN·Infinity와 bool을 정상 온도로 처리하지 않습니다. CSV 값은 문자열이므로 True 같은 글자는 변환 오류입니다.
- 검사 순서는 열 개수 → id 누락 → area 누락 → 이미 채택한 id 중복 → 온도 변환입니다. 정상 채택 후에만 id를 기록합니다.
- 헤더를 1줄로 보고 첫 데이터 줄은 2입니다. 원본 CSV와 보고서를 다시 읽어 결과를 검산하세요.

### 실행 예시

data/sensors.csv:

```text
id,area,temperature
S01,A,22.5
S02,A,30
S03,B,
S01,A,24
S04,B,bad
,B,18
```

화면 출력:

```text
입력 6 / 정상 3 / 오류 3
```

예시 검산: 입력 6행, 채택 3행, 유효 측정 2개, 미측정 1개, 전체 평균 26.25, 경고 S02. A구역 평균 26.25, B구역 평균 null입니다. 오류는 5번 줄 번호 중복, 6번 줄 온도 오류, 7번 줄 번호 누락입니다.
