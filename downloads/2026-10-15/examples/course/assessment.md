### 문제 1 · 함수가 받을 값과 돌려줄 결과 정하기

복습·도전: 물품 라벨에 상품명과 보관함을 받아 ‘장갑 / B02’처럼 한 문자열을 만드는 작업을 설계하세요. 입력 자리 두 개, 반환할 종류, 순서를 바꿨을 때 생길 문제를 문장으로 쓰세요. 첫 입력은 장갑/B02, 둘째 입력은 마스크/A01입니다. 이 두 호출의 결과를 예상하세요.

**정답·해설:** 입력은 상품명·보관함 문자열, 결과는 두 내용을 순서대로 연결한 문자열입니다. 장갑/B02와 마스크/A01의 결과는 각 입력에 따라 달라집니다. 순서를 바꾸면 B02 / 장갑처럼 업무 양식이 달라집니다. 컴퓨터가 이름의 뜻을 추측해 입력 위치를 고쳐 준다는 답은 오답입니다.

### 문제 2 · 화면 표시와 다음 계산의 반환값 구별하기

복습·도전: 배송 준비 함수는 포장비 500원을 화면에 표시하지만 반환문이 없습니다. 호출 결과를 fee에 연결한 뒤 총액 3000에 더하려 합니다. 화면값·fee 값·다음 계산을 분리해 설명하고 올바른 역할 배치를 문장으로 설계하세요.

**정답·해설:** 화면에는 500이 보이지만 fee는 None이며 다음 덧셈은 TypeError가 날 수 있습니다. 함수가 500을 반환하고 호출자가 총액에 더한 뒤 표시하도록 설계합니다. 화면에 500이 보이므로 fee도 500이라는 답은 표시와 반환을 혼동한 것입니다.

### 문제 3 · 읽은 텍스트에서 값으로, 값에서 저장 파일로

복습·도전: 입력 헤더는 device_id,value이고 한 행은 D09,0입니다. 프로그램은 temperature_c를 찾다가 실패했습니다. 파일 열기·헤더 찾기·숫자 변환 중 어느 단계인지 판단하고 원문을 보존한 수정 계획과 올바른 JSON 수치 표현을 쓰세요.

**정답·해설:** 헤더 찾기 단계의 문제입니다. 입력 열 이름이 value로 정해져 있다면 코드에서 찾는 키도 value로 맞춥니다. 고치기 전에 정해 둔 열 이름과 실제 헤더를 확인합니다. 수치 0은 실제 값이므로 JSON에서는 0이며 null이 아닙니다. 주소 수정이나 0 삭제는 현재 증거에 맞는 해결이 아닙니다.

### 문제 4 · 미측정·잘못된 글자·실제 0의 세 갈래

복습·도전: 수량 칸 원문이 빈 문자열, “0”, “여섯”, “ ”입니다. 이 문제의 규칙은 정확한 빈 문자열만 미확인으로 보고, 숫자만 계산 대상으로 정합니다. 네 갈래의 분류와 담당자에게 남길 이슈 원문을 작성하세요.

**정답·해설:** 빈 문자열은 미확인, “0”은 수치 0, “여섯”과 공백 한 칸은 현재 규칙으로 숫자로 읽을 수 없는 입력입니다. 두 이슈 원문을 그대로 남깁니다. 공백을 자동 삭제해 미확인으로 합치는 답은 명시되지 않은 정리 규칙을 추가한 것입니다.

### 문제 5 · 허용 범위의 바깥과 경계를 검사하기

복습·도전: 수업용 배터리 기록의 허용 충전율은 0~100%입니다. -0.1, 0, 50, 100, 100.1의 기대 결과와 바깥을 찾는 논리 문장을 쓰세요. 100.1을 100으로 자동 변경해도 되는지 근거를 설명하세요.

**정답·해설:** 양 끝 -0.1·100.1은 거부, 0·50·100은 허용입니다. ‘0 미만 또는 100 초과’가 바깥입니다. 자동 변경은 원문을 바꾸므로 현재 검사 규칙에서는 허용하지 않습니다. and로 쓰면 두 바깥 조건을 동시에 만족하는 값이 없어 오류를 놓칩니다.

### 문제 6 · 분류 건수와 평균 분모를 보존하기

복습·도전: 원문은 “5”, “15”, 빈 문자열, “뜨거움”, 빈 문자열, “0”입니다. 전체·수치·미측정·이슈·수락 건수와 평균을 구하고 두 검산식을 쓰세요. 수치가 전혀 없는 경우의 평균 표현도 적으세요.

**정답·해설:** 전체 6, 수치 3, 미측정 2, 이슈 1, 수락 5입니다. 6=5+1, 5=3+2이고 평균은 20÷3을 소수 둘째 자리로 반올림한 6.67입니다. 수치가 없으면 None입니다. 수락 5를 분모로 쓰면 4가 되어 미측정을 포함한 잘못된 평균입니다.
