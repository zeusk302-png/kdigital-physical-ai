# W03 HTML로 의미 있는 내용과 길 만들기

HTML은 ‘이 글은 큰 제목’, ‘여기는 탐색’, ‘이것은 버튼’처럼 내용의 역할을 표시합니다. 글자 크기를 먼저 지정하는 언어가 아닙니다. 시작 태그 <h1>과 닫는 태그 </h1> 사이에 제목을 넣습니다. 꺾쇠는 태그를 구분하고 슬래시는 닫음을 표시합니다. 태그 안의 id="features"는 이 요소의 고유한 이름입니다. 속성은 요소의 설정이며 따옴표 안에 값을 씁니다. 이미지처럼 닫는 태그를 따로 두지 않는 요소도 있습니다.

kit/index.html을 열어 doctype, html, head, body 순서로 찾습니다. doctype은 HTML 문서임을 알립니다. html의 lang="ko"는 문서 언어, meta charset은 한글을 읽는 문자 규칙, viewport는 모바일에서 화면 폭을 계산하는 기준입니다. head에는 제목·문자 규칙 같은 문서 정보가 있고 body에는 방문자가 보는 내용이 있습니다. title은 브라우저 탭 제목이며 화면 속 h1과 역할이 다릅니다. 브라우저 개발자 도구의 Elements에서 에디터의 구조가 화면 요소로 해석된 모습을 비교합니다.

header는 머리말, nav는 이동 메뉴, main은 주요 본문, section은 주제별 묶음, footer는 마무리 정보입니다. h1은 페이지 핵심 제목, h2는 각 영역 제목으로 사용합니다. 큰 글씨가 필요하다는 이유로 제목 계층을 건너뛰지 않습니다. a href="#contact"는 같은 문서에서 id="contact"로 이동합니다. 이동은 링크, 펼치거나 검사하는 동작은 button을 씁니다. 링크처럼 보이는 div를 클릭 가능하게 만드는 것보다 기본 요소를 사용하면 키보드 동작도 자연스럽게 얻습니다.

이미지는 src에 경로, alt에 이미지가 전하는 의미를 적습니다. ./images/walk.svg에서 점은 현재 폴더를 뜻합니다. 예제 원본의 /images는 Vite의 public 폴더를 기준으로 해석됩니다. 정적 대체본은 같은 폴더 안 images를 상대경로로 참조합니다. 이 차이는 도구가 처리하는 경로와 단순 파일 경로의 차이입니다. 이미지가 깨지면 먼저 Network나 이미지 새 탭 열기로 404와 대소문자를 확인합니다. alt를 ‘이미지’로만 적으면 내용을 전달하지 못합니다.

함께 작성할 활동은 ‘내 소개’ section 하나를 추가하고 h2, p, 내부 링크를 연결하는 것입니다. 학생 개별 활동에서는 장점 세 개를 자기 내용으로 다시 쓰고 각 장점의 제목과 근거를 분리합니다. 닫는 태그 하나를 지워 브라우저가 어떻게 보정하는지 관찰한 뒤 되돌리기로 복구합니다. 일부 화면이 보인다고 문서가 올바른 것은 아닙니다. 완료 확인은 제목 순서, 링크 도착 위치, 이미지 의미를 짝에게 설명하는 것입니다. 추가 도전은 이미지 없이도 핵심 설명이 전달되도록 본문을 개선하는 활동입니다.

## 확인과 합류

필수: 본문에서 지시한 한 기능을 직접 작성하고 예상과 실제 결과를 docs/checks.md에 남깁니다. 막힌 학생은 완성 예제에서 해당 부분을 찾아 먼저 실행한 후 자기 문구로 수정합니다. 설치 실패는 개념 미성취로 처리하지 않습니다. 짝은 수정 위치와 이유를 묻고 대신 입력하지 않습니다.

강사 피드백: 화면만 보여 달라고 하지 않고 원본 파일, 바꾼 줄, 예상, 실행 주소를 함께 확인합니다. 추가 도전은 필수 완료 뒤 선택합니다.
