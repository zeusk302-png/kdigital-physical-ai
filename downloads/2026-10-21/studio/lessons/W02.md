# W02 폴더·파일·브라우저와 실행 준비

컴퓨터의 폴더는 관련 서류를 넣는 서랍이고 파일은 그 안의 한 장 문서입니다. 확장자는 파일 이름 끝의 .html, .css, .js처럼 용도를 알려주는 부분입니다. 이름을 바꿀 때 index.html.txt가 되지 않도록 탐색기에서 파일 확장명 보기를 켭니다. 오늘은 kit 폴더 전체를 작업 위치로 사용합니다. 개별 파일만 바탕화면으로 꺼내면 서로를 찾는 길이 끊깁니다. 에디터에서 ‘폴더 열기’로 kit를 열고 README.md부터 읽습니다.

index.html은 기본 HTML 화면, src/styles/layout.css는 배치 규칙, src/vanilla.js는 동작, react.html과 src/App.jsx는 같은 페이지의 React판입니다. public/images/walk.svg는 공개 가능한 삽화입니다. 파일 이름의 대소문자도 구별해 쓰는 습관을 들입니다. Windows에서 맞아 보이던 Images와 images가 공개 서버에서는 다른 경로일 수 있습니다. 저장은 원본 글을 디스크에 쓰는 일이고 실행은 브라우저가 그 글을 읽고 해석하는 일입니다. 에디터를 저장했다고 공개 홈페이지가 자동 갱신되지는 않습니다.

Node.js는 브라우저 밖에서 JavaScript 도구를 실행하는 프로그램이고 npm은 이 프로젝트가 쓰는 도구를 설치·실행하는 명령입니다. PowerShell을 열고 현재 위치가 kit인지 확인합니다. pwd는 위치를 보여 주고 dir은 파일 목록을 보여 줍니다. package.json이 안 보이면 그 자리에서 npm 명령을 계속 입력하지 않습니다. cd 뒤에 실제 폴더 경로를 큰따옴표로 감싸 이동합니다. Node 22.12 이상 또는 24 계열을 제작 조건으로 삼았습니다. 설치 권한·인터넷은 강의실마다 확인해야 합니다.

처음 한 번 npm.cmd ci를 실행합니다. 잠금 파일에 적힌 조합을 node_modules에 설치합니다. 이후 npm.cmd run dev를 실행하고 출력된 주소를 브라우저 주소창에 입력합니다. 검은 창은 서버가 일하는 동안 계속 열어 둡니다. 종료는 그 창에서 Ctrl+C입니다. 명령 앞의 npm.cmd는 Windows에서 npm.ps1 실행 정책 오류를 피하는 경로이며 보안 정책 자체를 변경하는 명령은 아닙니다. ENOENT는 파일이나 경로를 찾지 못했다는 뜻입니다. EADDRINUSE나 포트 이동 안내가 나오면 화면에 실제 출력된 주소를 사용합니다.

필수 확인은 기본 페이지 제목을 바꾸고 저장했을 때 localhost 화면이 바뀌는 것입니다. React판은 /react.html에서 열고 App.jsx의 제목을 바꿉니다. 인터넷·설치가 안 되면 reference-static/index.html을 브라우저로 열어 HTML/CSS/JS 활동을 먼저 진행합니다. 이 경로가 React 실행이나 npm 설치 성공의 증거가 되지는 않습니다. 짝은 현재 위치, 수정 파일, 열린 주소 세 가지를 읽어 줍니다. 추가 도전은 두 화면의 파일 연결을 종이에 화살표로 그리는 것입니다.

## 확인과 합류

필수: 본문에서 지시한 한 기능을 직접 작성하고 예상과 실제 결과를 docs/checks.md에 남깁니다. 막힌 학생은 완성 예제에서 해당 부분을 찾아 먼저 실행한 후 자기 문구로 수정합니다. 설치 실패는 개념 미성취로 처리하지 않습니다. 짝은 수정 위치와 이유를 묻고 대신 입력하지 않습니다.
