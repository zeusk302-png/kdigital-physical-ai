# 작업 규칙
docs/brief.md → docs/design.md → docs/checks.md를 읽고 목적과 범위를 요약한다.
학생이 정한 콘텐츠와 의미 있는 HTML을 보존한다. 관련 파일만 최소 수정한다.
문의는 입력 검사 시연이며 서버 전송·추적·결제·계정 생성 기능을 추가하지 않는다.
키·개인 자료를 넣지 않는다. 새 라이브러리는 필요 이유와 대안을 먼저 설명한다.
수정 뒤 npm test와 npm run build를 실행하고 실제 화면·키보드를 점검한다.
실행한 명령·주소·화면 폭·결과를 구별해 보고한다. 실행하지 않은 검사를 성공으로 쓰지 않는다.
게시와 계정 작업은 학생 본인의 의사와 권한을 확인한다.
