# HTML/CSS/React/MCP · 내가 만드는 랜딩페이지

38명 입문자는 각자 주제와 콘텐츠를 정하고 실행 골격을 고쳐 자기 페이지를 완성합니다. 과목명은 유지합니다. 10:00–10:50 기획·실행, 11:00–11:50 HTML·CSS, 13:00–13:50 반응형, 14:00–14:50 JS, 15:00–15:50 React, 16:00–16:50 검수·요구 변경·배포입니다. 중식11:50–13:00. 총300분 운영 제안이며 초심자 수행시간 실측이 아닙니다.

매 교시는 설명·시연10분, 함께 구현10분, 서로 다른 개별 수행20분, 비교·오류복구·피드백10분으로 운영합니다. 한 값 관찰만 50분 시키지 않습니다. 학생은 HTML 소개 영역 작성, 카드 레이아웃, 메뉴·입력 검사 수정, React 부품 재사용, 긴 콘텐츠 요구 변경 등 서로 다른 산출물을 만듭니다. 19쌍으로 짝 검토하되 38명이 각자 파일을 제출합니다. 강사는 현재 파일·주소·오류 첫 줄을 표시하게 하여 공통 장애를 모읍니다.

1교시에는 방문자·주요 행동과 참고 사이트 분석표를 작성합니다. 2교시에는 자기 콘텐츠와 제목 계층·색·여백을 구현합니다. 3교시에는 세 폭에서 넘침을 재현하고 수정합니다. 4교시에는 메뉴 사건과 19/20자 입력 경계를 직접 작성합니다. 5교시에는 실행 골격의 컴포넌트·props·state를 수정합니다. 6교시에는 에이전트 검토 한 건을 재현하고 새 요구를 반영하며 로컬 빌드와 선택적 게시를 확인합니다.

필수 경로는 원본형 HTML 전체와 React 부품 하나 수정입니다. 페이지 전체 React 재작성, 고급 상태 관리, 실제 문의 접수 서버, 결제는 추가 범위입니다. 설치가 막히면 kit/reference-static에서 HTML/CSS/JS를 계속하고 React·MCP·공개 미수행을 별도 적습니다. PPT는 제작하지 않습니다.
