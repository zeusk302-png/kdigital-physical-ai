## 실행 준비

브라우저와 텍스트 편집기가 기본입니다. Python 명령의 현재 폴더는 압축을 푼 course입니다. Windows에서 python 대신 py만 있으면 강사의 확인 아래 py -3로 대체합니다.

```text
python code/mcp_client.py
```

실행하지 못하면 파일 경로·명령·오류 문구를 기록해 도움을 요청합니다. 코드 상자를 보는 것은 Python 실행이 아닙니다.

React 19.1.1과React DOM 19.1.1을 로컬 번들로 제공합니다. 설치와 전체 앱 작성은 필수가 아닙니다. MCP는 2025-11-25 명시 버전의 소규모 STDIO 예제이며 최신 전체 규격·HTTP·인증·AI 호스트 연결을 구현했다는 뜻이 아닙니다. React와 MCP 자동 연결은 없습니다.


## 수업 전, 이 세 가지부터 확인하세요

앞선 내용이 기억나지 않으면 아래 질문부터 읽어 보세요. 먼저 답을 적고 풀이와 비교하면 됩니다.

### 역할

질문: HTML, CSS, JavaScript는 같은 일을 하나요?

풀이: HTML은 내용과 구조, CSS는 모양, JavaScript는 동작을 담당합니다. 버튼 글자와 버튼 색, 클릭 뒤 값 변화를 나눠 봅니다.

### 상태

질문: 센서 카드 값을 바꾼 뒤 새로고침하면 꼭 남나요?

풀이: 화면의 현재 상태와 저장된 데이터를 구별합니다. 저장 기능이 없다면 초기 입력으로 돌아갈 수 있습니다.

### 연결

질문: React 화면이 있으면 MCP 도구도 자동으로 붙나요?

풀이: 화면과 도구 요청 경로는 별도로 연결하고 확인해야 합니다. 이 수업의 제공 예제는 두 역할을 구별해 읽습니다.
