# HTML/CSS/React/MCP 쉬운 용어

용어를 말한 뒤 예제의 실제 위치를 함께 짚습니다.

| 용어 | 뜻 |
| --- | --- |
| HTML | 제목·문단·버튼처럼 문서의 내용과 의미를 표시하는 형식 |
| 태그 | 요소를 표시하는 꺾쇠 안의 이름 |
| 속성 | 요소에 붙이는 이름과 값의 추가 정보 |
| CSS | 내용의 색·크기·간격·배치를 정하는 규칙 |
| 선택자 | CSS나 JavaScript가 대상을 고르는 표현 |
| 이벤트 | 클릭처럼 프로그램이 반응할 수 있는 사건 |
| 컴포넌트 | 다시 쓸 수 있도록 묶은 화면 부품 |
| props | 부모가 컴포넌트에 전달하는 입력 |
| 상태 | 컴포넌트가 기억하며 바뀔 수 있는 값 |
| 번들 | 여러 소스와 라이브러리를 브라우저가 실행하도록 묶은 출력 |
| MCP | AI 앱과 도구 제공 프로그램의 요청·응답을 연결하는 프로토콜 |
| STDIO | 프로그램의 표준입력과 표준출력을 이용한 통신 |
| JSON-RPC | 메서드·입력·id·결과를 JSON 메시지로 주고받는 형식 |
| MCP 호스트 | 사용자가 요청하는 AI 앱 전체로 연결과 도구 사용 흐름을 관리하는 쪽 |
| MCP 클라이언트 | 호스트 쪽에서 특정 서버와 메시지를 주고받는 연결 부분 |
| MCP 서버 | 도구와 입력 규칙을 제공하고 호출 결과를 돌려주는 프로그램 |
