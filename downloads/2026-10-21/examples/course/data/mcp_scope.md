# MCP 교육 예제의 범위

2025-11-25 명시 버전의 STDIO 연결을 학습하는 작은 서버다. 최신 규격 전체의 구현이나 제품용 서버를 뜻하지 않는다. initialize 응답 뒤 initialized 알림, tools/list, tools/call을 주고받는다. 서버 표준출력에는 한 줄 JSON-RPC만 쓰고 진단 메시지는 표준오류로 분리해야 한다.

이 클라이언트는 저장된 호출을 실행하는 테스트용 프로그램이며 LLM이나 AI 호스트가 아니다. S01은 22.5, S02는 미측정, S99는 도구 오류를 돌려준다. 센서·인터넷·유료계정은 사용하지 않는다. HTTP·인증·동시요청·취소·완전한 규격 준수는 범위 밖이다.
