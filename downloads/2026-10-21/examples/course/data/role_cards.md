# 네 요소의 역할

1. HTML: 제목과 단락과 버튼이라는 문서 내용과 의미.
2. CSS: 같은 내용의 색·간격·배치.
3. JavaScript와 React: 사용자 행동과 상태값에 따른 화면 갱신. React는 JavaScript 화면 라이브러리다.
4. MCP: AI 앱과 도구 제공 프로그램이 이름과 입력·결과를 교환하는 통신 약속. 브라우저 화면 모양을 정하는 기술이 아니다.

실습에서 MCP 결과를 React가 자동으로 받는 연결은 만들지 않는다. 값을 전달하려면 별도 프로그램과 연결 처리가 필요하다.

## MCP 안의 세 역할

- 호스트: 사용자가 요청하는 AI 앱 전체입니다. 어떤 서버와 연결할지 관리하고 도구를 쓸 흐름을 조율합니다.
- 클라이언트: 호스트 쪽에서 서버와 한 연결의 메시지를 주고받는 부분입니다. 오늘은 mcp_client.py가 고정 요청을 보내는 최소 역할만 합니다.
- 서버: 도구 목록과 입력 규칙을 제공하고 요청한 기능의 결과를 돌려주는 프로그램입니다. 오늘은 mcp_server.py가 가상 센서 파일을 읽습니다.

오늘 실습에는 실제 AI 호스트나 모델 판단이 없습니다. 클라이언트와 서버를 실행해 메시지 교환을 관찰합니다.
