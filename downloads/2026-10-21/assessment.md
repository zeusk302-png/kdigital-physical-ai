## 확인 질문

1. localhost와 GitHub Pages 주소는 왜 다른가요?
2. 원본을 수정한 뒤 dist와 공개 화면은 어떤 순서로 바뀌나요?
3. Notion 연결 설정과 실제 도구 호출 성공은 어떻게 구분하나요?
4. 어떤 팀 의견을 선택했고 어느 파일을 바꿨나요?
5. OAuth 로그인 정보와 서버 주소 중 Git에 넣을 수 있는 것은 무엇인가요?

팀 대표의 MCP 호출을 함께 확인한 경우에는 그 사실을 기록합니다. 개인 연결·직접 실행·팀 실행 관찰을 구분하며 계정과 설치 문제는 기능 이해와 별도로 확인합니다. 성공하지 않은 배포나 연결을 완료로 표시하지 않습니다.
