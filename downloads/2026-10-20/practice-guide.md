# 실습 진행 안내

1. starter를 열고 app.py를 실행해 현재 상태를 확인합니다. [준비 안내](#/sessions/2026-10-20/lesson?concept=E03)
2. docs/requirements.md에 반납의 경계값 사례를 적습니다. [요구사항](#/sessions/2026-10-20/lesson?concept=E06)
3. docs/design.md에서 화면·계산·저장을 나눕니다. [설계](#/sessions/2026-10-20/lesson?concept=E07)
4. AGENTS.md와 작업 요청문을 읽게 하고 checkout 한 기능을 구현합니다. [요청문](#/sessions/2026-10-20/lesson?concept=E08)
5. 자동 시험과 화면 확인을 수행하고 실제 결과를 기록합니다. [검토](#/sessions/2026-10-20/lesson?concept=E15)
6. Skill의 검토 절차를 적용하고 MCP 문서 조회 결과를 확인합니다. [Skill](#/sessions/2026-10-20/lesson?concept=E12) · [MCP](#/sessions/2026-10-20/lesson?concept=E14)
7. 검색 기능의 변경 요청과 인수인계 기록을 작성합니다. [다음 작업](#/sessions/2026-10-20/lesson?concept=E16)

## 비교용 완성본

reference는 동작과 구조를 비교하는 자료입니다. 먼저 요구사항과 작업 요청을 직접 작성한 뒤 비교하세요. starter와 reference의 데이터는 별개입니다. reference에서 실행한 결과를 자기 구현의 시험 결과로 사용하지 않습니다.

## 결과 묶기

본인의 코드와 docs, 지침, 실제 시험 기록을 한 폴더에 모읍니다. 계정 비밀번호·인증키·개인 대화는 포함하지 않습니다.
