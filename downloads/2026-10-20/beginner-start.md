# AI 코드 에이전트 · 설계부터 검토까지

실습실 장비 대여 프로그램을 설계하고, 에이전트에게 기능을 맡긴 뒤 직접 실행해 확인합니다.

## 먼저 준비하기

자료 탭에서 최신 실습 ZIP을 내려받고 압축을 풉니다. VS Code에서 starter 폴더를 열고 README부터 읽으세요. 인터넷과 선택한 에이전트의 사용 가능한 계정이 필요합니다. 설치가 막히면 요구사항·설계 문서 작성부터 진행할 수 있습니다.

## 수업 순서

도구 준비 → 요구사항과 설계 → 컨텍스트와 지침 → 기능 구현과 시험 → Skills·MCP → 변경 요청과 인수인계.

10:00–17:00 · 50분씩 여섯 구간 · 중식11:50–13:00. 각 구간은 설명·시연·직접 작업·결과 비교로 진행합니다.

## 오늘 남길 결과

요구사항, 화면·데이터 설계, 프로젝트 지침, 작업 요청문, 구현한 코드, 실제 시험 기록을 남깁니다. 전체 도구 설치가 목표는 아닙니다. 선택한 도구 하나로 같은 프로젝트를 끝까지 다룹니다.
