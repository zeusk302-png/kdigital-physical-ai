# E04 · 확장 설치·로그인·첫 질문

선택한 도구 하나를 설치한 뒤 읽기 요청부터 시작합니다.

## 설치 전 확인

인터넷, 설치 권한, 사용할 서비스 계정이 필요합니다. 로그인 성공과 유료 기능 사용 가능 여부는 별개입니다. 사용 불가 안내가 나오면 계정·조직 정책·이용 한도를 확인하고 임의로 결제를 진행하지 않습니다.

## Codex: VS Code 경로

1. 왼쪽 확장 아이콘 또는 `Ctrl+Shift+X`를 누릅니다.
2. 공식 Codex IDE 안내의 설치 링크로 이동해 OpenAI 게시자를 확인합니다.
3. 설치 후 필요하면 VS Code를 다시 엽니다.
4. Codex 아이콘을 누릅니다. 보이지 않으면 `Ctrl+Shift+P`에서 Codex 명령을 검색합니다.
5. 제공되는 로그인 방식으로 자신의 계정에 로그인합니다.
6. 열린 폴더가 `starter`인지 확인하고 아래 첫 질문을 보냅니다.

## Claude Code: VS Code 경로

확장에서 Claude Code를 검색하고 Anthropic의 공식 확장인지 확인합니다. 설치 후 Claude Code 패널을 열고 안내에 따라 로그인합니다. 패널을 사용하는 것과 터미널에서 `claude` 명령을 사용하는 설치 경로는 구분합니다. 터미널 명령이 없다고 패널 설치까지 실패한 것은 아닙니다.

## GitHub Copilot: VS Code 경로

VS Code의 Copilot 안내에 따라 GitHub 계정으로 로그인하고 채팅을 엽니다. 자동완성과 에이전트 모드는 다른 기능입니다. 채팅에서 현재 제공되는 모드와 모델, 사용할 수 있는 도구를 확인합니다. 조직 정책에 따라 기능이 제한될 수 있습니다.

## 첫 질문 복사하기

### Cursor를 쓰는 경우

공식 다운로드 페이지에서 운영체제에 맞는 편집기를 설치합니다. 실행 후 자신의 계정으로 로그인하고 Open Folder로 starter를 엽니다. 채팅·Agent 패널에서 현재 선택한 모드와 모델을 확인합니다. VS Code에 동명의 확장을 설치하는 경로와 구분하세요. 기존 VS Code 설정을 가져오는 것은 선택 사항입니다.

### Gemini Code Assist를 쓰는 경우

기존 사용 환경을 비교하는 참고 경로입니다. 2026-10-20 확인한 공식 안내에는 개인용 계정의 IDE 확장·CLI Google 로그인 경로 종료가 명시돼 있습니다. 지원되는 조직·구독·인증 방식이 있는지 공식 안내부터 확인하세요. 사용할 수 있는 환경에서만 공식 게시자의 확장을 설치하고 프로젝트 읽기부터 확인합니다. 이번 수업에서 새 개인 계정 가입을 필수로 요구하지 않습니다.

### Gemini CLI를 쓰는 경우

Code Assist 확장과 별도의 터미널 도구입니다. 공식 CLI 설치 안내와 현재 Node.js 요구 버전, 지원 인증 방식을 먼저 확인합니다. 사용할 수 있는 환경에서 설치한 경우 starter 폴더에서 `gemini`를 실행합니다. 기존 문서의 Google 개인 로그인 예시가 현재 계정에도 유효하다고 가정하지 마세요. 공식 안내의 Antigravity 이전 경로도 확인할 수 있습니다. 수업은 이미 준비된 도구 하나로 진행합니다.

[Cursor 다운로드](https://cursor.com/downloads) · [Gemini Code Assist 설치](https://developers.google.com/gemini-code-assist/docs/set-up-gemini) · [Gemini CLI 시작](https://geminicli.com/docs/get-started/)

```text
현재 열린 프로젝트에서 README.md와 app.py, inventory.py를 읽어 줘.
실행 방법과 아직 구현되지 않은 기능을 구분해서 설명해.
지금은 파일을 수정하거나 명령을 실행하지 마.
확인하지 못한 파일이 있다면 이름을 알려 줘.
```

## 확인 순서

답변에 나온 파일을 직접 엽니다. “수정하지 않음”을 답변 문장만으로 판단하지 말고 VS Code의 소스 제어에서도 변경 여부를 확인하세요. Git 저장소가 아니면 수정 전 파일과 비교하거나 직접 파일 내용을 확인합니다.

## 막혔을 때

도구 아이콘이 없으면 확장의 사용 여부와 다시 로드 안내를 확인합니다. 웹 로그인이 반복되면 같은 서비스의 다른 계정으로 로그인했는지 확인합니다. 비밀번호·인증 코드는 채팅창에 붙이지 않습니다.
