# E13 · 확장·플러그인·Hook·MCP 구별하기

설치하는 이름보다 무엇을 확장하는지 살펴봅니다.

## 역할로 비교하기

| 종류 | 쉬운 뜻 | 예 |
|---|---|---|
| VS Code 확장 | 편집기 기능을 추가하는 프로그램 | Python 지원·에이전트 패널 |
| 프로젝트 지침 | 이 프로젝트의 공통 작업 원칙 | AGENTS.md |
| Skill | 필요할 때 쓰는 작업 절차 | 수량 처리 코드 검토 |
| 사용자 정의 에이전트 | 역할과 도구 등을 정한 작업자 설정 | 읽기 중심 검토자 |
| Hook | 정해진 시점에 실행하는 처리 | 수정 후 형식 검사 |
| MCP | 외부 도구를 연결하는 공통 방식 | 공식 문서 검색 |
| 에이전트 플러그인 | 해당 제품의 확장 요소 묶음 | Skills·도구 설정 등의 배포 |

모든 제품의 플러그인이 같은 구성이나 설치 방법을 갖는 것은 아닙니다. VS Code 확장과 에이전트 플러그인도 구분합니다. Skill을 넣으면 외부 DB가 자동 연결되는 것도 아닙니다.

## 우리 프로그램에는 무엇이 필요할까

장비 수량 계산에는 MCP가 꼭 필요하지 않습니다. 로컬 Python과 JSON으로 구현할 수 있습니다. 외부 서비스의 자료가 필요할 때 도구 연결을 검토합니다. 필요한 기능이 이미 기본 도구에 있으면 같은 일을 하는 확장을 추가할 이유가 적습니다.

## 설치 전에 살펴보기

공식 배포 경로, 지원하는 클라이언트, 필요한 계정, 사용할 도구 목록을 확인합니다. 로컬 명령을 실행하는 확장인지 원격 서비스에 연결하는 설정인지 구별합니다. 수업에서는 문서 조회부터 연습합니다.

## 분류 실습

```text
다음 요구에 맞는 수단을 고르고 이유를 설명해.
1. 모든 수정에서 JSON 필드 이름을 유지하기
2. 매번 같은 순서로 코드 검토하기
3. 외부 공식 문서 검색하기
4. VS Code에서 Python 문법 색상과 실행 지원하기
5. 파일 수정 뒤 정해진 형식 검사 실행하기
```

## 풀이

1은 프로젝트 지침, 2는 Skill, 3은 MCP 또는 제공되는 문서 도구, 4는 편집기 확장, 5는 Hook이나 작업 자동화가 후보입니다. 정답 이름만 고르기보다 실제 지원 도구와 필요 권한을 설명하세요.

## 직접 해 보기

자신이 쓰는 도구의 확장 관리 화면에서 설치된 기능 한 개를 확인하고 위 표의 어느 종류인지 적습니다. 목록을 본 것과 기능을 실행한 것을 구분합니다.
