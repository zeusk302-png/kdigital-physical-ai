# E02 · 도구별 기능과 실행 환경

에이전트 하나로 실습을 끝까지 진행하고, 다른 도구는 차이와 대응 방법을 알아봅니다.

## 도구를 고를 때 보는 기준

어느 모델이 무조건 더 좋다고 외우기보다 프로젝트 읽기, 수정 검토, 명령 실행, 사용 가능한 계정을 확인합니다. 요금·모델·이용 한도는 계정과 시점에 따라 달라집니다. 수업을 위해 여러 구독을 동시에 구매할 필요는 없습니다.

| 도구 | 어디서 사용하나 | 확인할 기능 | 지침 예 |
|---|---|---|---|
| Codex | VS Code 확장·CLI | 프로젝트 문맥, 계획·수정·실행·diff 검토 | AGENTS.md |
| Claude Code | VS Code 확장·CLI | 파일 참조, 계획 검토, 코드 변경, 도구 사용 | CLAUDE.md |
| GitHub Copilot | VS Code 등 | 자동완성, 채팅, 에이전트 작업 | .github/copilot-instructions.md |
| Cursor | 별도 편집기 | 프로젝트 문맥, 여러 파일 수정, 규칙 | .cursor/rules/*.mdc |
| Gemini Code Assist | 지원 편집기 확장·이용 조건 확인 필요 | 코드 설명·지원 기능과 현재 제공 모드 | 해당 확장 문서에서 확인 |
| Gemini CLI | 터미널·인증 조건 확인 필요 | 폴더 기반 작업과 외부 도구 | GEMINI.md |

Cursor는 VS Code에 설치하는 동일 이름의 확장과 혼동하지 마세요. Gemini Code Assist와 Gemini CLI도 같은 실행 환경이 아닙니다. 지침 파일과 기능 지원을 서로 그대로 옮겨 적용하지 않습니다.

**Google 계열 이용 조건:** 2026-10-20 확인한 공식 안내에서는 개인용 Code Assist 등의 Google 로그인 경로 종료와 Antigravity 이전을 안내합니다. 예전 무료 개인 계정 설치 글을 그대로 따라가지 말고 현재 구독·인증 지원을 확인하세요. 이 수업의 필수 설치 경로로 두지 않습니다. [공식 변경 안내](https://developers.google.com/gemini-code-assist/docs/deprecations/code-assist-individuals)

## 기능을 하나씩 확인하기

1. **설명:** 파일을 읽고 역할을 말하는가?
2. **계획:** 수정 전에 바꿀 파일과 순서를 제시하는가?
3. **수정:** 여러 파일을 바꿀 때 차이를 볼 수 있는가?
4. **실행:** 터미널 명령과 결과를 확인할 수 있는가?
5. **검토:** 완료 조건에 맞는지 문제를 찾아 주는가?

## 비교 실습

```text
프로젝트를 읽고 장비 대여 기능이 구현된 곳을 찾아 줘.
화면, 계산, 저장이 각각 어느 파일에 있는지 표로 작성해.
모르는 내용은 추정하지 말고 확인할 파일을 알려 줘.
수정은 하지 마.
```

한 도구로 답을 받은 뒤 다른 도구를 사용할 수 있다면 같은 폴더와 같은 요청으로 비교합니다. 문장이 긴 쪽이 아니라 실제 파일과 맞고 다음 행동이 분명한 쪽을 고르세요.

## 확인할 것

사용한 도구, 실행 위치, 로그인 계정의 이용 가능 여부, 파일 읽기·수정·실행 중 확인한 기능을 적습니다. 설치가 막힌 경우 E06의 요구사항 설계는 일반 편집기에서도 진행할 수 있습니다.
