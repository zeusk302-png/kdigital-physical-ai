# E14 · MCP로 외부 문서 도구 연결하기

연결 설정, 도구 실행, 결과 확인을 각각 수행합니다.

## MCP는 무엇인가

에이전트가 외부 도구와 자료를 사용하도록 연결하는 방식입니다. 에이전트가 있는 프로그램은 클라이언트, 도구를 제공하는 쪽은 서버입니다. 서버마다 문서 검색·목록 조회·자료 변경 등 제공 기능이 다릅니다.

이번 예시는 OpenAI 공식 문서 조회 서버입니다. API 호출이나 장비 제어 서버가 아닙니다. 클라이언트가 원격 MCP를 지원하고 인터넷에 연결돼 있어야 합니다.

## Codex CLI 설정 예

아래 명령은 **Codex CLI를 설치한 환경의 터미널**에서 실행합니다. VS Code 확장 설치만으로 터미널의 `codex` 명령이 반드시 생기는 것은 아닙니다. 명령을 찾지 못하면 현재 도구의 MCP 설정 화면 또는 공식 CLI 설치 안내를 사용하세요.

```powershell
codex mcp add openaiDeveloperDocs --url https://developers.openai.com/mcp
codex mcp list
```

첫 줄은 서버 이름과 주소를 등록합니다. 둘째 줄은 등록 목록을 확인합니다. Codex IDE와 CLI는 공유 설정을 사용할 수 있습니다. 다른 제품에서는 이 명령을 그대로 사용하지 말고 해당 클라이언트의 서버 추가 절차를 따릅니다.

## VS Code MCP 설정 예

VS Code의 MCP 지원 경로를 사용하는 경우 프로젝트의 `.vscode/mcp.json`에 설정합니다. **이 설정이 모든 확장에 공통으로 전달되는 것은 아닙니다.** 사용할 채팅·에이전트의 도구 목록에 나타나는지 확인하세요.

```json
{
  "servers": {
    "openaiDeveloperDocs": {
      "type": "http",
      "url": "https://developers.openai.com/mcp"
    }
  }
}
```

## 실제 도구 사용 요청

### Claude Code와 Cursor의 대응 경로

Claude Code CLI가 준비돼 있다면 현재 프로젝트에서 다음 명령으로 같은 서버를 등록하고 확인할 수 있습니다. Claude Code 안의 `/mcp`에서도 연결 상태를 확인합니다.

```powershell
claude mcp add --transport http openaiDeveloperDocs https://developers.openai.com/mcp
claude mcp list
```

Cursor는 MCP 설정에서 서버를 추가하거나 해당 제품의 `mcp.json` 형식에 맞춰 등록합니다. VS Code의 `servers` 형식과 다르게 `mcpServers`를 사용하는 예입니다.

```json
{
  "mcpServers": {
    "openaiDeveloperDocs": {
      "url": "https://developers.openai.com/mcp"
    }
  }
}
```

모든 경로를 동시에 설치할 필요는 없습니다. 실제 사용 중인 클라이언트 한 곳에서 도구가 나타나는지 확인합니다.

```text
연결된 openaiDeveloperDocs의 사용 가능한 도구를 확인해.
공식 문서에서 Codex의 AGENTS.md 적용 범위를 찾아 설명해.
실제로 도구를 사용했는지, 찾은 문서 주소와 관련 내용을 보고해.
도구를 쓸 수 없으면 그 상태를 밝히고 연결 성공이라고 하지 마.
```

## 무엇을 확인하나

| 단계 | 확인 근거 |
|---|---|
| 등록 | 설정 또는 서버 목록에 이름·주소 표시 |
| 연결 | 클라이언트에서 서버가 준비 상태이며 도구 목록이 보임 |
| 실행 | 특정 도구 호출과 반환 결과가 기록됨 |
| 적용 | 출처를 열어 설명을 대조하고 프로젝트 판단에 사용 |

## 막혔을 때

등록은 됐지만 도구가 없으면 현재 클라이언트의 서버 상태와 연결 오류를 봅니다. 인증이 필요한 다른 서버라면 해당 인증 절차가 필요합니다. 서버 주소에 인증키를 임의로 붙이지 않습니다. 외부 쓰기 작업은 문서 조회와 권한·영향이 다릅니다.

## 더 해보기

GitHub 조회나 DB 읽기를 연결한다면 필요한 자료, 읽기 범위, 인증 방식, 결과 확인 방법을 먼저 설계합니다. GitHub Pages 배포나 DB 변경까지 같은 권한으로 묶지 않습니다.
