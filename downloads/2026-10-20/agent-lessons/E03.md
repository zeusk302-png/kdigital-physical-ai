# E03 · VS Code에서 폴더와 실행 준비

파일 하나만 여는 것보다 프로젝트 폴더 전체를 여는 것이 먼저입니다.

## 파일·폴더·확장자부터

`app.py`에서 `app`은 이름이고 `.py`는 Python 코드 파일임을 알리는 확장자입니다. `equipment.json`은 장비 정보를 저장합니다. `docs` 폴더에는 프로그램을 어떻게 만들지 적은 문서가 들어 있습니다.

자료 탭에서 최신 실습 ZIP을 내려받고 압축을 풉니다. Windows 탐색기의 보기에서 파일 확장명을 표시하세요. `app.py.txt`로 저장하면 Python 파일로 실행되지 않습니다.

## 폴더 열기

1. VS Code를 실행합니다.
2. 파일 → 폴더 열기를 누릅니다.
3. 압축을 푼 폴더 안의 `starter`를 선택합니다.
4. 왼쪽 탐색기에 `app.py`, `inventory.py`, `data`, `docs`가 보이는지 확인합니다.
5. 터미널 → 새 터미널을 엽니다. 아래쪽 검은 창은 명령을 입력하는 곳입니다.

```powershell
py --version
py app.py
```

첫 줄은 Python 버전을 확인합니다. 두 번째 줄은 현재 폴더의 `app.py`를 실행합니다. 창에 장비 목록이 나타나면 기본 준비가 끝났습니다. 시작 파일의 대여·반납은 아직 연결 전이라는 안내가 나옵니다. 이 기능을 수업 중 구현합니다.

## 실행 위치 확인

```powershell
Get-Location
Get-ChildItem
```

첫 명령은 현재 위치, 둘째 명령은 그 위치의 파일 목록을 보여 줍니다. 목록에 `app.py`가 없으면 폴더를 잘못 연 것입니다. 터미널에 Python 코드 자체를 붙이지 말고 명령을 입력하세요.

## 흔한 문제와 해결

| 화면에 보이는 문제 | 먼저 할 일 |
|---|---|
| py 명령을 찾을 수 없음 | `python --version` 확인 후 가능하면 `python app.py` 사용 |
| app.py를 찾을 수 없음 | 현재 폴더 확인, VS Code에서 starter 폴더 다시 열기 |
| tkinter 모듈 없음 | Python 설치 구성의 Tcl/Tk 항목 확인 |
| 창이 떠 있는데 터미널 입력이 안 됨 | 창을 닫고 다음 명령 실행 |
| 수정했는데 동작이 같음 | Ctrl+S로 저장한 뒤 실행 창을 닫고 재실행 |

## 직접 해 보기

`app.py`의 창 제목을 찾아 자신의 프로그램 이름으로 바꿉니다. 저장 후 재실행해서 제목만 바뀌고 목록은 유지되는지 확인하세요.
