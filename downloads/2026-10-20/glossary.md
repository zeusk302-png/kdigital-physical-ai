## 채팅과 코드 에이전트는 어떻게 다른가

답변을 받는 것과 프로젝트 파일을 수정하고 실행하는 것은 다른 작업입니다.

## 도구별 기능과 실행 환경

에이전트 하나로 실습을 끝까지 진행하고, 다른 도구는 차이와 대응 방법을 알아봅니다.

## VS Code에서 폴더와 실행 준비

파일 하나만 여는 것보다 프로젝트 폴더 전체를 여는 것이 먼저입니다.

## 확장 설치·로그인·첫 질문

선택한 도구 하나를 설치한 뒤 읽기 요청부터 시작합니다.

## 설명·계획·수정·실행·검토를 나누기

한 번에 전부 맡기기 전에 지금 어떤 작업을 하는지 구분합니다.

## 만들기 전에 요구사항 정하기

필요한 기능을 적고, 어떤 상태면 완성인지 먼저 정합니다.

## 화면·데이터·함수를 함께 설계하기

무엇을 보여 주고, 어떤 값을 저장하고, 어디서 계산할지 연결합니다.

## 잘 수행할 수 있는 작업 요청 만들기

길이보다 필요한 정보와 확인 가능한 완료 조건이 중요합니다.

## 컨텍스트를 고르고 작업을 이어 가기

대화 전체를 믿고 맡기기보다 다음 작업에 필요한 근거를 전달합니다.

## README와 설계·작업 기록의 역할

다른 사람과 에이전트가 같은 기준으로 작업할 수 있게 기록합니다.

## AGENTS.md와 도구별 지침 파일

프로젝트 전체 규칙과 역할별 에이전트 설정을 구별합니다.

## Skill로 반복 작업 절차 만들기

매번 길게 쓰던 검토 절차를 이름 붙여 재사용합니다.

## 확장·플러그인·Hook·MCP 구별하기

설치하는 이름보다 무엇을 확장하는지 살펴봅니다.

## MCP로 외부 문서 도구 연결하기

연결 설정, 도구 실행, 결과 확인을 각각 수행합니다.

## diff·테스트·오류 재현으로 검토하기

완료 보고를 실제 코드와 실행 결과로 확인합니다.

## 변경 요청을 나누고 다음 작업 전달하기
