# AI 코드에이전트 쉬운 용어

용어를 말한 뒤 예제의 실제 위치를 함께 짚습니다.

| 용어 | 뜻 |
| --- | --- |
| 코드에이전트 | 요청을 해석하고 코드 파일·실행 도구를 이용해 작업을 이어 가는 AI 도구 |
| 프롬프트 | 목표·자료·범위·확인 방법을 전달하는 요청 |
| 컨텍스트 | 이번 일을 이해하는 데 필요한 관련 설명과 자료 |
| 입출력 계약 | 받을 값과 돌려줄 결과에 대한 약속 |
| diff | 바뀌기 전후의 파일과 줄을 보여 주는 비교 |
| 경계값 | 판단 규칙이 바뀌는 기준 주변의 값 |
| 회귀 | 수정 뒤 예전에 맞던 동작이 틀리는 현상 |
| 재현 | 같은 입력과 조건으로 같은 현상을 다시 확인하기 |
| 검증 | 미리 정한 기대와 실제 결과를 대조하기 |
| 미측정 | 아직 측정값이 없는 상태로 실제0과 다름 |
