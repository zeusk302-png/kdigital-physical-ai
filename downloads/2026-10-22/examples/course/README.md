# OpenCV + 웹캠 실습 예제

기본 경로는 파일 이미지입니다. 개인 실행은 Python 3 설치 후 터미널에서 `python -m pip install opencv-python==4.12.0.88`을 사용할 수 있는 환경이 필요합니다. 설치 권한이 없으면 강사 시연·제공 출력 비교로 진행합니다. 실제 웹캠 스크립트는 강사가 장치·권한·촬영 범위를 확인한 뒤에만 선택해서 실행합니다.

[활동 전체 안내](activity-guide.md) · [모든 코드와 줄 해설](code/line-guide.md)

data는 원문, work는 학생 기록·수정본, code는 완성 시연 파일입니다. 폴더 구조를 유지합니다. 입력 파일을 덮어쓰지 않고 활동지의 work 파일에 결과를 남깁니다.

설치가 어려우면 입력 이미지와 제공 출력, 코드 줄 해설을 대조하고 work 양식에 예상·관찰·미실행을 기록합니다. 별도 카메라 연결은 필수가 아닙니다.
