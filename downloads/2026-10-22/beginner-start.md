# 2026-10-22 · 처음 시작

기본 경로는 파일 이미지입니다. 개인 실행은 Python 3 설치 후 터미널에서 `python -m pip install opencv-python==4.12.0.88`을 사용할 수 있는 환경이 필요합니다. 설치 권한이 없으면 강사 시연·제공 출력 비교로 진행합니다. 실제 웹캠 스크립트는 강사가 장치·권한·촬영 범위를 확인한 뒤에만 선택해서 실행합니다.

## 파일과 실행

`examples/course/data`는 읽을 입력, `code`는 완성 시연 코드, `work`는 나의 작성·수정 파일입니다. ZIP을 풀고 폴더 구조를 유지합니다. 터미널은 명령을 실행하는 창이며, 에디터는 파일 내용을 쓰고 저장하는 창입니다. 저장만으로 코드가 실행되지는 않습니다.

1. [용어](glossary.md)에서 낯선 말을 확인합니다.
2. [교안](lesson.md)의 개념과 예를 읽습니다.
3. [활동지](practice-guide.md)의 A01부터 입력을 열고 work 양식에 기록합니다.
4. 코드 실행은 code/line-guide.md의 명령과 조건을 따릅니다.

확인할 것: 기본 설정에서 검출 수가 2개이고 임계값을 60으로 바꾸면 3개가 되는 이유를 설명해 보세요. 파일 읽기 실패와 검출 결과가 0개인 경우를 구별하고, release로 카메라 자원을 해제하는 이유도 설명합니다.

실제 웹캠과 화면 창의 동작은 강의실에서 별도로 확인해야 합니다. 제공 파일을 사용하는 실습과 실제 장치의 결과를 구별해 기록하세요.
