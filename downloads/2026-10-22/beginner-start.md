# OpenCV + 웹캠 실습 · 영상 인식 프로그램 스튜디오
과목명은 OpenCV + 웹캠 실습을 유지한다. 사전학습 YOLO11n 검출→동영상/웹캠→ByteTrack ID→구역 진입/선 통과→실패와 성능 비교로 자기 프로그램을 만든다. 학생용 교안은 lessons/V01~V08, 실행 키트는 kit이다. PPT는 이번 제작 범위에 없다.

설치·모델 다운로드는 수업 전 점검하고, 당일 미준비는 설치 지원과 개념 활동을 분리한다. 교실 PC 사양·권한·카메라 수량은 확인 대상이다. 영상 대체로 모든 기능을 학습할 수 있지만 웹캠 성공으로 기록하지 않는다.

강사는 매 교시 '정상 실행 확인'과 '개념 설명 확인'을 별도로 표시한다. 빠른 학생은 추가 도전으로 이동하고 설치 지연 학생은 앞부분 실행 골격으로 합류한다. 개인 목표 선택과 코드 수정·새 입력 검증을 생략하지 않는다. 점심·휴식 시각은 현행 docs/schedule.md를 따르며 이 자료는 교시 학습 배정만 제시한다.
