# 웹캠으로 만드는 나의 영상 인식 프로그램

카메라 화면만 띄우는 데서 끝내지 않습니다. 영상 속 대상과 움직임을 읽어 구역 알림·방향별 집계·발견 장면 저장 중 자기 기능을 만듭니다. 기본 입력은 Logitech C270 USB 웹캠이고, 같은 프로그램에 동영상 파일도 넣을 수 있습니다.

## 오늘의 흐름

|시간|할 일|남길 결과|
|---|---|---|
|10:00–10:50|설치·웹캠 열기·사진 저장|직접 촬영한 입력과 첫 프로그램|
|11:00–11:50|YOLO·클래스·점수·좌표·필터|원하는 대상만 처리하는 코드|
|11:50–13:00|중식|—|
|13:00–13:50|추적·기억·관심 구역 진입|중복하지 않는 사건 처리|
|14:00–14:50|방향 집계·영상·기록 저장|화면과 사건 기록의 일치|
|15:00–15:50|개인 기능 구현·AI 검토|자기 영상 인식 프로그램|
|16:00–16:50|실패·속도 비교·새 입력 검수|개선 결과와 실행 안내|

각 구간 사이 10분 휴식, 16:50–17:00 저장·종료 준비입니다. 제공 골격으로 합류하고 필수 기능부터 완성합니다. 전체 코드를 암기하거나 복잡한 모델 학습을 하루에 끝내는 수업은 아닙니다.

## 필수 경로

[설치](lessons/V01.md) → [첫 카메라](lessons/V02.md) → [사진 저장](lessons/V03.md) → [검출](lessons/V04.md) → [필터](lessons/V05.md) → [추적](lessons/V06.md) → [구역 알림](lessons/V07.md) → [개인 프로그램](lessons/V12.md) 순서입니다. 방향 집계·체류 알림·사건 사진 저장 중 한 기능을 선택해 확장합니다. 모든 12개 단원은 목차에서 볼 수 있습니다.

## 실행 자료

[실행 안내](kit/README.md), [실험 기록](kit/docs/experiment.md), [실습 순서](practice.md)를 사용합니다. 예제는 01_camera → 02_snapshot → 03_detect → src.main 순으로 확장됩니다. 카메라 화면은 Q로 종료하며 결과는 runtime에 저장합니다. 자료 다운로드의 ZIP에는 코드·설정·교안이 들어 있고 가중치와 촬영 영상은 별도로 준비합니다.

## 완료 확인

자기 입력에서 동작하는 기능 하나, 오류 한 가지의 복구, 같은 입력에서 설정 비교, 다른 사람이 따라 실행할 README를 남깁니다. 웹캠 직접 실행과 영상 파일 실행은 기록에서 구분합니다. 이 Python 프로그램은 PC에서 실행하며 GitHub Pages에는 소개 페이지를 게시할 수 있습니다.
