# 웹캠 프로그램 필수 실습

1. **설치와 입력 확인**: V01 명령으로 가상환경·패키지·모델을 준비하고 카메라 앱을 닫습니다. 성공 기준은 버전 출력과 올바른 카메라 화면입니다.
2. **화면과 저장**: examples.01_camera를 실행하고 표시 문구를 바꿉니다. examples.02_snapshot에서 S로 사진을 저장하고 탐색기로 엽니다. 실패한 저장을 성공으로 출력하지 않습니다.
3. **검출과 필터**: examples.03_detect로 클래스·점수·박스를 읽습니다. 원하는 클래스를 고르고 크기 또는 점수 조건 하나를 작성합니다. 빈 검출도 시험합니다.
4. **추적 확인**: src.main의 ID를 보며 이동·가림·재등장을 시험합니다. 프레임별 박스 수와 고유 방문자 수가 다른 이유를 적습니다.
5. **구역 알림**: configs/my-zone.json을 만들고 바깥→안→머무름→나감→재진입을 시험합니다. 첫 관찰과 진입 사건을 구분합니다.
6. **개인 기능**: 방향별 집계·체류 알림·발견 사진 저장 중 하나를 직접 구현합니다. 입력·상태·출력을 먼저 적고 AI에게 한 파일 책임씩 요청합니다.
7. **오류와 속도 비교**: 입력 없음·카메라 번호 오류·가림·잘못된 설정을 확인합니다. 같은 입력에서 한 설정씩 바꾸고 결과를 기록합니다.
8. **재현과 제출**: 새 입력에서 실행하고 팀원이 README대로 실행해 봅니다. docs/experiment.md와 Git 원본을 정리합니다. 촬영 영상·가중치·가상환경은 공개 저장소에서 제외합니다.

필수 완료 뒤 체류 상태 초기화, 경고 표시 유지 시간, 키보드 초기화 기능을 추가할 수 있습니다. 로봇 제어는 이번 검출 프로그램에서 즉시 연결하지 않고 후속 장치 수업에서 별도로 검토합니다.
