# 평가 · OpenCV와 웹캠

이 평가는 이미지를 처리한 결과를 근거로 설명할 수 있는지 확인합니다. 코드를 외우거나 빨리 입력하는 능력은 평가하지 않습니다. 직접 실행하기 어려우면 제공 출력과 강사 시연을 비교하고, 기록에 수행 방법을 표시하세요.

## 준비와 제출 방법

1. 실습에서 작성한 `work/A17_worksheet.md`와 `work/A18_worksheet.md`를 엽니다. 여기서 `work`는 예제 ZIP을 푼 폴더 안의 작업 폴더입니다.
2. A17 기록에 사용한 입력 파일 이름, 임계값, 최소 면적, 실행 전 예상, 실제 검출 수를 적습니다. 임계값은 밝고 어두운 픽셀을 나누는 기준이고, 최소 면적은 너무 작은 영역을 제외하는 기준입니다.
3. 직접 생성한 출력이 있다면 설정 파일과 회색조·이진화·검출 결과 이미지를 함께 제출합니다. 제공 출력만 비교했다면 새로 실행했다고 쓰지 말고, 비교한 파일 이름과 관찰을 적습니다.
4. A18에는 아래 세 문장을 자신의 결과에 맞게 완성합니다. “이 입력에서 ___을 찾으려고 했다.” “___ 설정을 사용하자 ___ 결과가 나왔다.” “이 결과만으로 ___까지 확인한 것은 아니다.”

제출 묶음은 **A17 결과표 + 설정 값 + 출력 또는 제공 출력 대조 기록 + A18 설명**입니다. 실제 카메라가 없어도 파일 실습과 모의 장치 흐름의 근거로 평가받을 수 있습니다.

## 수행 과제

- 이미지의 높이·너비·채널을 읽고, 한 픽셀을 `[y, x]`로 찾는 이유를 설명하세요. BGR은 파랑·초록·빨강 순서의 색 값이라는 점을 예시와 연결하세요.
- 임계값 100과 60을 비교한 기록, 최소 면적을 바꾼 기록을 제시하세요. 한 번에 바꾼 설정과 그대로 둔 설정을 구별하세요.
- 빈 장면, 어두운 장면, 표식이 붙은 장면, 처음 보는 입력에서 예상과 실제를 비교하세요. “읽기에 실패함”과 “정상적으로 읽었지만 검출 수가 0임”을 같은 결과로 쓰지 마세요.
- 카메라 예제의 열기 → 읽기 → 종료 입력 → 자원 정리 흐름을 말로 설명하세요. 모의 시험에서 확인한 것과 실제 카메라에서 아직 확인하지 않은 것을 따로 적으세요.

## 채점 기준 · 100점

| 관점 | 배점 | 충분한 근거의 기준 |
|---|---:|---|
| 이미지 기초 | 25 | 높이·너비·BGR·`[y, x]`를 실제 예시의 값과 연결하여 설명한다. |
| 처리와 비교 | 30 | 입력 이름과 설정을 남기고, 임계값·면적 변경 전후의 예상과 실제 결과를 비교한다. |
| 검수와 한계 | 25 | 빈·어두운·붙은·새 입력의 차이를 설명하고, 읽기 실패와 정상 0을 구분한다. |
| 장치 흐름 설명 | 20 | 열기·읽기·`q`·`finally`·`release`의 역할과 실제 미검증 범위를 설명한다. |

각 관점은 **근거 없음 0% / 일부 근거가 있으나 핵심 누락 50% / 입력·설정·출력이 맞고 한계까지 설명 100%**로 채점합니다. 예를 들어 30점 항목은 0·15·30점입니다. 25점 항목의 중간 점수는 12.5점입니다. 70점 이상이고 입력 실패와 정상 빈 장면을 구분하면 기본 목표에 도달한 것으로 봅니다.

## 설명으로 확인하는 질문

1. `shape`가 `(480, 640, 3)`이라면 너비와 채널 수는 각각 무엇인가요? 숫자의 순서를 함께 설명하세요.
2. `THRESH_BINARY`의 기준이 100일 때 밝기가 정확히 100인 픽셀은 어느 쪽으로 처리되나요? 코드의 비교 규칙을 근거로 설명하세요.
3. 붙어 있는 표식 두 개가 윤곽선 하나로 검출됐다면, 검출 수만 보고 물체가 하나라고 결론 내릴 수 있나요? 다음에 확인할 것을 적으세요.
4. 모의 캡처에서 `release` 호출을 확인하면 실제 카메라 드라이버 동작까지 검증한 것인가요? 시험 범위를 설명하세요.

## 제출 전 확인

- 파일 이름과 설정이 기록에 남아 있는가?
- 예상과 실제를 구분했는가?
- 직접 실행과 제공 출력 관찰을 구분했는가?
- 실패 사례와 아직 확인하지 않은 조건을 적었는가?

점수가 낮은 항목은 전체를 다시 만들기보다 빠진 입력·설정·관찰 근거를 보충한 뒤 다시 설명합니다. 정답과 채점 예시는 강사용 자료에 있습니다.


## 새 상황으로 옮겨 보는 전이 문제 · 복습·도전

교시당 한 문제이며 기존 필수 평가 후 필요에 따라 선택합니다. 독립 작성 또는 판단을 먼저 기록한 뒤 해설을 확인합니다. 설치 실패나 장비 부재는 개념 오답과 구분합니다.

### 전이 1 · 1교시

가로 7·세로 2·채널 3인 사진에서 x=6,y=1의 표기와 색 성분 수를 쓰세요.

<details><summary>정답과 해설</summary>

image[1,6], 42개입니다. 가로·세로 순서를 뒤집거나 42를 물체 수로 쓰지 않습니다.

</details>

### 전이 2 · 2교시

ROI가 [5:25,10:60]일 때 크기와 ROI (3,4)의 원본 (x,y)를 계산하세요.

<details><summary>정답과 해설</summary>

높이 20·너비 50, 원본 (13,9)입니다. 끝 번호는 제외하고 원본 시작점만 더합니다.

</details>

### 전이 3 · 3교시

밝기 [99,100,101], threshold=100과 면적 [99,100,101], min_area=100을 각각 판정하세요.

<details><summary>정답과 해설</summary>

마스크 [0,0,255], 남는 영역 2개입니다. 밝기의 >와 면적의 >=를 구별합니다.

</details>

### 전이 4 · 4교시

밝기와 면적 기준을 동시에 바꿔 수가 4에서 3이 되었습니다. 원인 검증용 다음 시험을 작성하세요.

<details><summary>정답과 해설</summary>

같은 파일과 면적 기준을 고정하고 밝기만 바꾸거나 반대로 한 조건만 비교합니다. 현재 숫자만으로 원인을 확정할 수 없습니다.

</details>

### 전이 5 · 5교시

한 물체가 10프레임에서 계속 검출됐습니다. 통과 물품 수를 10이라 보고해도 될까요?

<details><summary>정답과 해설</summary>

아닙니다. 프레임별 관찰과 고유 물체를 구별해야 하며 이동 추적·통과 기준·중복 시험이 필요합니다.

</details>

### 전이 6 · 6교시

합성 사진 두 개에서 예상 수가 맞았습니다. 실물 컨베이어 인수 보고의 상태를 쓰세요.

<details><summary>정답과 해설</summary>

해당 파일 비교는 통과, 실물 속도·조명·장치 시험은 미실행입니다. 합성 입력 결과를 전체 현장 정확도로 확대하지 않습니다.

</details>
