# 시험과 실제 장면의 대응
실행 위치 kit, 명령: `.\.venv\Scripts\python.exe -m unittest discover -s tests -v`.
표준 라이브러리만으로 좌표·상태 시험을 실행할 수 있다. 모델·OpenCV·웹캠이 없어도 시험되므로 통과가 실제 추적 성능 보증은 아니다.

|시험|입력 변화|기대|
|---|---|---|
|머무름|밖→안→안|entered 한 번|
|재진입|안→밖→안|새 entered|
|프레임 중복|같은 ID 두 관찰|사건 한 번·duplicate_id 경고|
|긴 소실|기준 초과 뒤 안쪽 재등장|lost_id·first_seen_inside|
|짧은 소실|안→없음→안|추가 사건 없음|
|선 떨림|왼쪽→여유영역→오른쪽|확정 오른쪽에 도달할 때 통과 한 번|
|새 ID|안쪽 ID1→ID99|새 관찰이며 같은 사람 확정 아님|
|관찰 없음|기준 초과 빈 프레임|기억 제거·소실 경고|

현장 추가 시험: 사진 검출 결과와 원본 대조, 자연 동영상의 ID 변경 장면, 실제 카메라 열기·종료 후 재열기, 저장 영상 끝까지 재생, 다른 해상도에서 구역 위치 유지, 어두운 장면·빠른 이동, CPU 반복 측정. 실제 실행한 것만 결과 칸에 쓴다.
