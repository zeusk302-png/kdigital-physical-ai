제작 검증은 상위 verification.md와 verification-inference.json을 참조한다. 공식 bus 사진의 사람 검출은 320→3개,640→4개였으며 실제 CPU 모델 추론이다. 같은 사진을 가로로 평행이동한 12프레임에서 ByteTrack을 실제 호출했다. 이는 자연 영상·실제 웹캠 성능 검증과 다르다. 좌표 상태 시험은 표준 unittest로 따로 수행했다. 학생 실험 수치는 학생이 실행한 값만 적는다.
