# 영상 프로젝트 변경 지침
README.md → docs/setup.md → docs/architecture.md → tests 순서로 읽는다.
검출·추적·좌표·사건·표시·실행 역할을 유지한다. public 함수에 한국어 설명과 입력·출력 의미를 쓴다.
YOLO11n/ByteTrack/고정 의존성을 임의로 교체하지 않는다. 변경 전에 문제·수정 파일·시험을 설명한다.
사건 type과 로그 필드는 다음 대시보드가 사용하므로 임의로 변경하지 않는다.
진입·머무름·재진입·중복ID·소실·선 주변 흔들림 시험을 유지하고 실패를 숨기려고 시험을 삭제하지 않는다.
runtime/ 원본 영상·가중치·결과는 Git과 배포에 넣지 않는다. 게시·계정 생성·학습 데이터 업로드는 별도 요청이 필요하다.
모의 좌표 시험·실제 모델 추론·실제 웹캠 검증을 구분하고 실행하지 않은 결과를 만들지 않는다.
