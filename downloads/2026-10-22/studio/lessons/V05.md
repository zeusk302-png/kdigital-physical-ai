# V05 대상 필터와 검출 조건 직접 작성하기


필터는 모델이 반환한 결과 중 프로그램에서 사용할 대상만 고르는 규칙입니다. 클래스 필터와 점수 기준을 따로 조절해야 무엇 때문에 결과가 달라졌는지 알 수 있습니다.

```powershell
.\.venv\Scripts\python.exe -m examples.03_detect --source 0 --classes 0 --conf 0.7 --imgsz 640
```

같은 장소에서 conf 0.35와 0.7을 비교합니다. 점수 기준이 높으면 틀린 검출이 줄 수 있지만 실제 대상을 놓칠 수도 있습니다. 사진 속 실제 대상 수를 사람이 확인하고, 틀리게 찾음과 놓침을 따로 적습니다. 결과 박스 수가 적어졌다고 성능이 좋아졌다고 결론 내리지 않습니다.

## 학생이 작성할 조건

예제 반복문 안에서 점수와 박스 크기를 읽어 최소 넓이보다 작은 박스를 표시 목록에서 제외하는 함수를 만듭니다. 넓이는 (right-left)*(bottom-top)입니다. 화면 크기가 바뀌면 고정 픽셀 넓이가 같은 뜻인지 확인하고 비율 기준으로 확장합니다. 무엇을 제외했는지 터미널에 함께 출력해 규칙을 설명할 수 있게 합니다.

## 오류 주입과 복구

클래스 번호를 잘못 지정해 원하는 대상이 사라지는 상황을 만들고 names와 비교해 고칩니다. conf를 1.5로 입력하면 시작 시 잘못된 설정이라고 안내되어야 합니다. ‘결과가 없다’와 ‘카메라 입력이 없다’를 같은 메시지로 처리하지 않습니다.


## 주석과 함께 읽는 실행 코드

```python
"""사진 한 장에서 객체의 종류, 점수, 위치를 얻습니다."""
from pathlib import Path


def load_model(weights):
    """다운로드는 준비 단계에서만 합니다. 실행 중 몰래 받지 않습니다."""
    from ultralytics import YOLO
    if not Path(weights).is_file():
        raise FileNotFoundError('가중치 없음: README의 prepare 명령을 먼저 실행하세요.')
    return YOLO(weights)


def detect(model, frame, conf=0.35, imgsz=640, classes=(0,)):
    # model.predict는 결과 목록을 줍니다. [0]은 첫 사진의 결과입니다.
    return model.predict(frame, conf=conf, imgsz=imgsz, classes=list(classes),
                         device='cpu', verbose=False)[0]

```

실행 명령의 현재 위치는 kit입니다. 파일을 읽은 뒤 한 기능을 직접 바꾸고 예상과 실제 결과를 비교합니다.
