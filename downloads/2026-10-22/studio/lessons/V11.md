# V11 AI 작업 지시·파일 구조·Git·팀 검수


프로젝트는 camera.py(입력), detector.py(검출), tracker.py(추적 변환), zones.py(위치 계산), events.py(기억과 사건), drawing.py(표시), main.py(연결)로 나뉩니다. 여러 파일이 있다고 무조건 좋은 구조는 아닙니다. 무엇을 바꾸려는지와 책임이 맞아야 합니다.

## 복사할 요청

```text
AGENTS.md, src/events.py, src/zones.py와 관련 tests를 읽어.
구역에 2초 이상 머물면 한 번만 알리는 기능을 추가하고 싶어.
입력·기억할 상태·출력·종료 조건을 먼저 설계해.
카메라 입구와 YOLO 모델 설정은 바꾸지 마.
첫 관찰·경계·나갔다 재진입·소실에 대한 시험을 제안해.
모의 로직 시험과 실제 카메라 확인을 나눠 보고해.
```

계획을 읽고 필요한 수정 범위를 정합니다. 코드가 바뀌면 diff와 시험을 확인한 뒤 실제 영상을 넣습니다. 시험 통과가 인식 성능을 증명하지는 않습니다. 팀 Notion 검수 문서에는 사용 입력·문제 장면·확인 환경을 적고, 이전 수업의 MCP로 자기 피드백만 읽어 작업을 정리할 수 있습니다. 사용 권한 없는 영상이나 개인 얼굴을 AI에 업로드하지 않습니다.

## Git 포함과 제외

src·examples·configs·requirements·README·tests·docs를 올립니다. .venv·runtime·가중치·촬영 영상·캐시는 제외합니다. .gitignore는 이미 커밋한 파일을 지우지 않으므로 git status와 git diff --cached를 확인합니다. 공개 GitHub Pages는 이 Python 웹캠 프로그램을 서버처럼 실행해 주지 않습니다. 프로젝트 소개·허가된 결과 화면을 게시할 수 있고 프로그램 자체는 PC에서 실행합니다.
