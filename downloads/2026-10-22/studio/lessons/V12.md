# V12 나의 웹캠 프로그램 완성과 재현


최종 작품은 화면에 박스가 뜨는 예제를 넘어, 영상에서 얻은 값이 프로그램 동작을 바꾸어야 합니다. 다음 중 하나를 선택하거나 같은 수준의 자기 주제를 정합니다.

|주제|핵심 동작|확인할 실패|
|구역 접근 알림|바깥에서 안으로 진입할 때 표시·기록|경계 흔들림·가림·재등장|
|방향별 통과 집계|선을 넘은 방향별로 수 표시|처음 등장·선 위 정지·중복|
|물체 찾기 도우미|선택한 클래스만 표시하고 발견 장면 저장|비슷한 물체·미검출·작은 대상|
|체류 알림|구역 안 일정 시간 머물면 한 번 알림|일시 가림·나갔다 재진입|

## 구현 순서

입력과 목적을 정하고 → 화면을 종이에 그려 → 필요한 검출 값을 고르고 → 기억할 상태를 정하고 → 사건 처리와 표시를 연결합니다. 시작 코드가 있어도 자기 설정과 기능을 하나 이상 직접 작성해야 합니다. 기능별 파일과 기대 결과를 먼저 적습니다.

## 팀별 검수

2명씩 교대해 실행자와 검수자를 맡고 각자 원본을 보관합니다. 검수자는 설명 없이 README 명령을 실행해 정상·빈 화면·가림·입력 종료를 확인합니다. 팀 대표의 영상 실행을 본 것과 자기 PC에서 직접 실행한 것을 구분합니다. 카메라를 못 쓰는 학생은 권한 있는 영상 파일로 같은 함수와 사건 처리를 진행하고 웹캠 확인은 미실행으로 남깁니다.

## 제출

프로그램 목적·실행 명령·사용 카메라 번호·클래스·구역·자기 기능·실패와 복구·Git 커밋을 docs/experiment.md에 적습니다. 새 입력에서 다시 확인하고 실제 성공·실패를 기록합니다. 영상은 수업 내 허용된 경로로 공유하고 공개 저장소에는 개인정보 없는 설명과 코드만 둡니다. 10/29에는 events.jsonl의 실제 사건 또는 센서 데이터를 대시보드에 연결합니다.
