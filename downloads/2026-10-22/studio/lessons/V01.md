# V01 설치·폴더·가상환경과 웹캠 준비


## 먼저 구별할 것

Python 실행, 패키지 설치, 카메라 연결은 서로 다른 단계입니다. 하나가 실패했다고 모든 코드를 다시 만들지 않습니다.


## 폴더와 설치

자료 ZIP을 ‘모두 압축 풀기’로 풀고 kit를 VS Code의 File → Open Folder로 엽니다. Terminal → New Terminal에서 pwd와 dir을 입력해 requirements.txt·prepare.py·src가 보이는지 확인합니다. [Python 공식 Windows 설치](https://www.python.org/downloads/windows/)에서 Python 3.12 64비트를 설치합니다. 설치 뒤 VS Code를 다시 열고 아래를 한 줄씩 실행합니다. 3.12 명령이 없으면 py --list로 설치 목록을 확인합니다.

```powershell
py --list
py -3.12 --version
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:YOLO_CONFIG_DIR="$PWD/runtime"
.\.venv\Scripts\python.exe prepare.py
.\.venv\Scripts\python.exe -c "import cv2, ultralytics; print(cv2.__version__, ultralytics.__version__)"
```

.venv는 이 프로젝트 전용 실행 환경입니다. 활성화 명령 없이 그 안의 python.exe를 직접 사용하므로 PowerShell 실행 정책을 바꿀 필요가 없습니다. requirements.txt에는 수업에서 사용할 버전이 적혀 있고 prepare.py는 YOLO11n 가중치를 내려받습니다. CPU 기준이라 GPU·CUDA 설치는 필수가 아닙니다. 최초 설치는 다운로드 용량과 네트워크에 따라 시간이 걸립니다. 다운로드 중인 것을 오류로 오해하지 말고 마지막 결과를 확인합니다.

예상 결과는 두 버전 번호와 runtime/models/yolo11n.pt 파일입니다. 모델은 이번 수업의 검증된 YOLO11n으로 통일합니다. 공식 문서의 최신 모델 예시와 이름이 다를 수 있으므로 중간에 모델을 임의로 바꾸지 않습니다. pip가 실패하면 마지막 오류와 현재 Python 경로를 확인하고 같은 명령을 무작정 반복하지 않습니다.

## 웹캠 준비

Logitech C270을 USB에 연결합니다. Windows 카메라 앱으로 화면이 나오는지 확인한 뒤 앱을 완전히 닫습니다. Teams·Zoom·다른 Python 창도 카메라를 사용 중인지 확인합니다. Windows 설정 → 개인정보 및 보안 → 카메라에서 카메라 액세스와 데스크톱 앱 접근 허용을 확인합니다. 기관 PC에서 잠긴 설정은 임의로 우회하지 않습니다.

내장 카메라가 0이고 C270이 1일 수 있습니다. 카메라 번호는 기기 제품 번호가 아니라 PC가 할당한 입력 번호입니다. Raspberry Pi CSI 카메라나 XIAO 카메라를 Windows USB 웹캠처럼 바로 0으로 열 수 있다고 가정하지 않습니다.

## 오류 해결

ModuleNotFoundError는 설치한 Python과 실행한 Python이 같은지부터 확인합니다. ‘No matching distribution’은 Python 버전·64비트·지원 운영체제를 확인합니다. 모델 없음은 prepare.py 실행과 현재 폴더를 확인합니다. 카메라 미연결은 다음 V02에서 번호·권한·백엔드 순서로 확인합니다.
