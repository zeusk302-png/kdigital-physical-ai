# V06 추적 ID와 프레임 사이 기억


검출은 현재 프레임의 박스를 찾고, 추적은 다음 프레임에서도 같은 대상으로 보이는 박스를 연결합니다. 같은 사람을 매 프레임마다 새 사람으로 세면 실제 인원보다 훨씬 큰 숫자가 나옵니다. 추적 ID는 잠시 이어지는 영상 안의 번호이며 영구 신원 번호가 아닙니다.

완성 실행본은 src.main입니다. 먼저 V02와 V04가 정상인지 확인한 뒤 실행합니다.

```powershell
.\.venv\Scripts\python.exe -m src.main --source 0 --show --output runtime/results/tracking01
```

이 프로그램은 ByteTrack을 명시하고 persist=True로 이어지는 프레임 상태를 유지합니다. 추적기를 프레임마다 새로 만들면 ID 기억이 끊깁니다. boxes.id가 아직 없는 프레임은 화면 검출과 사건 판정을 구분합니다. ID를 무조건 정수로 바꾸려고 하면 오류가 날 수 있습니다.

## 직접 확인

한 사람이 천천히 이동 → 가림 → 다시 등장하는 순서로 시험합니다. 같은 ID가 유지되는 구간과 달라지는 구간을 적습니다. 카메라 밖으로 나갔다 들어오면 같은 ID가 보장되지 않으므로 이 수를 누적 고유 방문자 수라고 부르지 않습니다. 두 사람이 교차할 때 잘못 연결되는 사례도 기록합니다.

## 코드 확장

추적 박스의 아래쪽 가운데 좌표를 구합니다. 바닥 기준의 구역 판정에 쓰려는 선택이며 얼굴 중심이나 박스 중심과 결과가 다릅니다. src/tracker.py는 모델 결과 변환, src/events.py는 프레임 사이 기억을 담당합니다. AI에게 ID 표시 수정만 요청할 때 사건 처리까지 바꾸지 않게 범위를 지정합니다.


## 주석과 함께 읽는 실행 코드

```python
"""추적기 호출과 결과 변환. 추적 ID는 주민번호처럼 영구적인 번호가 아닙니다."""
from dataclasses import dataclass


@dataclass(frozen=True)
class Observation:
    track_id: int
    xyxy: tuple
    class_id: int = 0
    confidence: float = 1.0


def track_frame(model, frame, conf=0.35, imgsz=640, classes=(0,)):
    # persist=True: 다음 사진도 같은 영상의 이어지는 장면이라고 알려 줍니다.
    # 기본 추적기는 버전에 따라 달라질 수 있어 ByteTrack을 명시합니다.
    result = model.track(frame, persist=True, tracker='bytetrack.yaml',
                         conf=conf, imgsz=imgsz, classes=list(classes),
                         device='cpu', verbose=False)[0]
    observations = []
    if result.boxes is not None and result.boxes.id is not None:
        for box, tid, cls, score in zip(result.boxes.xyxy.cpu().tolist(),
                result.boxes.id.cpu().tolist(), result.boxes.cls.cpu().tolist(),
                result.boxes.conf.cpu().tolist()):
            observations.append(Observation(int(tid), tuple(box), int(cls), float(score)))
    # 아직 ID를 받지 못한 검출은 화면에는 보이지만 사건 판정에서는 제외합니다.
    return result, observations

```

실행 명령의 현재 위치는 kit입니다. 파일을 읽은 뒤 한 기능을 직접 바꾸고 예상과 실제 결과를 비교합니다.
