# V02 웹캠 화면을 직접 띄우는 첫 프로그램


사진 한 장을 프레임이라고 합니다. 영상은 여러 프레임을 순서대로 보여주는 것이고, 웹캠 프로그램은 새 프레임을 읽고 처리하고 표시하는 일을 반복합니다. OpenCV는 그 사진 배열을 읽고 바꾸고 보여주는 도구입니다. 아직 YOLO를 쓰지 않고 카메라 입구부터 확인합니다.

## 실행과 조작

```powershell
.\.venv\Scripts\python.exe -m examples.01_camera --source 0
```

카메라 창을 클릭한 뒤 Q로 종료합니다. 터미널의 Ctrl+C도 중단에 사용할 수 있습니다. 화면이 다른 카메라라면 종료하고 --source 1로 다시 실행합니다. 번호는 확인한 장치만 사용합니다. 검은 화면이면 다른 앱을 닫고 다음처럼 Windows 백엔드 하나를 비교합니다.

```powershell
.\.venv\Scripts\python.exe -m examples.01_camera --source 1 --backend dshow
```

auto는 기본 연결 방식, dshow와 msmf는 Windows의 다른 영상 입력 방식입니다. 어느 방식이 항상 더 좋다고 정하지 말고 실제 PC에서 확인한 번호와 방식을 docs/experiment.md에 기록합니다.

## 코드 읽기

capture.read()는 성공 여부 ok와 사진 frame을 함께 반환합니다. 실패한 frame을 바로 그리려고 하면 ‘NoneType’ 또는 이미지가 비었다는 오류가 납니다. 먼저 ok를 확인해야 합니다. shape[:2]는 높이·너비이며 그림 좌표의 x·y 순서와 다릅니다. finally의 release는 오류가 나도 카메라를 돌려주는 부분입니다.

## 직접 구현

표시 문구에 자기 프로그램 이름을 넣고 글자 위치·색을 바꿉니다. 다음에는 화면 한가운데 기준점을 그려 봅니다. 카메라 앞 손의 위치와 화면 좌우가 어떻게 보이는지 확인하고, 뒤집기 기능을 추가한다면 구역 판정에 쓰는 좌표도 같은 기준인지 설명합니다. 보기 화면만 뒤집고 판정 좌표를 그대로 두는 문제를 주의합니다.


## 주석과 함께 읽는 실행 코드

```python
"""실행 위치 kit: python -m examples.01_camera --source 0
화면은 Q로 종료합니다. 파일 입력은 --source runtime/input/clip.mp4입니다.
"""
import argparse
import cv2
from src.camera import open_input

def main(args):
    capture = open_input(args.source, args.backend)
    frames = 0  # 지금까지 실제로 읽은 프레임 수입니다.
    try:
        # limit=0이면 제한 없이 계속합니다. 영상 파일은 끝에서 종료합니다.
        while args.limit == 0 or frames < args.limit:
            ok, frame = capture.read()  # 성공 여부와 사진 배열, 두 값을 돌려줍니다.
            if not ok:
                if args.source.isdecimal():
                    raise RuntimeError('카메라 읽기 실패: USB 연결과 다른 앱을 확인하세요.')
                break  # 영상 파일의 마지막 프레임을 읽었습니다.
            height, width = frame.shape[:2]  # 높이·너비 순서에 주의합니다.
            frames += 1
            if not args.no_show:
                cv2.putText(frame, f'{width}x{height} frame={frames}', (20, 35),
                            cv2.FONT_HERSHEY_SIMPLEX, 0.7, (0, 255, 0), 2)
                cv2.imshow('01 Camera - Q to stop', frame)
                # 창을 클릭한 뒤 Q를 누릅니다. waitKey는 창의 키 입력도 처리합니다.
                if cv2.waitKey(1) & 0xFF == ord('q'):
                    break
        if frames == 0:
            raise RuntimeError('읽은 프레임이 없습니다.')
        print(f'읽은 프레임: {frames}')
    finally:
        # 오류가 나도 다음 프로그램이 카메라를 쓸 수 있도록 반환합니다.
        capture.release()
        if not args.no_show:
            cv2.destroyAllWindows()

if __name__ == '__main__':
    parser = argparse.ArgumentParser()
    parser.add_argument('--source', default='0')
    parser.add_argument('--backend', choices=['auto','dshow','msmf'], default='auto')
    parser.add_argument('--limit', type=int, default=0)
    parser.add_argument('--no-show', action='store_true')
    main(parser.parse_args())

```

실행 명령의 현재 위치는 kit입니다. 파일을 읽은 뒤 한 기능을 직접 바꾸고 예상과 실제 결과를 비교합니다.
