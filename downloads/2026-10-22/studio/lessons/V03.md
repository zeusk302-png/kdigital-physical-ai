# V03 키보드로 사진 저장하고 원본 확인하기


화면에 보이는 안내 글자와 원본 사진은 구분해서 보관합니다. frame.copy()는 표시용 복사본을 만들고 imwrite는 파일을 저장합니다. 화면에만 표시된 글자는 원본에 자동 저장되지 않습니다.

```powershell
.\.venv\Scripts\python.exe -m examples.02_snapshot --source 0
```

카메라 창에서 S를 누르면 runtime/input에 사진이 저장됩니다. Q로 종료하고 탐색기에서 실제 JPG를 열어 봅니다. S를 누른 횟수와 새 파일 수를 비교합니다. 사람이 나온 사진은 촬영에 동의한 팀원만 포함하고 실습 원본은 로컬에 둡니다. Git에는 코드와 설정을 올립니다.

## 준비 → 저장 → 확인

1. 책상 위 물체를 촬영해 첫 사진을 만듭니다.
2. 같은 물체를 밝기·거리·가림 정도를 달리해 촬영합니다.
3. 각 파일명과 촬영 조건을 experiment.md에 적습니다.
4. imwrite 반환이 False면 저장 성공 문구를 출력하지 않고 폴더·권한·디스크를 확인합니다.

## 독립 변경

G를 누르면 회색조 사진을 저장하도록 구현합니다. cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)를 사용하고 컬러 원본과 다른 파일명을 붙입니다. 왜 원본을 덮어쓰지 않아야 하는지 설명합니다. 의도한 오류는 존재하지 않는 폴더로 저장해 보는 것입니다. 실패를 확인하고 폴더 생성과 결과 검사로 복구합니다.


## 주석과 함께 읽는 실행 코드

```python
"""S로 한 장 저장하고 Q로 종료합니다. 실행 위치는 kit입니다."""
import argparse
from datetime import datetime
from pathlib import Path
import cv2
from src.camera import open_input

def main(source, backend):
    capture = open_input(source, backend)
    folder = Path('runtime/input')
    folder.mkdir(parents=True, exist_ok=True)
    try:
        while True:
            ok, frame = capture.read()
            if not ok:
                if source.isdecimal():
                    raise RuntimeError('카메라 프레임을 읽지 못했습니다.')
                break
            # 원본 frame을 보존하고 표시용 복사본에만 안내를 그립니다.
            shown = frame.copy()
            cv2.putText(shown, 'S: save / Q: quit', (20, 35),
                        cv2.FONT_HERSHEY_SIMPLEX, 0.8, (0,255,0), 2)
            cv2.imshow('02 Snapshot', shown)
            key = cv2.waitKey(1) & 0xFF
            if key == ord('s'):
                # 마이크로초까지 포함해 연속 저장 시 이전 파일을 덮지 않습니다.
                name = datetime.now().strftime('photo_%Y%m%d_%H%M%S_%f.jpg')
                target = folder / name
                if not cv2.imwrite(str(target), frame):
                    raise RuntimeError('사진 저장 실패: 폴더·디스크 공간을 확인하세요.')
                print('저장:', target.resolve())
            elif key == ord('q'):
                break
    finally:
        capture.release()
        cv2.destroyAllWindows()

if __name__ == '__main__':
    p=argparse.ArgumentParser()
    p.add_argument('--source',default='0')
    p.add_argument('--backend',choices=['auto','dshow','msmf'],default='auto')
    args=p.parse_args();main(args.source,args.backend)

```

실행 명령의 현재 위치는 kit입니다. 파일을 읽은 뒤 한 기능을 직접 바꾸고 예상과 실제 결과를 비교합니다.
