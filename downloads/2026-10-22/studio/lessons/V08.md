# V08 방향별 선 통과 집계와 중복 처리


선 통과는 대상이 어느 쪽에 있었고 어느 쪽으로 바뀌었는지를 비교하는 사건입니다. 한 프레임의 x 좌표만으로 이동 방향을 알 수는 없습니다. line_x는 세로선 위치, margin은 선 근처에서 흔들리는 좌표를 바로 방향 전환으로 세지 않기 위한 여유 영역입니다.

## 시험 순서

왼쪽→오른쪽, 오른쪽→왼쪽, 선 앞에서 멈춤, 선 주변에서 작은 움직임, 가림 뒤 재등장을 각각 시험합니다. 첫 관찰이 오른쪽인 것만으로 통과가 생기면 안 됩니다. 선 근처 0 영역에서는 마지막으로 확정한 쪽을 기억합니다.

## 직접 구현

events 중 type이 crossed인 것만 골라 direction별 합계를 만듭니다. 매 프레임 검출 개수를 더하지 않습니다. 화면에 좌→우와 우→좌 수를 별도로 표시하고 Q로 종료한 뒤 events.jsonl의 해당 사건 수와 맞는지 확인합니다. 재진입은 다른 사건일 수 있으므로 ‘고유 인원’이라는 제목을 붙이지 않습니다.

## 의도한 오류

margin을 0으로 바꾸고 경계 흔들림을 비교합니다. 중복이 재현되지 않으면 재현되지 않았다고 기록하고 단위시험의 경계 좌표로 상태 로직을 확인합니다. 카메라에서 보이지 않은 오류를 보았다고 적지 않습니다. tests의 입력은 로직 확인용이며 실제 영상 인식 결과를 대신하는 근거가 아닙니다.


## 주석과 함께 읽는 실행 코드

```python
"""좌표만 계산합니다. 모델이나 카메라가 없어도 시험할 수 있습니다."""


def bottom_center(xyxy):
    # 사람의 발이 있는 쪽을 대표점으로 선택합니다. 박스 전체 겹침과 다릅니다.
    left, top, right, bottom = xyxy
    return ((left + right) / 2, bottom)


def inside(point, zone):
    x, y = point
    left, top, right, bottom = zone
    return left <= x <= right and top <= y <= bottom


def side(point, line_x, margin):
    # 선 주위 여유 영역은 0입니다. 작은 떨림을 통과로 세지 않습니다.
    if point[0] < line_x - margin:
        return -1
    if point[0] > line_x + margin:
        return 1
    return 0

```

실행 명령의 현재 위치는 kit입니다. 파일을 읽은 뒤 한 기능을 직접 바꾸고 예상과 실제 결과를 비교합니다.
