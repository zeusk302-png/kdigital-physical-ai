# V04 YOLO 검출·박스·클래스·점수 읽기


YOLO는 사진에서 학습한 종류의 물체를 찾아 종류·점수·사각형 위치를 돌려주는 모델입니다. OpenCV는 카메라와 화면을 다루고, YOLO는 그 프레임 안의 객체를 검출합니다. 추론은 학습된 모델로 새 입력을 처리하는 것이며 오늘은 처음부터 모델을 학습하지 않습니다.

```powershell
.\.venv\Scripts\python.exe -m examples.03_detect --source 0 --classes 0 --conf 0.35 --imgsz 640
```

기본 classes 0은 이 COCO 사전학습 모델의 person입니다. 신뢰도 점수 0.8을 ‘정확도 80%’라고 해석하지 않습니다. boxes.xyxy의 네 값은 왼쪽·위·오른쪽·아래 픽셀 위치이고 cls는 종류 번호, conf는 점수입니다. results[0]은 이번 한 프레임의 결과입니다. 다음 코드의 zip은 같은 순서의 종류·점수·박스를 함께 꺼냅니다.

## 직접 해보기

첫 번째 실행은 사람만, 다음은 모델이 알고 있는 책상 위 물체 하나를 골라 검출합니다. 클래스 목록은 모델의 names에서 확인합니다. model.names에 없는 사용자 물건 이름을 글자로 추가한다고 그 물건을 새로 학습하는 것은 아닙니다. 컵·병처럼 사전학습 대상인지 먼저 확인합니다.

## 결과가 없는 프레임

아무도 없는 화면에서 검출이 0개가 나오는 것은 정상일 수 있습니다. boxes가 비어 있는 상황도 반복문이 정상 진행되는지 확인합니다. 얼굴이나 개인 이름을 식별하는 프로그램은 아니며 person 검출만으로 특정 학생을 알아낼 수 없습니다.


## 주석과 함께 읽는 실행 코드

```python
"""검출만 먼저 익힙니다. 추적 ID·구역 사건은 다음 단계에서 붙입니다."""
import argparse
from time import perf_counter
import cv2
from src.camera import open_input
from src.detector import load_model, detect

def main(args):
    if not 0 <= args.conf <= 1:
        raise ValueError('conf는 0~1 사이입니다.')
    # 모델은 반복문 밖에서 한 번만 읽습니다. 프레임마다 읽으면 매우 느립니다.
    model=load_model(args.weights)
    capture=open_input(args.source,args.backend)
    frames=0
    try:
        while args.limit == 0 or frames < args.limit:
            ok,frame=capture.read()
            if not ok:
                if args.source.isdecimal():
                    raise RuntimeError('카메라 읽기 실패')
                break
            tick=perf_counter()
            result=detect(model,frame,args.conf,args.imgsz,args.classes)
            # conf 점수는 정답률이 아닙니다. 이 검출에 대한 모델의 점수입니다.
            boxes=result.boxes
            for cls,score,xyxy in zip(boxes.cls.tolist(), boxes.conf.tolist(),
                                      boxes.xyxy.tolist()):
                print(model.names[int(cls)], round(score,3), [round(v) for v in xyxy])
            shown=result.plot()  # 박스와 이름을 그린 새 사진 배열입니다.
            latency_ms=(perf_counter()-tick)*1000
            cv2.putText(shown,f'detections={len(boxes)} pipeline={latency_ms:.0f}ms',
                        (20,35),cv2.FONT_HERSHEY_SIMPLEX,0.7,(0,255,0),2)
            frames+=1
            if not args.no_show:
                cv2.imshow('03 YOLO - Q to stop',shown)
                if cv2.waitKey(1)&0xFF==ord('q'):break
        if frames==0:raise RuntimeError('읽은 프레임이 없습니다.')
        print(f'처리 프레임: {frames}')
    finally:
        capture.release()
        if not args.no_show:cv2.destroyAllWindows()

if __name__=='__main__':
    p=argparse.ArgumentParser()
    p.add_argument('--source',default='0')
    p.add_argument('--backend',choices=['auto','dshow','msmf'],default='auto')
    p.add_argument('--weights',default='runtime/models/yolo11n.pt')
    p.add_argument('--conf',type=float,default=0.35)
    p.add_argument('--imgsz',type=int,default=640)
    p.add_argument('--classes',type=int,nargs='+',default=[0])
    p.add_argument('--limit',type=int,default=0)
    p.add_argument('--no-show',action='store_true')
    main(p.parse_args())

```

실행 명령의 현재 위치는 kit입니다. 파일을 읽은 뒤 한 기능을 직접 바꾸고 예상과 실제 결과를 비교합니다.
