# 설치와 로그인부터 시작하기

GitHub 가입과 설치부터 시작해 내 프로필을 꾸미고 파이썬 작품을 공유합니다. GitHub Desktop으로 변경을 확인하고 커밋·push를 반복합니다. 마지막에는 자기 저장소에서 브랜치를 만들고 짝과 PR을 검토합니다.

Windows와 설치 권한·인터넷 사용을 기준으로 안내합니다. macOS는 공식 다운로드에서 해당 운영체제를 선택하세요. 본인 이메일에 접근할 수 있어야 합니다. 가입·인증은 본인이 진행합니다. 유료 구독은 필요하지 않습니다.

## 준비물

- 본인 이메일을 확인할 수 있는 브라우저와 PC
- Git·GitHub Desktop 설치 권한. 막히면 강사에게 알려 주세요.
- Python 수업에서 만든 파일. 미완성이라면 실습 ZIP의 공통 예제를 사용합니다.
- [실습 ZIP](student-examples.zip)을 내려받고 압축을 일반 폴더에 풉니다.

## 오늘 끝나면 남는 것

1. 로그인한 GitHub와 연결한 Desktop
2. 자기소개·배지·이미지 또는 GIF가 있는 프로필
3. 실행 안내가 있는 Python 작품 저장소
4. 목적이 다른 커밋과 PR 검토 기록

## 파일을 여는 위치

브라우저는 github.com, Desktop은 변경 기록, 편집기는 README와 Python 파일을 고치는 곳입니다. 터미널은 명령을 입력합니다. README.md는 문서, main.py는 Python 프로그램, demo.gif는 움직이는 그림입니다. GitHub의 코드 보기 화면은 Python 실행기가 아닙니다.
