# A08 · 현재 내용과 과거 커밋 비교

첫 커밋에는 Run checker.가 있고 둘째에는 Run checker from course.가 있습니다. show는 이전 내용을 보여 주고 diff는 둘의 변경 줄을 보여 줍니다.

## 전체 시연 코드


```powershell
git show HEAD~1:README.md
git diff HEAD~1 HEAD -- README.md
git log --oneline -2
```
