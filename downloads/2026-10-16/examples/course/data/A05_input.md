# A05 · add는 현재 변경을 선택한다

처음 README를 add하면 짧은 상태의 왼쪽 A가 추가 준비를 나타냅니다. --staged는 선택한 상태와 마지막 커밋을 비교합니다. 첫 커밋 전에는 선택한 전체 내용을 볼 수 있습니다.

## 전체 시연 코드


```powershell
git add README.md
git status --short
git diff --staged
```
