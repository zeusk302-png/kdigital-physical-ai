# 나의 할 일 프로그램

## 목적
할 일을 추가하고 완료한 항목을 지우는 Python 프로그램입니다.

## 기능
1. 할 일 입력과 추가
2. 선택한 항목 완료
3. 남은 개수 표시

## 실행
Python 3와 tkinter가 필요합니다. 일반 Windows Python 설치에는 tkinter가 함께 제공됩니다. 빠진 환경에서는 강사와 설치 옵션을 확인하세요.

1. 저장소를 clone합니다.
2. main.py와 tracker.py가 같은 폴더에 있는지 확인합니다.
3. 그 폴더에서 터미널을 열고 아래를 실행합니다.

```text
python main.py
```

할 일 창이 열립니다. 추가 패키지는 없습니다. 종료하면 목록은 사라집니다. 파일 저장 기능은 아직 없습니다.

## 직접 시험하기
- 책 읽기 입력 → 추가 → 목록과 개수 확인
- 빈칸 입력 → 안내 확인
- 항목 선택 → 완료 → 개수 감소 확인

## 개선할 것
저장·복원 기능과 취소 기능을 추가할 수 있습니다. 실제 구현한 뒤 완성 기능으로 옮깁니다.
