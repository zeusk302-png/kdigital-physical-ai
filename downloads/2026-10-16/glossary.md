# Git/GitHub 쉬운 용어

| 용어 | 뜻 |
| --- | --- |
| 저장소 | 프로젝트 파일과 변경 기록을 함께 관리하는 단위 |
| 작업 영역 | 지금 편집하는 파일의 상태 |
| 스테이징 | 다음 커밋에 넣을 변경을 선택하는 단계 |
| 커밋 | 선택한 상태를 설명과 함께 남긴 기록 |
| diff | 두 상태에서 달라진 줄을 보여 주는 비교 |
| 브랜치 | 일련의 커밋을 가리키는 이름 |
| 원격 저장소 | 다른 경로에서 가져오거나 보낼 수 있는 저장소 |
| PR | 변경을 합치기 전에 제안·검토하는 GitHub의 요청 |
| 충돌 | 변경을 자동으로 합치기 어려워 사람이 결정해야 하는 상태 |

용어 이름만 외우기보다 활동의 값·파일·출력에서 무엇을 가리키는지 짚습니다. 파일 저장·스테이징·커밋·공유가 각각 어느 상태를 바꾸는지 구별합니다.
