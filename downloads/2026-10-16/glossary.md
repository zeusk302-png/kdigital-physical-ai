# 오늘 쓰는 말

## Git

내 PC에서 변경 이력을 관리하는 도구

## GitHub

저장소를 공유하고 검토하는 웹 서비스

## GitHub Desktop

Git 작업을 버튼으로 하는 앱

## repository

파일과 변경 이력을 관리하는 저장소

## README.md

처음 읽는 안내 문서

## Markdown

글의 제목·목록·링크를 적는 문법

## clone

저장소와 이력을 PC로 가져오기

## diff

바뀐 줄 비교

## commit

선택한 변경을 이력으로 기록

## push

내 커밋을 공유 저장소로 보내기

## fetch / pull

원격 변경 확인 / 가져와 반영

## branch

변경을 따로 작업하는 흐름

## PR

변경을 합치기 전에 비교하고 의견을 나누는 제안

## merge

두 변경 흐름을 합치기

## badge

문구·색·로고를 표시하는 작은 이미지

## GIF

여러 그림을 순서대로 표시하는 이미지 형식

## relative path

현재 문서 위치를 기준으로 적은 파일 경로
