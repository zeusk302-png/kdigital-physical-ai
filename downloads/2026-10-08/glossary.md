# 데이터 기초 용어 사전

낯선 말을 외우기보다 예와 비교하며 다시 찾아봅니다. **자료 전체의 구조, 값의 의미, 컴퓨터 자료형은 서로 다른 관점**입니다.

## 데이터와 맥락

| 말 | 쉬운 뜻 | 예 |
| --- | --- | --- |
| 데이터 | 관찰·측정·기록한 내용 | 온도 22.5, 주문 3건, 점검 사진 |
| 정보 | 맥락과 목적에 맞게 정리·해석하여 얻는 내용 | 같은 센서의 두 시각 값을 대조한 결과 |
| 맥락 | 값의 뜻을 이해하는 데 필요한 상황 | 누가·언제·어디서·무슨 단위로 기록했는지 |
| 출처 | 데이터가 나온 곳이나 수집 경로 | 센서 기록, 설문 응답, 주문 시스템 |
| 메타데이터 | 데이터를 설명하는 데이터 | 파일의 작성 시각, 온도 단위, 수집 장비 |
| 관찰 단위 | 기록 한 건이 무엇을 나타내는지 | 한 센서 자체인지, 센서의 한 시점 측정인지 |
| 변수·항목 | 대상마다 관찰하는 특성 | 부서·수량·온도. 코드의 변수라는 이름표와 문맥을 구별 |

## 자료 전체의 구조

| 말 | 쉬운 뜻 | 예와 주의 |
| --- | --- | --- |
| 정형 데이터 | 정해진 항목과 구조에 맞춘 데이터 | 열의 의미가 일정한 주문 표 |
| 반정형 데이터 | 키·태그·계층 등의 구조를 가지며 구성이 유연한 데이터 | 중첩 항목이 달라지는 JSON 기록 |
| 비정형 데이터 | 분석할 내용이 미리 정한 레코드·필드 구조로 정리되지 않은 데이터 | 자유 후기, 사진 속 장면, 음성 대화 |
| 정형화 | 필요한 내용을 공통 항목과 규칙으로 정리하기 | 점검 메모에서 장소·시각·온도를 추출해 표로 만들기 |
| 스키마 | 어떤 항목과 자료형·관계를 사용하는지 정한 구조 | 센서·시각·온도·상태의 항목 규칙 |
| 계층·중첩 | 묶음 안에 또 묶음이 들어 있는 구조 | 센서 소개 안에 측정 목록을 담기 |

JSON이라는 확장자만으로 정형성을 단정하지 않습니다. 고정 스키마를 적용할 수도 있습니다. 비정형은 저장 형식이 무규칙하다는 뜻이 아닙니다. 사진 속에 표가 보여도 그 장면과 바로 계산 가능한 셀 값은 구별합니다.

## 값의 의미에 따른 분류

| 말 | 쉬운 뜻 | 예와 주의 |
| --- | --- | --- |
| 범주형 | 어떤 부류인지를 나타내는 값 | 부서·색·등급 |
| 명목형 | 이름으로 구별하며 자연스러운 순서가 없는 범주 | 부서명, 사번, 색 |
| 순서형 | 순서는 있지만 간격까지 같다고 보장하지 않는 범주 | 낮음·보통·높음, 만족 등급 |
| 수치형 | 세거나 측정한 양을 나타내는 값 | 수량·길이·온도 |
| 이산형 | 구별되는 개수를 세는 값 | 주문 건수 0, 1, 2 |
| 연속형 | 범위 안의 양을 측정한 값 | 길이·시간·온도 |
| 측정 정밀도 | 얼마나 세밀하게 기록할 수 있는지 | 소수 첫째 자리까지 기록한 온도 |

사번 001은 숫자로 생겨도 수량이 아닙니다. 연속량인 온도를 소수 첫째 자리까지만 저장한다고 온도의 의미가 개수가 되는 것은 아닙니다. 자유 문장을 문자열로 저장했다고 문장 전체가 자동으로 하나의 명목 범주가 되는 것도 아닙니다.

## 컴퓨터의 값과 자료형

| 말 | 쉬운 뜻 | 예 |
| --- | --- | --- |
| 자료형 | 컴퓨터가 값을 표현하고 다루는 종류 | 문자열·정수·실수·불리언 |
| 문자열, str | 글자로 다루는 값 | "001", "22.5", "입구" |
| 정수, int | 소수 부분 없이 다루는 숫자 | 수량 3 |
| 실수, float | 소수점을 포함한 수 등을 표현하는 숫자형 | Python의 22.5 |
| 불리언, bool | 참·거짓 두 상태 | Python True/False, JSON true/false |
| None | Python에서 값 없음에 사용하는 값 | 온도를 확인하지 못한 예 |
| null | JSON에서 값 없음을 표현하는 값 | 미측정 온도 |
| 날짜·시간 | 시점을 나타내는 의미 | 문자열로 적은 "2026-10-08 10:00" |
| 형 변환 | 컴퓨터가 다루는 값의 종류를 바꾸기 | 계산할 수 있는 글자 "3"을 숫자 3으로 바꾸기 |

CSV에는 기본적으로 숫자·불리언을 선언하는 고유 자료형 체계가 없습니다. Python의 기본 CSV 읽기에서는 필드가 문자열로 들어옵니다. JSON은 number·string·boolean·null 등을 구별합니다. JSON number와 Python int/float가 같은 이름의 분류라고 설명하지 않습니다.

0은 숫자이고 False는 거짓이며 null은 값 없음입니다. "0"·"false"·"null"은 따옴표로 감싼 글자입니다. 비슷해 보여도 의미와 처리 방식이 다릅니다.

## 표와 값 묶음

| 말 | 쉬운 뜻 | 예 |
| --- | --- | --- |
| 행 | 표의 가로줄 | 한 시점의 센서 측정 |
| 열 | 같은 항목을 세로로 모은 줄 | 온도 열 |
| 셀 | 행과 열이 만나는 한 칸 | S01의 10:00 온도 22.5 |
| 헤더 | 열의 이름을 적은 부분 | sensor_id, temperature_c |
| 레코드 | 정한 관찰 단위의 기록 한 건 | S01의 10:00 점검 한 건 |
| 필드 | 기록 안의 항목 | 온도 항목 |
| 식별자 | 대상을 구별하는 이름 | S01 또는 사번 001 |
| 키 | 대상을 식별하는 기준 또는 값의 이름표 | 표의 식별 키와 딕셔너리의 키는 문맥을 구별 |
| 복합 식별 | 둘 이상의 항목을 함께 사용해 기록을 구별 | 센서 ID와 시각의 조합 |
| 데이터 사전 | 항목의 뜻·단위·형식·허용값·누락 처리를 적은 설명서 | temperature_c는 섭씨, 미측정은 빈칸/null |
| 리스트 | Python의 순서 있는 값 묶음 | [22.5, 24.0] |
| 인덱스 | 순서로 값을 찾는 번호 | 첫 번째 값의 번호는 0 |
| 딕셔너리 | Python에서 이름표와 값을 연결한 묶음 | {"sensor_id": "S01"} |
| 객체 | JSON의 이름표와 값 묶음 | {"temperature_c": 22.5} |
| 배열 | JSON의 순서 있는 값 묶음 | 두 측정 객체를 담은 목록 |

## CSV·JSON과 검수

| 말 | 쉬운 뜻 | 예와 주의 |
| --- | --- | --- |
| CSV | 표의 필드를 구분 기호로 적은 텍스트 표현 | 이번 수업은 쉼표 사용 |
| 구분자 | 필드 사이를 나누는 표시 | CSV의 쉼표 |
| 인용·quoting | 구분 기호가 들어 있는 값 등을 따옴표로 감싸기 | "창고, 안쪽"을 한 값으로 읽음 |
| JSON | 이름표·값·객체·배열 등을 규칙에 맞게 적는 텍스트 표현 | 센서 객체 안의 측정 배열 |
| 파싱 | 형식 규칙으로 글자를 읽어 구조로 바꾸기 | JSON을 객체와 배열로 읽기 |
| 구문 오류 | 적는 모양의 규칙이 깨진 상태 | 빠진 따옴표, JSON 마지막의 여분 쉼표 |
| 내용 오류 | 읽히지만 원문이나 업무 규칙과 다른 값 | 22.5를 225로 옮겨 적음 |
| 검수 | 원문·규칙·결과물을 대조하는 일 | 건수·단위·중복·자료형·누락 확인 |
| 보류 | 근거가 없어 값을 확정하지 않는 상태 | 미측정 값을 임의로 채우지 않고 확인 요청 |

## 파일과 코드를 다룰 때

| 말 | 쉬운 뜻 | 예 |
| --- | --- | --- |
| 파일·폴더 | 저장한 내용 한 묶음·그것을 모은 곳 | .csv 파일과 data 폴더 |
| 확장자 | 파일 이름 끝의 형식 표시 | .csv, .json, .py |
| 경로 | 파일을 찾는 주소 | foundations/data/ 안의 파일 |
| 편집기 | 내용을 읽고 바꾸는 프로그램 | 텍스트 편집기 |
| 터미널 | 명령을 글자로 입력하고 결과를 읽는 창 | python 실행 명령 |
| 저장·실행 | 바꾼 내용을 남김·코드의 지시를 수행함 | 저장 후 같은 작업본을 실행 |
| 인코딩·UTF-8 | 글자를 저장하고 읽는 약속·이번 자료의 약속 | 한글 장소를 보존 |
| 코드의 변수 | 값을 가리키도록 붙인 이름 | temperature = 22.5 |
| print | 전달한 값을 화면에 보여 주는 작업 | print(temperature) |
| type | 값의 Python 자료형을 확인하는 작업 | type(temperature) |
| 주석 | 사람이 읽도록 코드 옆에 적은 설명 | # 뒤의 내용 |

괄호 ()는 작업에 전달할 값, 대괄호 []는 목록 또는 값 선택, 중괄호 {}는 이름표 묶음 등에 쓰입니다. 같은 기호도 사용하는 문맥이 다르므로 완성 예와 출력으로 확인합니다. 오류가 나면 바꾼 부분·파일 경로·기대 결과와 실제 메시지를 함께 기록합니다.
