# 데이터 기초 · 적용과 설명 평가 초안

이 평가는 코딩 경험이 전혀 없는 비전공자의 학습을 돕는 확인 기준입니다. 공식 수료·채용 평가 기준이 아닙니다. **확정 운영은 50분×6교시·수업 300분이며, 실제 소요시간과 학습 효과는 리허설 전입니다.**

학생은 용어를 맞추는 데 그치지 않고 자료의 근거를 보고 분류 이유와 표현 선택을 설명합니다. 개인 Python 설치·실행 여부만으로 이해도를 판단하지 않습니다. 실행 환경이 없으면 출력 예측과 실제 강사 실행 비교를 기록합니다. 데이터 작성·수정·검수는 학생이 직접 수행하며, PC 미준비 시 같은 원문과 기호를 종이에 씁니다.

## 다른 사례로 연습하기

아래 여섯 문제는 추가 복습용입니다. 풀이를 보기 전에 답과 그렇게 생각한 이유를 적으세요. 프로그램 설치 여부와 별개로 내용을 이해했는지 확인하는 문제입니다.

### 문제 1 · 냉장 창고 기록에서 사실과 판단 나누기

복습·도전: 14:00의 작업장 기록은 A구역 70, B구역 40입니다. 소음 점검 기준은 각 구역 65데시벨 이하라고 별도로 주어졌습니다. 아직 단위 확인 전인 기록으로 가능한 말 한 문장, 확인 후 각 구역 판정 두 문장, 더 물을 질문 한 문장을 작성하세요.

**정답·해설:** 단위 확인 전에는 숫자 기록 두 개가 있다는 사실만 말합니다. 데시벨 기록임을 확인하면 A는 기준 초과, B는 기준 이내입니다. 두 구역의 평균 55를 근거로 모두 정상이라고 쓰면 개별 기준을 평균 기준으로 바꾼 오답입니다. 시각과 측정 방법도 확인해야 비교 조건을 판단할 수 있습니다.

### 문제 2 · 숫자 코드와 실제 수량을 구별하기

복습·도전: 주차 기록의 차량번호 “0032”, 층 등급 “상/중/하”, 입차횟수 4, 체류시간 2.25시간을 세 분류 축으로 설명하는 네 행의 표를 새로 만드세요. 층 등급은 이번 표에서 순서가 있다고 명시합니다.

**정답·해설:** 모든 행의 구조는 고정 표 기준 정형입니다. 차량번호는 명목·문자열, 층 등급은 순서·문자열, 횟수는 이산 수치·정수, 체류시간은 연속 수치·실수입니다. 차량번호를 수량으로 분류하면 식별 목적을 놓친 것입니다. 층 등급의 평균을 내면 등급 사이 간격이 같다는 확인되지 않은 가정이 생깁니다.

### 문제 3 · 주문 한 건과 주문 품목 한 줄의 차이

복습·도전: 교육 신청 R01에 Python과 Git, 신청 R02에 Python이 포함되었습니다. 한 행을 신청 과목으로 정하고 신청번호·과목코드 두 칸으로 키를 설계하세요. 전체 행 수, 신청 건수, Python 신청 과목 수를 각각 쓰세요.

**정답·해설:** 세 행은 R01/PY, R01/GIT, R02/PY입니다. 조합 키를 쓰며 행 수 3, 신청 건수 2, Python 수 2입니다. 신청번호만 키로 쓰면 R01의 두 과목을 구별하지 못합니다. 과목코드만 키로 쓰면 서로 다른 사람의 Python 신청을 합쳐 버립니다.

### 문제 4 · CSV의 구분자와 내용 안 쉼표 읽기

복습·도전: 책 이름은 ‘Python, 처음부터’, 가격 15000, 상품번호 “0007”입니다. book,price,product_id 세 열의 헤더와 데이터 한 줄을 직접 쓰고 각 칸의 시작·끝을 표시하세요. Python 코드는 작성하지 않습니다.

**정답·해설:** 헤더는 book,price,product_id, 데이터는 "Python, 처음부터",15000,0007입니다. 제목의 쉼표는 따옴표 안이라 내용입니다. CSV의 0007은 텍스트 원문을 보존하되 스프레드시트에서 자동 숫자 변환될 수 있으므로 식별자 열을 텍스트로 가져오는 조건도 확인합니다. 따옴표를 무조건 넣으면 어떤 프로그램에서도 앞 0이 보존된다는 주장은 오답입니다.

### 문제 5 · JSON의 없다는 뜻과 꺼졌다는 뜻

복습·도전: 대여함 L03은 잠겨 있음, 물품 수량은 미확인, 비고는 작성자가 의도적으로 빈 문장으로 남겼습니다. locker_id,locked,quantity,note 네 키의 JSON 객체를 쓰세요. 잠김은 true로 약속합니다.

**정답·해설:** 정답은 {"locker_id":"L03","locked":true,"quantity":null,"note":""}입니다. true는 상태, null은 미확인 수량, 빈 문자열은 알려진 빈 글입니다. quantity를 0으로 쓰면 미확인을 실제 0개로 바꾸는 오답이며 note를 null로 쓰면 의도적인 빈 문장이라는 원문을 잃습니다.

### 문제 6 · 목표에 맞춰 필요한 데이터만 설계하기

복습·도전: 배터리 점검에서 E01의 충전율 80%, E02는 미확인, E03은 0%입니다. 20% 미만을 충전 대상으로 정합니다. 세 기록의 판정과 두 파일 형식에서 미확인을 나타낼 약속, 원자료를 확인할 후속 질문을 작성하세요.

**정답·해설:** E01은 대상 아님, E02는 보류, E03은 대상입니다. CSV의 빈칸은 사전에서 미확인으로, JSON의 null도 동일 규칙으로 정합니다. E02를 0%로 적으면 확인되지 않은 충전 대상이 생깁니다. 단위와 측정시각·누락 이유를 물어야 비교 가능한 기록인지 판단할 수 있습니다.
