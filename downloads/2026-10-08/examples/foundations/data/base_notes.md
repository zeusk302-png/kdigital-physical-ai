# 현장 점검 메모 6건 · A01/A03 입력

가상 실습장의 기록이다. 실제 장비 측정값이나 개인정보가 아니다. 아래 메모 번호 순서대로 한 표에 옮긴다. 위치나 수치를 추정해서 덧붙이지 않는다.

1. 2026-10-08 오전 10:00, 입구 장치 S01. 섭씨 22.5도. 가동 중.
2. 창고 / S02 / 24.0 ℃ / 2026-10-08 10:00 / 작동 true.
3. 실습실에서 10월 8일 10:00에 적음(2026년). S03, 온도 23.5, active=true.
4. 2026-10-08 10:00 복도 S04. 온도 21.0도. 장치 가동 표시 false.
5. S01, 입구, 2026-10-08 10:05, 22.8 ℃, 가동 true.
6. 2026-10-08 10:05 / 창고 S02 / 온도 미측정 / 가동 표시는 true.

작성자의 설명: 가동 표시는 측정 기록에 함께 적힌 상태다. false여도 이미 적혀 있는 온도를 임의로 지우지 않는다. 모든 온도 단위는 섭씨다. 날짜·시각은 메모에 적힌 값을 사용한다.
