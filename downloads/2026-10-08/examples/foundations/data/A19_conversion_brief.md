# A19 · 뜻을 보존해 변환하고 기호 복구

csv_to_json.csv의 두 행을 JSON 배열로 직접 바꾼다. 첫 기록 S01 온도 22.8, 둘째 기록 S02 온도 빈칸이다. 날짜는 2026-10-08, 시각은 모두 10:05다. 빈 온도는 null, 가동 상태는 true 불리언으로 표현한다.

별도의 json_broken_1.json과 json_broken_2.json은 S01 / 입구 / 22.5 / 2026-10-08 10:00 / true의 같은 기록을 표현하려는 오류 파일이다. 값은 유지하고 잘못된 기호만 고친다. 두 복구 과제의 기록과 변환 과제의 기록은 다르다.
