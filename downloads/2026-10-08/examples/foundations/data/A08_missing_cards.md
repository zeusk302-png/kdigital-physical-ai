# A08 · 같은 빈 상태일까

| 카드 | 저장 예 | 원문에서 확인한 뜻 |
| --- | --- | --- |
| 1 | JSON number `0` | 온도를 실제로 0℃로 측정했다. |
| 2 | JSON boolean `false` | 장치가 가동하지 않는다고 기록했다. |
| 3 | JSON string `"0"` | 원문 숫자 글자 0을 문자열로 저장했다. |
| 4 | JSON `null` | 온도를 측정하지 않아 값이 없다. |
| 5 | JSON string `""` | 담당자가 빈 문자열을 보냈다. 업무상 뜻은 아직 확인하지 않았다. |
| 6 | CSV 온도 빈칸 | 이번 데이터 사전에서는 미측정을 뜻한다. |

| 표현 도구 | 이번 수업에서 값 없음 | 참·거짓 |
| --- | --- | --- |
| CSV | 온도 필드를 비워 둠. 파일 자체가 뜻을 정하지 않으므로 사전 필요 | true/false라는 글자 |
| JSON | null | true/false 불리언 |
| Python | None | True/False 불리언 |

빈 문자열, 누락된 키, 미측정, 실제 0을 무조건 같은 뜻으로 합치지 않는다. 원문과 규칙으로 확인한다.
