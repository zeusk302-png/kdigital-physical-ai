# A04 · 같은 관찰을 다른 모습으로

원문: “2026-10-08 오전 10:00, 입구 장치 S01에서 22.5℃를 읽었다. 장치는 가동 중이었다. 바로 옆 문이 잠깐 열렸지만 온도에 영향을 줬는지는 모른다.”

공통 표 항목: sensor_id / location / temperature_c / measured_at / active

키와 값 표현의 시작: `sensor_id: S01`

할 일: 다섯 항목 표 한 행과 키·값 다섯 쌍을 직접 쓴다. 원문 중 이 표에 들어가지 않은 맥락 한 가지와, 이를 보존할 별도 메모 방법을 제안한다. 문이 열렸다는 관찰을 온도 변화의 원인이라고 단정하지 않는다.
