# 새 점검 자료 정리 의뢰

먼저 입력의 구조와 의미를 분류하고 공통 항목 사전을 작성한다. final_notes.md의 순서를 유지해 다음 결과를 만든다.

- 다섯 항목의 의미적 종류·저장 자료형·단위·누락 규칙·기록 구별 기준을 적은 사전.
- sensor_id,location,temperature_c,measured_at,active 순서의 CSV: 데이터 여섯 행.
- 메모 첫째와 셋째 기록만 넣은 JSON 배열: 객체 두 개, 객체마다 다섯 키.
- 모르는 값과 후속 확인을 적은 짧은 이슈 기록.

미측정은 CSV 온도 빈칸, JSON null로 보존한다. 실제 측정 0.0과 false도 그대로 남긴다. 복잡한 코드를 새로 작성할 필요는 없다. 앞서 쓴 빈 표·CSV·JSON 양식을 사용한다.
