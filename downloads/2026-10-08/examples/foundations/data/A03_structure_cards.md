# A03 · 구조를 판단하는 카드 여덟 개

분류는 이 자료가 현재 어떤 모습으로 제공되는지와 분석 목적을 함께 본다. 확장자는 결론의 근거가 아니다.

1. 모든 주문이 주문번호·상품·수량의 같은 세 열을 가진 표. 각 열의 뜻과 빈값 규칙이 고정되어 있다.
2. 설비마다 다른 키와 선택 항목을 가진 JSON 기록. 키·배열·계층은 있으나 공통 필수 항목은 아직 정하지 않았다.
3. 같은 다섯 필드를 같은 자료형으로 반드시 기록하도록 스키마 검사하는 JSON 센서 기록.
4. 점검자가 길이와 표현을 자유롭게 쓴 메모 본문. 문장마다 등장하는 항목도 다르다.
5. 주문 표를 촬영한 사진 원본이라는 설명 카드. 보이는 내용에는 행과 열이 있지만, 분석 도구가 바로 읽을 셀 값은 아직 추출하지 않았다.
6. 상품명 태그와 선택 사양 태그가 있고 중첩 구조를 갖는 XML 문서. 상품마다 선택 태그가 다르다.
7. 같은 여섯 센서 기록을 헤더 다섯 개 아래에 맞춰 쓴 CSV. 열의 뜻·단위·허용값이 고정되어 있다.
8. 고객의 말소리를 녹음한 음성 파일이라는 설명 카드. 발화 내용은 아직 항목별로 정리하지 않았다.

각 카드에 정형·반정형·비정형 중 적절한 구조 판단과 그 근거를 쓴다. 판단 관점이나 조건이 필요하면 함께 적는다. 5와 8은 실제 미디어 분석 과제가 아니라 제공 형태를 생각하는 설명 카드다.
