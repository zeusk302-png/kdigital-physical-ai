# 데이터 기초 실습 묶음

코딩 경험이 없는 비전공자를 위한 자료입니다. 데이터의 의미·형태·통계적 종류·저장 자료형·구조를 먼저 배우고, CSV와 JSON을 그 표현으로 연결합니다. 모든 업무 값은 합성 자료입니다.

## 처음 열기

1. ZIP을 일반 폴더에 풉니다. data·work·code 폴더의 상대 위치를 유지합니다.
2. [24활동 안내](activity-guide.md)를 A01부터 순서대로 엽니다. 설명·비교 시연·직접 적용·풀이를 포함한 활동입니다.
3. data의 입력을 읽고 work의 답칸과 빈 파일에 직접 작성합니다. 원본을 고치지 않습니다.
4. CSV·JSON은 웹 편집기 또는 텍스트 편집기에서 직접 작성하고 UTF-8로 저장합니다. 웹을 쓸 수 없어도 텍스트 편집기와 종이로 같은 작업을 할 수 있습니다.
5. [제출·확인 기준](assessment.md)을 보고 설명의 근거와 실제 확인 방법을 남깁니다.

## 폴더와 학습 순서

- data: 개념 분류 카드, 입력 원문, 데이터 사전, 비교 예, 고의 오류 파일. 사진·음성은 실제 미디어 대신 제공 형태를 생각하는 설명 카드입니다.
- work: 직접 채울 답칸과 표·CSV·JSON 시작 양식. 빈 객체·배열이나 헤더만 있는 CSV는 작업 전 상태입니다.
- code: A07 자료형, A11 리스트·딕셔너리, A16 CSV 읽기, A20 JSON 읽기의 완성 코드. [모든 줄 해설과 실제 전체 출력](code/line-guide.md)을 먼저 읽습니다.

앞의 12활동은 데이터의 의미와 세 분류 축, 관찰 단위·키·스키마·목록과 계층입니다. 뒤의 12활동은 CSV·JSON 표현과 새 업무 자료의 분류·설계·검수입니다. 구조의 정도, 통계적 의미, 컴퓨터 저장 종류를 한 분류처럼 섞지 않습니다.

## Python 실행은 준비된 PC에서

웹 자료 화면은 Python을 실행하지 않습니다. 개인 환경이 준비되지 않았다면 예상 출력을 직접 적고 강사가 실제로 실행한 결과와 비교합니다. 코드 수정안과 데이터 원문은 학생이 직접 씁니다.

터미널의 현재 위치가 이 foundations 폴더이면 다음과 같이 실행합니다.

```text
python -X utf8 code/A07_types.py
python -X utf8 code/A11_structures.py
python -X utf8 code/A16_read_csv.py
python -X utf8 code/A20_read_json.py
```

수정한 작업본은 예를 들어 `python -X utf8 work/A07_types.py`로 실행합니다. code와 work는 다른 파일입니다. Windows에서 py만 준비되어 있다면 강사 안내에 따라 `py -3 -X utf8 work/A07_types.py`처럼 사용합니다. 설치를 혼자 해결할 필요는 없습니다. csv·json·pathlib는 Python 표준 모듈이며 별도 유료 서비스·로그인·장비가 필요하지 않습니다.

## 내용 규칙

미측정은 이 사전의 CSV 온도 빈칸 또는 JSON null로 보존합니다. 0은 실제 측정값이고 false는 가동 상태입니다. 모르는 실제값을 추측해서 채우지 않습니다. 온도 0~50은 이 수업의 입력 점검 규칙이며 실제 하드웨어의 안전 한계가 아닙니다. 근거 없는 값을 받으면 원문을 남기고 질문합니다.

## 제작 상태와 확인 범위

점심 60분은 별도입니다.

원본 Python 네 개는 제작용 Python에서 실제 실행해 전체 출력과 비교했습니다. 코드 폴더와 다른 현재 위치에서도 입력 파일을 찾는 것을 확인했습니다. 개인 PC·실제 강의실·실제 센서·웹의 Python 실행은 검증한 범위가 아닙니다. 추가로 24활동의 입력·작업·풀이 파일 경로와 15·60·360분 배정 합계, CSV·JSON의 기록 수·자료형·미측정 표현, 고의 오류와 수정 결과를 자동 검사했습니다. 원본 코드 네 개와 작업 복사본 네 개, 지시된 값 수정 두 가지의 실제 출력도 기대값과 일치했습니다. 이 검사는 수업 시간이나 학습 효과를 증명하지 않습니다. 설치 환경이 다르면 강사에게 실행한 파일 경로와 실제 오류를 전달합니다.


## Windows · 선택 Python 실행 위치 확인

제작 가정: Windows 탐색기와 PowerShell입니다. Python 실행은 준비된 PC에서만 합니다.

ZIP을 모두 추출한 뒤 `foundations` 안의 data·code·work가 보이는 폴더를 엽니다. 탐색기 주소 표시줄에 `powershell`을 입력하고 Enter를 누릅니다. 새 창에서 한 줄씩 실행합니다.

```powershell
Get-Location
Get-ChildItem -Directory
Test-Path .\code\A07_types.py
python -X utf8 code/A07_types.py
```

경로 끝은 foundations, 폴더 목록은 data·code·work, 파일 확인은 True여야 합니다. 정상 출력은 code/line-guide.md의 A07 전체 출력과 대조합니다. False 또는 파일 없음이면 탐색기에서 실제 foundations 위치를 찾아 같은 순서로 창을 다시 엽니다. python을 찾지 못하면 강사에게 환경을 확인받고 제공 출력 비교를 진행합니다. 개인 실행은 미완료로 기록합니다. 다른 활동도 같은 폴더에서 명령을 입력합니다.
