# 전자회로·ESP32 · Python으로 만드는 RaspTank 명령 프로젝트

과목명은 원본을 유지하고 실제 실습은 사용자 지정 Adeept RaspTank ADR013 Raspberry Pi 로봇으로 진행합니다. 오늘은 부품·회로 역할과 PC/Pi 실행 위치를 구별하고, Python의 명령 검사·주행 어댑터·정지·상태·시퀀스를 연결합니다. 초록색/보라색 확장보드는 제조사 저장소와 함수 계약이 달라 분기합니다. 서보는 모의 명령 설계와 공식 보정 준비를 진행하며, 미확인 실물 범위를 만들어 자동 구동하지 않습니다.

학생 시작: [R01](lessons/R01.md) → kit/README.md → sequence.json. 설치가 어려운 학생은 짝 PC 또는 강사 모의 로그로 명령 설계·오류 설명을 계속합니다. 필수는 PC dryrun과 입력·중단 검사, 준비된 장치의 실물 시연은 별도로 관찰합니다. 제작 가정: PC Python 3.10 이상, 텍스트 편집기, 강사의 사전 조립/OS 준비 시간이 필요합니다. 실제 Pi 모델·보드 리비전·OS·전원·보정은 현장 확인표로 관리합니다.
