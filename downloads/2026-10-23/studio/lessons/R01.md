# R01. 오늘 만들 로봇 프로그램과 작업 폴더

로봇에 “조금 앞으로 가라”라고 말하는 것과 바퀴가 실제로 도는 것은 여러 단계를 거칩니다. 사람이 원하는 동작을 글자로 적고, Python이 그 글자를 해석하고, 확장보드가 모터에 출력을 내보냅니다. 오늘은 이 사이의 관계를 직접 만듭니다. 과정표의 과목명은 전자회로·ESP32로 유지하지만, 사용자가 지정한 실습 제품은 Adeept RaspTank ADR013 Raspberry Pi 기반 키트입니다. ESP32용 Arduino 업로드 실습으로 진행하지 않습니다. Raspberry Pi는 운영체제와 파일을 갖는 작은 컴퓨터이고 모터 드라이버는 전력 출력을 담당하는 부품입니다. 둘의 역할을 말로 구별하는 것이 첫 목표입니다.

먼저 PC에서 압축을 풀고 kit 폴더를 엽니다. 폴더는 관련 파일을 넣는 상자, 파일은 내용을 저장하는 한 묶음입니다. `sequence.json`의 점 뒤 json은 데이터 표현 형식을 알려 주는 확장자입니다. Windows 탐색기에서 파일 확장명을 표시하고 `sequence.json.txt`가 되지 않았는지 확인합니다. 편집기의 저장과 터미널의 실행은 별개입니다. 파일을 수정한 뒤 저장하지 않으면 실행은 이전 내용을 읽습니다. PC 터미널에서 `cd`로 kit 폴더로 이동하고 `python --version`을 입력합니다. 폴더 위치를 모르겠으면 탐색기 주소 표시줄을 보고, 터미널의 현재 위치와 대조합니다.

```text
kit/
  README.md          사람이 읽는 시작 안내
  AGENTS.md          AI가 수정할 때 따르는 규칙
  sequence.json      학생이 바꿀 동작 목록
  robotlab/          Python 프로그램 파일
  docs/              장치 준비와 시험 기록
  tests/             자동 확인 코드
```

강사가 `python -m robotlab sequence.json`을 시연합니다. `python`은 실행할 프로그램, `-m`은 뒤 이름의 모듈을 실행하라는 옵션, `robotlab`은 제공 폴더 이름, 마지막은 읽을 데이터 파일입니다. 예상 화면에는 `mode: dryrun`, `status: completed`, `completed: 3`이 나옵니다. 이는 세 명령을 모의로 처리했다는 뜻이며 로봇 이동 관찰 결과가 아닙니다. 학생은 같은 명령을 따라 입력하고 출력의 mode 값을 자기 말로 풀이합니다. 모의 실행은 보드·로그인·인터넷 없이 가능합니다.

필수 활동은 새 파일 `my-sequence.json`을 복사해 만들고, 첫 명령의 seconds만 0.3에서 0.5로 바꾸어 저장한 다음 그 파일 이름으로 실행하는 것입니다. 실행 전에 “명령 개수는 그대로이고 기다리는 시간만 달라진다”라고 예상합니다. 실제 출력에서 명령 개수와 입력값을 확인합니다. 이어 잘못된 파일 이름으로 실행해 파일을 못 찾는 오류를 한 번 읽고 정확한 이름으로 복구합니다. 오류는 컴퓨터 고장이라는 뜻이 아니라 다음에 확인할 위치를 알려 주는 단서입니다.

짝 활동에서는 한 학생이 PC 역할, 다른 학생이 로봇 역할을 맡아 종이 명령을 전달합니다. “빨리 가”처럼 애매한 지시와 action·speed·seconds가 있는 지시를 비교합니다. 종이 활동을 마치면 명령, 실행기, 어댑터, 실제 출력이라는 네 부분을 그림으로 연결합니다. 추가 도전은 README에서 실제 장치 경로를 찾아 모의 경로와 다른 준비 사항 세 개를 표시하는 것입니다. 강사는 모든 PC에서 Python이 준비되었는지와 학생이 명령 구조를 이해했는지를 별도 기록합니다. 설치가 안 된 학생에게는 짝 PC의 로그와 출력 예를 제공하여 개념 활동을 계속하게 합니다.
