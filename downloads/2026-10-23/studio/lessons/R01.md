# R01 장비 구분·Arduino IDE·보드 업로드


## 준비와 실제 장비

오늘의 보드는 XIAO ESP32-S3 Sense, 회로 부품은 SZH-EK013, 거리 센서는 HC-SR04 Ultra01+, 자세 센서는 MPU6050입니다. 키트의 UNO는 XIAO와 다른 보드입니다. 라즈봇V2는 Raspberry Pi 5 기반 로봇이며 ESP32 펌웨어를 그대로 올리는 장치가 아닙니다. 각 보드가 어느 케이블과 프로그램으로 연결되는지 먼저 표시합니다.

## Arduino IDE 설치·보드 등록

[Arduino 공식 IDE](https://www.arduino.cc/en/software/)를 설치하고 실행합니다. File → Preferences의 Additional boards manager URLs에 Espressif 공식 주소 https://espressif.github.io/arduino-esp32/package_esp32_index.json 을 추가합니다. 기존 주소는 지우지 말고 줄을 추가합니다. Boards Manager에서 ‘esp32 by Espressif Systems’를 설치합니다. Tools → Board에서 XIAO_ESP32S3를 고릅니다. 보드 이름이 없으면 설치한 패키지와 검색어를 확인합니다. [Seeed 공식 시작 안내](https://wiki.seeedstudio.com/xiao_esp32s3_getting_started/)의 현재 메뉴도 함께 확인합니다.

데이터 전송이 가능한 USB 케이블로 연결하고 Tools → Port에서 연결 전후 달라진 COM 번호를 선택합니다. Tools → USB CDC On Boot는 Enabled로 둡니다. firmware/00_hello/00_hello.ino를 열고 Verify(체크)로 컴파일, Upload(화살표)로 전송합니다. Serial Monitor를 115200으로 열면 1초마다 hello와 가동시간이 보여야 합니다. Verify 성공과 업로드 성공, 실제 출력 확인은 세 단계입니다.

업로드 실패는 케이블·포트·다른 앱 사용을 먼저 확인합니다. 공식 안내의 BOOT 버튼 절차는 XIAO 모델이 맞을 때 적용합니다. 포트가 다시 생기면 바뀐 번호를 고릅니다. 반도체 칩의 GPIO 번호와 보드에 인쇄된 D 번호를 혼동하지 않습니다.

## PC 파일 준비

수업 ZIP을 풀고 kit를 VS Code로 엽니다. 펌웨어는 Arduino IDE, pc 폴더의 Python은 PC에서 실행합니다. Arduino IDE의 C++ 스케치를 Python 터미널에서 실행하지 않습니다. Python 3.12가 있다면 kit 터미널에서 다음을 실행합니다.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```


## 주석 예제 원본

```cpp
// Arduino IDE의 보드 XIAO_ESP32S3, 해당 USB 포트를 선택합니다.
// USB CDC On Boot를 Enabled로 선택하고 업로드 후 115200으로 모니터를 엽니다.
unsigned long previous = 0;
void setup() { Serial.begin(115200); }
void loop() {
  unsigned long now = millis();  // 전원이 켜진 뒤 지난 밀리초입니다.
  if (now - previous >= 1000) {
    previous = now;
    Serial.print("hello uptime_ms=");
    Serial.println(now);  // println은 줄 끝을 붙여 다음 기록과 구별합니다.
  }
}

```
