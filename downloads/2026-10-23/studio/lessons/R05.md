# R05 MPU6050·I2C·정지 기준과 변화


MPU6050은 가속도와 각속도를 읽는 센서입니다. I2C는 전원·GND 외에 SDA(데이터)와 SCL(시계) 두 신호로 통신합니다. XIAO의 SDA는 D4(GPIO5), SCL은 D5(GPIO6)입니다. 모듈 VCC 허용 전압과 풀업 저항이 어느 전압에 연결되는지 확인하고 XIAO 신호가 3.3V 범위를 넘지 않게 합니다.

Arduino IDE Library Manager에서 Adafruit MPU6050과 제안되는 의존 라이브러리를 설치합니다. firmware/03_motion은 주소 0x68을 사용합니다. 응답이 없으면 전원·공통 GND·SDA/SCL·AD0와 주소를 순서대로 확인합니다. [Adafruit API](https://adafruit.github.io/Adafruit_MPU6050/html/class_adafruit___m_p_u6050.html)의 getEvent로 acceleration·gyro·temperature를 얻습니다.

## 실제 값 읽기

수평 책상 위에서 정지 값을 기록한 뒤 각 축을 천천히 기울입니다. 가속도 단위는 m/s²이고 중력 성분이 포함됩니다. 각속도는 rad/s이며 각도 도 단위와 같지 않습니다. 예제는 x축 가속도를 전송하므로 화면 제목도 accel_x_m_s2입니다. 이를 곧바로 x축 각도나 이동 거리라고 부르지 않습니다.

## 독립 기능

처음 20회 정지 측정의 평균을 기준으로 편차를 계산하고 기준보다 크게 변할 때 한 번 알립니다. 보정 중 흔들렸다면 다시 보정하게 합니다. 기준선·단위·알림 기준·해제 조건을 설명합니다. 거리 센서와 MPU6050의 전원·핀을 동시에 연결하기 전에 각각 따로 정상 동작시킵니다.


## 주석 예제 원본

```cpp
// 모듈의 전원 허용값·풀업 전압을 먼저 확인합니다. I2C 신호는 3.3V 기준입니다.
// SDA→D4(GPIO5), SCL→D5(GPIO6), GND 공통. 전원은 확인한 모듈 사양에 맞춥니다.
// Library Manager: Adafruit MPU6050 및 의존 라이브러리를 설치합니다.
#include <Wire.h>
#include <Adafruit_MPU6050.h>
#include <Adafruit_Sensor.h>
Adafruit_MPU6050 mpu;
bool ready=false;
unsigned long previous=0,sequence=0;
void setup(){
 Serial.begin(115200);
 Wire.begin(D4,D5);
 ready=mpu.begin(0x68,&Wire);  // AD0 상태에 따라 주소가 다르면 스캐너로 확인합니다.
 if(ready){mpu.setAccelerometerRange(MPU6050_RANGE_2_G);}
}
void loop(){
 unsigned long now=millis();if(now-previous<200)return;previous=now;
 sensors_event_t acceleration,gyro,temperature;
 bool ok=ready && mpu.getEvent(&acceleration,&gyro,&temperature);
 Serial.print("{\"seq\":");Serial.print(sequence++);
 Serial.print(",\"uptime_ms\":");Serial.print(now);
 Serial.print(",\"kind\":\"accel_x_m_s2\",\"value\":");
 if(ok)Serial.print(acceleration.acceleration.x,3);else Serial.print("null");
 Serial.println(ok?",\"status\":\"normal\"}":",\"status\":\"fault\"}");
 // 가속도에는 중력이 포함됩니다. 이 값만 두 번 적분해 이동 거리라 부르지 않습니다.
}

```
