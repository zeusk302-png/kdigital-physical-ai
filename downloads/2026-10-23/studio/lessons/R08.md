# R08 개인 장치 기능·AI·Git·후속 연결


거리·자세 측정과 로봇은 각자 정상 동작부터 확보합니다. ESP32를 라즈봇 모터 보드에 임의 배선해 한꺼번에 묶지 않습니다. 공통 경로는 센서 → USB 시리얼 → PC 수집 → JSONL이며, 10/29에 같은 파일을 읽어 API → DB → 화면으로 연결합니다.

## 개인 기능

거리 알림의 단계 추가, 버튼으로 재설정, 정지 기준 보정, fault 표시 중 하나를 선택합니다. 입력·기억할 상태·출력·완료 조건을 적고 firmware와 pc 중 수정 위치를 결정합니다. 데이터 필드를 바꾸면 수집기의 검증도 맞춰야 하며 몰래 필드를 추가한 뒤 서버가 받지 않는 것을 네트워크 오류로 오해하지 않습니다.

## AI 요청

```text
AGENTS.md, firmware/02_distance와 pc/collect.py를 읽어.
센서 실패와 경고 표시를 분리하고 싶어.
보드·핀·분압·출력 필드는 유지해.
상태 전이와 수정 파일, 정상·경계·실패 시험을 먼저 제안해.
펌웨어 업로드·실물 동작과 PC 단위시험 결과를 구분해.
```

## Git과 제출

firmware·pc·tests·requirements·배선도·실행 안내를 포함합니다. runtime의 실제 측정·개인 장치 주소·인증 정보·.venv는 제외합니다. 배선 사진에서 개인 정보가 보이지 않는지 확인합니다. docs/hardware-check.md에 장비·배선·전압·업로드·실측·오류·자기 기능·아직 못 한 단계를 기록합니다.
