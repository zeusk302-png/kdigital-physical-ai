# R03 초음파 거리 측정·분압·시간초과


초음파 센서는 신호를 보낸 뒤 반사 신호가 돌아오기까지 걸린 시간으로 거리를 구합니다. 왕복이므로 시간×소리 속도를 2로 나눕니다. 단위와 시간초과를 함께 다뤄야 합니다.

## 배선

|HC-SR04|XIAO 쪽|
|---|---|
|VCC|5V 공급|
|GND|공통 GND|
|TRIG|D2(GPIO3)|
|ECHO|분압 후 D3(GPIO4)|

ECHO → 상단 1k옴 → D3와 만나는 접점 → 하단 2k옴 → GND입니다. 하단 2k옴은 1k옴 두 개 직렬로 만들 수 있습니다. 5V×2/(1+2)≈3.33V로 줄입니다. 공급 전압과 저항 값을 실제로 확인합니다. 필요한 저항이 없으면 XIAO에 Echo를 직결하지 말고 부품을 준비한 뒤 진행합니다. UNO에서 진행할 경우에는 UNO 전용 배선과 스케치 핀으로 별도 수정해야 합니다.

## 측정과 검증

firmware/02_distance를 업로드하고 Serial Monitor 115200에서 JSON 한 줄을 봅니다. 자로 잰 10·20·30cm에서 센서 앞 물체의 각도·재질을 바꿉니다. timeout이면 value:null과 status:fault가 나와야 하고 0cm로 보내지 않습니다. 정확하지 않은 원인을 코드만 탓하기 전에 반사면·범위·배선·전원을 확인합니다.

## 직접 작성

경고 켜짐은 20cm 미만, 해제는 25cm 초과입니다. 두 기준 사이에서는 이전 상태를 유지합니다. 이를 히스테리시스라고 부릅니다. 두 기준을 같게 했을 때 경계 흔들림과 비교합니다. 다음에는 fault일 때 정상 LED와 다른 표시를 만들고 이유를 적습니다.


## 주석 예제 원본

```cpp
// XIAO ESP32-S3 전용 예제입니다. UNO 핀 번호와 섞지 않습니다.
// HC-SR04 VCC→5V, GND→GND, TRIG→D2.
// ECHO→상단1k옴→D3 접점→하단2k옴→GND로 분압합니다.
// ECHO 5V를 XIAO GPIO에 바로 연결하지 않습니다.
const int LED_PIN=D0, TRIG_PIN=D2, ECHO_PIN=D3;
unsigned long previous=0, sequence=0;
bool warning=false;
void setup() {
  Serial.begin(115200);
  pinMode(LED_PIN,OUTPUT); pinMode(TRIG_PIN,OUTPUT); pinMode(ECHO_PIN,INPUT);
  digitalWrite(TRIG_PIN,LOW);
}
void loop() {
  unsigned long now=millis();
  if(now-previous<200)return;
  previous=now;
  digitalWrite(TRIG_PIN,LOW); delayMicroseconds(2);
  digitalWrite(TRIG_PIN,HIGH); delayMicroseconds(10); digitalWrite(TRIG_PIN,LOW);
  // 30ms 안에 응답이 없으면 0입니다. 무제한 기다리지 않습니다.
  unsigned long duration=pulseIn(ECHO_PIN,HIGH,30000UL);
  float cm=duration*0.0343f/2.0f;  // 소리의 왕복이므로 2로 나눕니다.
  bool valid=duration>0 && cm>=2.0f && cm<=400.0f;
  // 20cm 미만에서 켜고 25cm 초과에서 끕니다. 경계 깜박임을 줄입니다.
  if(valid) {
    if(cm<20)warning=true;
    else if(cm>25)warning=false;
  }
  digitalWrite(LED_PIN,valid && warning ? HIGH : LOW);
  // 센서 실패를 숫자 0cm로 보내지 않고 null과 fault 상태로 구별합니다.
  Serial.print("{\"seq\":");Serial.print(sequence++);
  Serial.print(",\"uptime_ms\":");Serial.print(now);
  Serial.print(",\"kind\":\"distance_cm\",\"value\":");
  if(valid)Serial.print(cm,2);else Serial.print("null");
  Serial.print(",\"status\":\"");
  Serial.print(!valid?"fault":warning?"warning":"normal");
  Serial.println("\"}");
}

```
