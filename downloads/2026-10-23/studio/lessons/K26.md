# 2핀 화염 소자 · 빛 변화와 모델 확인

[실물 사진과 한 단계씩 바뀌는 배선도 열기](../kit/guide/index.html?lab=K26#workbench)

![2핀 화염 소자 · 빛 변화와 모델 확인 전체 연결 위치](../kit/guide/diagrams/K26.svg)

그림을 확대하고 한 선씩 보려면 위 실습실을 여세요. 부품별 추가 준비 조건은 아래에서 먼저 확인합니다.

## 무엇을 하는 부품인가요?

판매처의 부품은 2핀 감지 소자입니다. 디지털 모듈의 VCC·GND·DO 세 핀을 가진 것처럼 연결하지 않습니다. 광트랜지스터형인지 광다이오드형인지에 따라 동작과 극성·회로가 달라집니다. 이름만 보고 임의로 전원을 넣지 않는 것도 부품 사용의 한 단계입니다.

## 준비와 방향

필요 부품: 2핀 화염 감지 소자, 고정저항. 실물 사진은 위 실습 화면에서 각각 확대할 수 있습니다.

부품 핀의 이름을 먼저 확인합니다. 모듈 그림은 핀 이름을 읽기 위한 펼친 그림이며, 실물 커넥터의 좌우 순서를 뜻하지 않습니다. 표시가 다른 부품은 연결 전에 해당 모델 핀표와 대조합니다.

**연결 전 확인:** 이 회로는 C·E가 확인되고 해당 전압을 허용하는 광트랜지스터일 때만 사용합니다. 상품 사진은 정확한 모델·극성을 제공하지 않으므로 현물 각인·공급사 자료 확인이 먼저입니다. 광다이오드형이나 미확인 소자는 식별 기록까지만 진행합니다. 불·라이터를 쓰지 않습니다.

## 부품을 놓으세요

1. **핀표가 확인된 광트랜지스터형만**: Collector C → E8, Emitter E → E12
2. **10kΩ**: 한쪽 → C8, 다른쪽 → C16

## 선을 한 개씩 연결하세요

| 순서 | 출발 | 도착 | 연결 이유 |
|---:|---|---|---|
| 1 | UNO 3V3 | A16 | 그림의 양 끝 이름을 확인하고 USB를 뺀 상태에서 연결합니다. |
| 2 | UNO A0 | A8 | 그림의 양 끝 이름을 확인하고 USB를 뺀 상태에서 연결합니다. |
| 3 | UNO GND | A12 | 그림의 양 끝 이름을 확인하고 USB를 뺀 상태에서 연결합니다. |

그림과 표는 같은 연결 데이터로 생성합니다. 선 색이 달라도 양 끝 이름이 같으면 같은 연결입니다. 한 단계를 완료한 뒤 다음으로 이동하고, 마지막에는 전체 연결표로 빠진 선을 확인합니다.

## 저장과 실행

Arduino IDE에서 새 스케치를 만들고 아래 코드를 붙여넣습니다. 파일은 `K26/K26.ino`로 저장합니다. 보드는 Arduino Uno, 포트는 실제 연결된 COM, 시리얼 모니터는 9600으로 맞춥니다. 검증 버튼은 코드의 문법을 검사하고, 업로드 버튼은 연결된 보드로 프로그램을 보냅니다.

이 예제는 추가 라이브러리 설치가 필요하지 않습니다.

```cpp
// 2핀 화염 소자 · 빛 변화와 모델 확인
// 보드: Arduino Uno / 시리얼 모니터: 9600 baud
// USB를 뽑고 배선한 뒤, 아래 연결표와 코드의 핀 번호를 대조하세요.

// setup()은 업로드·리셋 직후 한 번만 실행합니다.
void setup() {
  Serial.begin(9600); // PC에 값을 보여 줄 통신 속도입니다.
}
// loop()는 전원이 들어온 동안 계속 반복합니다.
void loop() {
  int value = analogRead(A0); // UNO는 입력 전압을 0~1023 값으로 읽습니다.
  Serial.print("infrared_raw=");
  Serial.println(value); // 숫자 뒤에서 줄을 바꿉니다.

  delay(200); // 값이 너무 빠르게 지나가지 않게 0.2초 기다립니다.
}

```

## 예상 결과와 직접 바꾸기

핀표·정격이 맞는 광트랜지스터형에서 적외선 광량에 따라 값이 변합니다.

불꽃 대신 적외선 리모컨을 눌러 가까이 댔을 때의 변화를 비교합니다. 변화가 작으면 센서 파장·샘플링도 함께 확인합니다.

바꾸기 전 예상과 바꾼 뒤 실제 결과를 나눠 적습니다. 실행하지 못했다면 이유와 다음 확인 항목을 적습니다. 예시 출력은 내 보드의 실제 측정 기록이 아니므로 자신의 값·사진으로 남깁니다.

## 잘 안될 때

반응이 없다고 불을 붙이거나 다리를 바꾸지 않습니다. 다른 광소자면 그 제조사 응용 회로로 바꿉니다.

코드에 적힌 핀과 연결표부터 비교합니다. 회로를 고칠 때는 USB와 외부 전원을 모두 분리합니다. 프로그램의 컴파일 성공과 실제 부품의 동작은 별도로 확인합니다. 고친 선·코드·결과를 함께 기록하면 다음에 같은 문제를 찾아낼 수 있습니다.
