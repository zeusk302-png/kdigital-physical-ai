# R02 브레드보드·저항·LED·버튼 입출력


회로는 전기가 지나갈 길입니다. 전원은 공급, GND는 기준과 돌아오는 길, 신호는 입력·출력 값입니다. 브레드보드는 같은 줄이 내부에서 연결되지만 전원 레일이 중간에 끊긴 제품도 있으므로 실제 연결 표시를 확인합니다. 배선은 전원을 끈 뒤 바꾸고 전원과 GND를 바로 연결하지 않습니다.

firmware/01_button을 엽니다. 외부 LED는 D0 → 330옴 저항 → 긴 다리, 짧은 다리 → GND로 연결합니다. 버튼은 D1과 GND 사이입니다. INPUT_PULLUP은 버튼을 누르지 않으면 HIGH가 되게 내부 저항을 사용하는 설정입니다. 따라서 pressed는 LOW일 때 참입니다.

## 직접 수행

누르면 켜짐 → 누르면 꺼짐 → 버튼을 눌렀다 놓을 때 상태 유지 순서로 변경합니다. 마지막 기능은 이전 버튼 상태를 기억해야 합니다. 접점이 순간 흔들리는 바운스를 먼저 관찰한 뒤 일정 시간 안정된 입력만 채택하는 방식으로 확장합니다. 긴 delay로 모든 입력을 멈추는 해결과 차이를 설명합니다.

LED가 안 켜지면 방향·저항·D0·GND를 한 번에 하나씩 확인합니다. 잘못된 회로를 일부러 단락시키는 실습은 하지 않습니다. 오류 실습은 코드의 HIGH/LOW 반전이나 잘못된 핀 설정으로 재현합니다.


## 주석 예제 원본

```cpp
// D0 → 저항 330옴 → LED 긴 다리, LED 짧은 다리 → GND.
// D1 → 버튼 → GND. 내부 풀업이므로 안 누름 HIGH, 누름 LOW입니다.
const int LED_PIN = D0;
const int BUTTON_PIN = D1;
void setup() {
  Serial.begin(115200);
  pinMode(LED_PIN, OUTPUT);
  pinMode(BUTTON_PIN, INPUT_PULLUP);
}
void loop() {
  bool pressed = digitalRead(BUTTON_PIN) == LOW;
  digitalWrite(LED_PIN, pressed ? HIGH : LOW);
  Serial.println(pressed ? "pressed" : "released");
  delay(100);  // 첫 예제의 관찰 간격입니다. 후속 센서는 millis로 주기를 관리합니다.
}

```
