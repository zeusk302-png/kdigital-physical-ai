# R02. 부품·회로·보드 리비전과 조립 준비

전자회로는 전기가 이동할 경로와 부품의 연결입니다. 전원은 에너지를 주고, 제어 신호는 어떤 동작을 할지 전달합니다. GPIO 신호선에 모터 전원을 직접 연결해도 된다는 뜻이 아닙니다. RaspTank에서는 Raspberry Pi, 확장보드, 모터, 서보, 센서, 배선의 역할을 나누어 봅니다. DC 모터는 계속 회전하는 동작에 쓰이고 서보는 명령한 위치를 향해 움직이는 장치입니다. 서보의 명령 숫자가 곧 실제 관절 각도라고 단정하지 않습니다. 기어와 링크를 어떻게 조립했는지에 따라 부딪히는 위치가 달라집니다.

오늘의 장비 확인은 사용자에게 제품을 다시 고르라고 묻는 절차가 아닙니다. 지정 제품 안에서 실제 받은 상자의 구성과 보드 리비전을 읽는 작업입니다. 전원을 분리한 상태에서 확장보드의 색, 인쇄된 모델·리비전, Raspberry Pi 모델, 케이블 연결 상태를 `docs/hardware-record.md`에 적습니다. 사진은 접속 정보나 학생 얼굴이 없게 찍고 개인 장비 식별번호는 공개하지 않습니다. 색만 애매하면 인쇄와 해당 제조사 설명서를 함께 대조합니다. 확인 불가 칸에는 “미확인”을 적고 PC 모의 실습을 계속합니다.

제조사 기존 [Adeept_RaspTank 저장소](https://github.com/adeept/Adeept_RaspTank)는 초록색 확장보드 전용이라고 안내합니다. 보라색은 [adeept_rasptank2](https://github.com/adeept/adeept_rasptank2)를 사용하도록 연결합니다. 이 둘은 폴더 이름만 다른 같은 프로그램이 아닙니다. 제공 어댑터도 두 경로를 나누며 보드 색을 지정하지 않으면 실물 초기화를 시작하지 않습니다. 제조사 문서의 새 제품 안내와 판매 링크의 제품 이름만으로 우리 상자가 최신 V4라고 확정하지 않습니다.

조립 전에는 부품을 설명서의 그림·부품표와 대조해 분류합니다. 제조사 [준비 자료 페이지](https://www.adeept.com/learn/detail-83.html)에서 해당 리비전의 자료를 선택하고 다운로드 파일명·날짜를 기록합니다. 보라색 V4 자료를 초록색 장치의 조립도에 덮어 쓰지 않습니다. 배터리는 종류·극성·제조사 요구 조건을 실제 설명서에서 확인하며 이 교안은 임의의 전압이나 셀 개수를 제시하지 않습니다. 없는 부품을 비슷하게 생긴 것으로 바꾸어 통전하지 않습니다. 전원을 분리하고 기구 조립, 케이블 방향, 단락 가능성, 가동 부품 간섭을 점검합니다.

서보 혼과 팔 링크를 고정하기 전 필요한 초기 위치 맞춤은 해당 제조사 조립 순서를 따릅니다. 인터넷 예제의 끝까지 왕복하는 코드를 그대로 실행하면 조립된 팔에 무리가 갈 수 있습니다. 이미 조립된 장치는 일단 상태를 기록하고 강사가 보정 완료 여부를 확인합니다. 장비 조립과 OS 설치를 수업 당일의 전원 없는 PC 활동으로 대체했다고 기록하지 않습니다. 미조립 키트가 있으면 강사는 사전 준비 시간을 별도 확보하고, 학생 수업에서는 준비된 한 대의 단계 시연과 종이 부품도를 병행합니다.

필수 활동은 부품 사진 또는 실물에서 “에너지 공급, 계산, 출력 제어, 실제 움직임” 역할을 연결하는 것입니다. 학생은 잘못 연결된 모의 회로 그림에서 신호와 전원을 혼동한 부분을 찾아 이유를 설명합니다. 함께 따라 하기에서는 리비전 확인표 한 줄을 작성하고, 서로 다른 저장소를 선택했을 때 생길 수 있는 오류를 예측합니다. 추가 도전은 해당 조립 자료에서 서보 고정 전 초기화 단계의 페이지를 찾아 근거로 적는 것입니다. 강사는 페이지를 실제 열었는지와 실물 조립 완료 여부를 별도 표시합니다.
