# R07 라즈봇V2 준비·모터·정지 확인


라즈봇V2는 메카넘휠과 Raspberry Pi 5를 사용하는 로봇카입니다. 앞서 제공됐던 RaspTank의 코드·핀·보드 설명을 그대로 사용하지 않습니다. [Yahboom 공식 수업](https://www.yahboom.net/study/RASPBOT-V2/)에서 조립·전원·이미지·원격 접속·드라이버·모터 수업을 차례로 확인합니다. 실제 구매 옵션의 Pi·저장장치 포함 여부와 준비 상태는 현물을 기준으로 확인합니다.

## 실제 준비 순서

보드·배터리·충전기·휠 조립을 확인 → 해당 모델의 제조사 OS·설치 안내 확인 → Pi 부팅 → 같은 네트워크에서 주소 확인 → 공식 원격 접속 방법으로 접속 → 제조사 모터 예제의 정지 기능부터 확인합니다. PC PowerShell과 Pi 터미널의 실행 위치를 구분합니다. 사용자명·주소는 실제 설정값으로 사용하고 기본 암호를 교안에서 공동 계정처럼 복사하지 않습니다.

제조사 드라이버 문서에서 Raspbot 클래스의 Ctrl_Car(motor_id,motor_dir,motor_speed)를 확인했습니다. 제공 pc/robot_pulse.py는 기본 모의 출력이며 실제 실행은 Pi에서 확인한 제조사 드라이버 .py 경로를 --driver로 넘길 때만 사용합니다. 파일 이름과 설치 위치를 임의로 가정하지 않습니다. 드라이버의 import 자체가 장치에 접근할 수 있으므로 실물 준비 후 실행합니다.

```powershell
py -m pc.robot_pulse --motor 0 --speed 30 --seconds 0.2
```

위는 PC 모의 실행입니다. 실제 Pi에서는 준비한 Python 환경에서 python3 -m pc.robot_pulse --real --driver 실제드라이버경로 --motor 0 --speed 30 --seconds 0.2처럼 실행합니다. 최초에는 바퀴를 띄우고 짧게 한 모터씩 확인합니다. 정지 통신이 실패하면 코드의 finally만 믿지 않고 물리 전원을 차단합니다.

## 확인과 확장

모터 번호·실제 바퀴·방향을 표로 적은 뒤 전진·회전 함수를 만듭니다. 여러 모터 동시 주행을 검증 전 자동 적용하지 않습니다. 10/29의 통신 연동에 앞서 정지·명령 유효시간·중단 처리를 확인합니다. 이번 모의 출력은 실제 주행 성공의 근거가 아닙니다.


## 주석 예제 원본

```python
"""라즈봇V2 제조사 Ctrl_Car를 사용한 제한된 모터 시험. 기본은 모의 출력입니다."""
import argparse,importlib.util,time
from pathlib import Path

def pulse(car,motor,speed,seconds):
    if motor not in range(4) or type(speed) is not int or not 0<=speed<=50:
        raise ValueError('시험 범위: motor 0~3, speed 0~50')
    if not 0<seconds<=0.5:raise ValueError('시험 시간은 0초 초과 0.5초 이하')
    try:
        car.Ctrl_Car(motor,0,speed)
        time.sleep(seconds)
    finally:
        # 한 모터의 정지가 실패해도 나머지 정지 호출은 계속 시도합니다.
        failures=[]
        for mid in range(4):
            try:car.Ctrl_Car(mid,0,0)
            except Exception as error:failures.append(error)
        if failures:raise RuntimeError('모터 정지 통신 실패. 물리 전원을 차단하세요.') from failures[0]

class Preview:
    def Ctrl_Car(self,*args):print('DRYRUN Ctrl_Car',args)

if __name__=='__main__':
    p=argparse.ArgumentParser();p.add_argument('--motor',type=int,default=0)
    p.add_argument('--speed',type=int,default=30);p.add_argument('--seconds',type=float,default=.2)
    p.add_argument('--real',action='store_true');p.add_argument('--driver',type=Path)
    a=p.parse_args();car=Preview()
    if a.real:
        if not a.driver or not a.driver.is_file():p.error('실제 Pi의 확인한 제조사 드라이버 .py 경로가 필요합니다.')
        spec=importlib.util.spec_from_file_location('verified_raspbot_driver',a.driver.resolve())
        module=importlib.util.module_from_spec(spec);spec.loader.exec_module(module)
        car=module.Raspbot()
    pulse(car,a.motor,a.speed,a.seconds)

```
