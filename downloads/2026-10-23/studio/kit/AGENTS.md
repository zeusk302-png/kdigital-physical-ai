# 작업 규칙

README.md → docs/hardware.md → docs/checks.md 순으로 읽는다. 기본은 dryrun이다.
제조사 코드를 다운로드한 뒤 자동 실행하지 않는다. GPIO·채널·각도·배터리 전압을 추측하지 않는다.
commands.py의 범위 검사와 runner.py의 finally 정지를 보존한다. 실제 장치 명령을 원격으로 실행하지 않는다.
수정 범위·재현 입력·예상 출력·실제 시험·미확인을 보고한다. 테스트 성공을 실물 성공으로 바꾸어 쓰지 않는다.
Wi-Fi 비밀번호·학생 개인정보·로컬 보정값을 커밋하지 않는다.
