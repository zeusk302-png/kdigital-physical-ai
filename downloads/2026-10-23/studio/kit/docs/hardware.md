# 실제 장치 준비와 연결

지정 제품은 ADR013입니다. 실제 상자의 Pi 모델·확장보드 리비전을 확인하고 아래 순서로 조립·OS·전원·주행·서보 보정을 준비합니다. 준비가 끝나지 않은 단계는 통전·실행 전에 확인합니다.

## 1. 조립 전 기록

전원을 분리하고 부품표, 확장보드 색과 인쇄 모델, Pi 모델, 설명서 버전을 hardware-record.md에 기록합니다. 제조사 기존 저장소 README는 초록색 전용이며 보라색은 rasptank2로 안내합니다. 색·인쇄·해당 설명서를 함께 봅니다. 제조사 새 자료 페이지 https://www.adeept.com/learn/detail-83.html 에서 리비전에 맞는 조립·설치 자료를 선택합니다. 배터리 종류·극성·전압·전원 경로는 그 설명서와 실물을 대조합니다. 이 자료는 값이나 배선 번호를 추측하지 않습니다.

나사·지지대·절연·케이블 방향·링크 간섭을 확인합니다. 서보 혼 조립 전 초기 위치 맞춤은 해당 설명서 순서를 따릅니다. 미조립 장치를 50분 안에 완성한다는 계획은 세우지 않습니다. 강사가 조립·OS 준비를 사전에 완료하지 못하면 학생 수업은 PC 경로와 부품도 활동으로 운영하고 실제 조립은 별도 시간으로 기록합니다.

## 2. OS·라이브러리

PC에서 대상 microSD의 자료와 장치명을 확인한 후, 선택 리비전 문서에 맞는 OS 이미지를 준비합니다. 최신 OS가 이전 드라이버와 호환된다고 보장하지 않습니다. Pi 모델, OS, Python, I2C 등 필요한 인터페이스, 설치 라이브러리 버전과 제조사 커밋을 기록합니다. 공식 Pi 시작 안내: https://www.raspberrypi.com/documentation/computers/getting-started.html .

Pi에서 pwd, python3 --version, cat /etc/os-release를 확인합니다. 제조사 setup.py는 먼저 내용을 검토하고 변경 범위·네트워크 다운로드·자동 시작 서비스를 파악합니다. 이 kit는 다운로드나 설치 스크립트를 자동 실행하지 않습니다. 원격 키와 Wi-Fi 비밀번호는 공유하지 않습니다.

## 3. 주행 어댑터

공식 고정 커밋과 경로는 sources.md에 있습니다. 파일을 강사가 내려받아 검토하고 해시를 source-evidence.json과 비교합니다. PC에서는 Get-FileHash로, Pi에서는 sha256sum으로 읽을 수 있습니다. 해시 일치는 파일 동일성 검사이며 장치 적합성 인증은 아닙니다. 제조사 파일은 vendor/ 등 별도 경로에 보관하며 무단 재배포하지 않습니다.

준비 완료된 Pi의 kit 폴더에서 먼저 `python3 -m robotlab sequence.json`으로 dryrun을 확인합니다. 실제 주행은 짧은 주행만 담은 reviewed-drive.json을 별도로 만들고 명시적 옵션을 사용합니다.

```text
python3 -m robotlab reviewed-drive.json --hardware --board green --vendor-file /검토한/경로/move.py --sha256 강사가검토한64자리해시 --confirmed
```

보라색은 board purple과 해당 web/move.py 경로를 사용합니다. 예시의 한글 경로·해시는 실제 값으로 바꾸기 전에는 실행할 수 없습니다. 자동 원격 실행용 명령이 아닙니다. 같은 보드를 제어하는 제조사 서버 등 다른 프로세스는 중단하고 단독 제어를 확인합니다. 궤도를 띄운 지지 상태에서 방향과 정지를 확인한 뒤 안전 구역의 저속 시연으로 옮깁니다. 관찰·전원 분리 담당을 정합니다. 정상 종료·예외·Ctrl+C/SIGTERM에는 정지를 요청하지만 강제 종료·전원 손실의 물리적 안전까지 보장하지 않습니다.

## 4. 서보 확장

서보는 현재 실물 어댑터에서 거절됩니다. 초록색 server/servo.py는 import 시 장치 초기화가 있고 보라색 examples/03_Servo.py의 직접 실행은 다채널 반복 이동이므로 진단용으로 즉시 실행하지 않습니다. 제조사 도구로 한 관절씩 확인하고 실제 포트, 단위, 조립 영점, 간섭 없는 범위, 부하와 정지 정책을 기록한 뒤 별도 어댑터를 검토해야 합니다. 코드에 제시된 각도 범위가 조립체의 안전 범위라는 주장은 하지 않습니다. 토크 해제로 팔이 떨어질 가능성도 확인합니다. 현재 필수 학습은 모의 명령·순서·거절·설계이며 준비된 실제 장비는 감독 시연으로 연결합니다.
