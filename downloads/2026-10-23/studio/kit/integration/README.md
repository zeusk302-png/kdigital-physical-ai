# 오늘 배선·코드 확인 → 목요일 통합 대시보드

사용자 확인: **추가 장비 없이 고급키트만 보유**. 오늘은 배선과 보드 코드를 우선 준비하고 목요일(2026-10-29)에 대시보드를 만듭니다. 원본 과목 날짜 10/23을 옮기지 않고 오늘 보강 자료를 추가했습니다.

UNO 한 대와 기본 키트로 전체 모듈을 동시에 꽂아 유지할 수는 없습니다. 이 자료는 **전체 37품목·단품 28안내의 핀 명세와 함께 연결 가능한 4개 통합 회로**를 제공합니다. 모든 모듈을 동시에 연결하는 목표는 추가 핀·전원·배치 조건이 필요하여 미완료입니다. 그림만으로 완료했다고 표시하지 않습니다.

1. [오프라인 단계별 그림](index.html)을 열고 P01을 선택합니다. 한 선을 연결할 때마다 다음을 누릅니다.
2. [P01 기본 통합](profiles/P01.md)을 조립하고 입력과 LED 명령을 확인합니다. 목요일에 사용할 기본 회로입니다.
3. 추가 실습은 [P02 조이스틱·RGB](profiles/P02.md), [P03 키패드·세 LED](profiles/P03.md)로 교체합니다. USB를 빼고 이전 회로를 전체 해체합니다. 키트의 암–수 10개에 맞춰 각각 9개, 8개를 사용합니다. P01은 7개입니다.
4. [P04 모터](profiles/P04.md)는 외부전원이 없어 모터 연결·통전·구동을 보류합니다. 핀과 전원 경로를 읽고 차단 코드 및 가변저항·정지 버튼 입력을 확인합니다.
5. [전체 부품표](INVENTORY.md)에서 나머지 FND·RTC·IR·RFID 등의 단품 배선을 찾습니다. 모든 단품에 그림과 각 핀 표, 기존 참조 코드를 연결했습니다. 단품 코드는 새 통합 명령 규약과 구분합니다.
6. Claude에는 [CLAUDE-HANDOFF.md](CLAUDE-HANDOFF.md)와 전체 ZIP을 전달합니다. 이 MD는 37품목과 32회로의 배선·전원·통신 규약을 한 파일에 담았습니다. 그림은 ZIP을 함께 보내야 열립니다.
7. 목요일에는 [통신 규약](PROTOCOL.md)을 기준으로 PC와 대시보드를 연결합니다. P 기준 코드는 명령 응답을 지원하지만 기존 대시보드가 이미 지원하는 것은 아닙니다.

필수는 P01 조립·입력 측정·LED 명령·오류 복구입니다. 추가 도전은 P02/P03 교체와 자동 모드입니다. 설치 문제로 못한 경우와 회로 학습 미완료를 구분합니다. 단품 28개와 통합 4개를 하루에 모두 수행한다는 시간 보장은 하지 않습니다.

배선 노드·구멍 중복·전원 단락·저항 우회·핀 자원·코드 컴파일·PC 통신 로직 검증은 별도 보고서를 따릅니다. 실물 조립·업로드·전류·동작·수업 리허설은 미실시입니다. 공개 게시도 자료 생성과 구분합니다.

## 오늘의 준비·연결 순서

1. 폴더 `my-kit`를 만들고 이 자료를 풉니다. `.md`는 설명, `.svg`는 확대 가능한 그림, `.ino`는 보드 프로그램입니다. `index.html`은 더블클릭해 오프라인으로 열 수 있습니다.
2. 화면과 부품 사진을 대조합니다. USB를 빼고, 이전 프로파일 부품·선을 모두 해체합니다. 다른 P/K 회로의 선을 남겨 합치지 않습니다.
3. 지정한 부품을 놓고 신호선을 하나씩 연결합니다. 그림의 모듈 핀은 펼친 표기입니다. 모듈을 그림처럼 빵판에 억지로 꽂지 말고 암–수 선으로 실제 핀 이름을 연결합니다. 부품 자체의 핀 간격·왼쪽 순서는 실물과 모델 핀표를 따릅니다.
4. 전원 분배 묶음과 GND를 연결합니다. 조건부 전원·신호는 보류합니다. A~E와 F~J의 같은 숫자 줄은 서로 다른 금속판입니다. 실제 전원 레일은 이 그림에서 쓰지 않습니다.
5. 핀표와 코드의 `pins.h`를 대조합니다. 저항 값·극성·전원 단락·비어 있어야 할 핀을 확인합니다. 멀티미터가 있으면 **모든 전원을 분리한 빈 빵판**에서 연결 묶음을 확인합니다. 전원 연결 상태에서 저항/연속성 모드를 쓰지 않습니다.
6. PC에 Arduino IDE를 열고 `firmware/Pxx/Pxx.ino`를 엽니다. 같은 폴더의 `pins.h`, `protocol.h`도 유지합니다. Arduino Uno와 실제 COM 포트를 선택하고 필요한 라이브러리를 설치합니다. 검증 → 업로드 후 시리얼 모니터를 **115200**, 줄 끝을 **새 줄**로 설정합니다. 기존 단품 K 예제는 **9600**입니다.
7. `1 STATUS`를 보내고 실제 숫자를 확인합니다. 그다음 이 프로파일의 출력 명령을 하나만 실행합니다. 시리얼 모니터와 PC 연결 프로그램은 같은 COM 포트를 동시에 열지 않습니다.
8. 사진·회로 ID·코드·예상/실제 결과를 저장합니다. 수업 끝에는 USB를 빼고, 목요일 전에도 다시 전원 분리 상태에서 전체 배선을 점검합니다. 다른 회로 실습을 했다면 목요일 사용할 P01로 복원합니다.

## 동작과 완료의 구별

컴파일 성공은 문법·라이브러리 조합 확인입니다. 업로드 성공은 보드 전송, 수신 JSON은 보드 프로그램 응답입니다. LED 실제 발광·모터 실제 각도는 별도 관찰입니다. 자동 자료 검사는 실물 정격·납땜·실제 핀 순서·전류·노이즈를 보증하지 않습니다.
