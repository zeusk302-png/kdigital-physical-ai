# 회로·센서 실습

1. XIAO·UNO·라즈봇의 역할을 구분하고 hello 업로드·출력을 확인합니다.
2. 전원을 끄고 LED·저항·버튼을 배선한 뒤 누름/해제 동작을 확인합니다.
3. Echo 분압을 확인하고 HC-SR04로 자와 거리값을 비교합니다.
4. 경고 켜짐/꺼짐 기준을 나누고 시간초과를 fault로 처리합니다.
5. MPU6050의 정지 상태·기울임·단위를 비교합니다. 설치가 막히면 공통 거리 기능을 먼저 완성합니다.
6. Serial Monitor를 닫고 pc.collect로 실제 측정 JSONL을 저장합니다.
7. 준비된 라즈봇에서 제조사 정지 경로와 모터 대응을 확인합니다. PC 모의 실행과 구분합니다.
8. 개인 알림·보정 기능 하나를 추가하고 장비 확인표·Git·실행 안내를 남깁니다.

오류는 코드의 잘못된 핀·조건·입력 형식으로 확인합니다. 전원 단락이나 허용 전압을 넘기는 배선은 오류 실습에 쓰지 않습니다. 출력 계약을 바꾸면 수집기와 서버도 함께 검토합니다.
