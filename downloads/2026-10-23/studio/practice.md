## 오늘 보강: 전체 부품 배선과 목요일 대시보드 준비

[단계별 전체 배선 실습실](kit/integration/index.html) · [Claude에 전달할 전체 MD](kit/integration/CLAUDE-HANDOFF.md) · [전원과 모터드라이버의 각 핀](kit/integration/POWER-AND-DRIVER.md)

고급키트만 보유한 조건으로 P01 기본 통합과 기능별 교체 회로를 제공합니다. 목요일(2026-10-29)에 사용할 회로는 P01입니다. 외부전원이 없는 모터와 미확인 모델은 조건을 확인하기 전 연결·구동을 보류합니다. 전체 모듈을 동시에 연결한 구성은 아닙니다.

[37개 구성품·단계별 빵판 실습실](kit/guide/index.html)

오전은 강사 제공 Sense PDF, 오후는 각자 UNO 고급키트로 진행합니다.

1. K00에서 UNO 업로드를 확인합니다.
2. K01의 빵판 구멍을 눌러 같은 연결 묶음을 확인하고, 저항·LED부터 연결합니다.
3. K02 버튼과 K04 가변저항으로 디지털·아날로그 입력을 비교합니다.
4. 센서·표시·구동 목록에서 순서대로 한 부품씩 연결합니다. 추가 전원·핀표 조건이 있는 항목은 준비를 확인하고 진행합니다.
5. 개인 기능을 만듭니다. 예: 조도 센서+RGB의 자동 조명, 조이스틱+LCD의 방향 표시, 키패드+FND의 숫자 입력기. 각 부품이 단독으로 된 뒤 합칩니다.
6. 합칠 때 겹친 핀·전원 용량·라이브러리 타이머 사용을 확인합니다. delay 때문에 입력이 늦어지면 millis로 주기를 나눕니다.

## 남길 결과

부품별로 **실제 연결 사진 / 사용한 저항 값 / 수정한 코드 / 정상 결과 / 한 가지 오류와 복구**를 기록합니다. 예상 결과와 실제 결과는 구분합니다. 수업 중 끝내지 못한 항목도 전체 목록에서 계속 열 수 있습니다.

```text
my-arduino/
  sketches/K01/K01.ino
  sketches/my_feature/my_feature.ino
  photos/
  notes/results.md
  .gitignore
```

`.gitignore`에는 build/, .cache/, *.hex, *.elf를 넣습니다. 보드 소스와 README는 올립니다. Git에 올리기 전 학생 이름·계정 정보·다른 사람 얼굴이 포함된 사진은 확인합니다.
