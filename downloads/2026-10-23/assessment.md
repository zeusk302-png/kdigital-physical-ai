# 평가 · 전자회로·ESP32

이 평가는 전기의 기본량을 말로 설명하고, 센서 기록을 서로 다른 상태로 구분하며, 다음 작업자에게 확인 근거를 전달할 수 있는지 확인합니다. 실제 보드 보유 여부와 코드 입력 속도는 평가하지 않습니다.

## 준비와 제출 방법

예제 ZIP을 푼 폴더에서 활동별 `work/A번호_worksheet.md`를 찾으세요. 앞선 전기량 계산·배선 검토·센서 검수 기록을 모으고, `work/A17_worksheet.md`에 종합 결과를, `work/A18_worksheet.md`에 인수인계 설명을 적습니다. 인수인계는 다음 사람이 같은 조건으로 작업을 이어 갈 수 있도록 설명과 파일을 넘기는 일입니다.

직접 실행했는지, 종이로 계산했는지, 제공 출력 또는 강사 시연과 비교했는지 표시하세요. 실제 통전이나 측정을 하지 않았다면 “미확인”으로 적습니다.

## 수행 과제

1. **전기량 설명:** 전압·전류·저항의 뜻과 단위 V·A·Ω를 연결하세요. 계산식에 숫자와 단위를 함께 적고, GND가 회로에서 어떤 기준점인지와 전류가 흐를 닫힌 경로를 설명하세요.
2. **장비 확인표:** 실제 보드·센서 모델, 공급 전압, 사용할 핀, 연결 근거를 적으세요. 자료가 없는 칸에는 추측값 대신 “미확인 / 확인할 자료”를 씁니다. 확인되지 않은 장비를 직접 연결할 필요는 없습니다.
3. **모의 센서 검수:** 숫자 `0.0`, 미측정 `null`, 숫자로 보이는 문자열, 경계값을 각각 확인하세요. 입력 값·자료형·예상 상태·실제 상태·판단 이유를 한 줄씩 기록합니다. 원시값을 물리량으로 바꾸는 기준이 있는지도 구분하세요.
4. **인수인계:** 사용한 입력 파일, 적용 규칙, 결과, 아직 확인하지 못한 실제 장비 조건을 묶어 전달하세요. 모의 코드의 성공과 실제 보드의 성공을 별도로 표시하세요.

최종 제출물은 **전기량 계산과 배선 검토표 + A17 예상·결과표 + A18 인수인계 기록**입니다. 입력·설정·출력 파일이 있으면 함께 첨부하세요.

## 채점 기준 · 100점

| 관점 | 배점 | 충분한 근거의 기준 |
|---|---:|---|
| 전기 개념 | 25 | V·A·Ω와 기준점·닫힌 경로를 연결하여 설명하고 계산에 단위를 쓴다. |
| 하드웨어 판단 | 25 | 모델·전압·핀맵의 근거를 적으며, 근거가 없을 때 확인 전 보류로 표시한다. |
| 데이터 검수 | 30 | 0·null·문자·경계값을 구별하고, 입력과 규칙으로 상태 판단을 설명한다. |
| 재현과 인수인계 | 20 | 입력·규칙·결과·미확인 사항을 함께 남겨 다음 사람이 같은 검사를 할 수 있게 한다. |

각 관점은 **근거 없음 0% / 일부는 맞지만 핵심 누락 50% / 근거와 결과·범위가 일치 100%**로 채점합니다. 25점 항목은 0·12.5·25점, 30점 항목은 0·15·30점, 20점 항목은 0·10·20점입니다. 총점 70점 이상이며, (1) 모의/실물 검증 범위를 구분하고 (2) 모델·전압·핀 근거가 없을 때 임의로 확정하지 않고 **확인 전 보류**로 표시해야 기본 목표에 도달합니다. 필수 조건이 미충족이면 총점과 별도로 보완 필요를 기록하고, 장비 검토표의 미확인 항목·확인할 자료를 고친 뒤 이유를 다시 설명합니다.

## 설명으로 확인하는 질문

1. 저항 양단에 3.3V가 걸리고 저항이 660Ω이라면 전류는 얼마인가요? A와 mA 단위를 구별해 설명하세요.
2. ADC 원시값 하나만 보고 온도라고 말할 수 있나요? 해석에 필요한 추가 정보를 적으세요.
3. `null`과 `0.0`을 같은 값으로 처리하면 어떤 정보를 잃게 되나요? 센서 측정 상황으로 설명하세요.
4. 파일을 사용한 모의 예제가 통과한 뒤, 실제 보드를 연결하기 전에 더 확인할 사항 세 가지는 무엇인가요?

## 제출 전 확인

- 계산의 숫자와 단위를 함께 썼는가?
- 장비 정보의 확인 근거와 미확인 항목이 나뉘어 있는가?
- 미측정·잘못된 입력·정상값을 구분했는가?
- 실제 실행 여부와 실제 장비 미검증 범위를 밝혔는가?

잘못된 답은 판단에 사용한 입력과 규칙부터 다시 확인합니다. 설명을 수정했다면 바뀐 이유를 인수인계 기록에 한 문장 추가하세요. 정답과 채점 예시는 강사용 자료에 있습니다.


## 새 상황으로 옮겨 보는 전이 문제 · 복습·도전

교시당 한 문제이며 기존 필수 평가 후 필요에 따라 선택합니다. 독립 작성 또는 판단을 먼저 기록한 뒤 해설을 확인합니다. 설치 실패나 장비 부재는 개념 오답과 구분합니다.

### 전이 1 · 1교시

저항 양단 2.4V·1200Ω일 때 A와 mA를 계산하고 닫힌 경로를 설명하세요.

<details><summary>정답과 해설</summary>

0.002A=2mA입니다. 전원 +에서 저항을 거쳐 −로 돌아오는 길을 포함합니다.

</details>

### 전이 2 · 2교시

공급 5V·가정 LED 강하 2V·저항 1000Ω의 계산 전류와 GPIO 연결 승인 여부를 쓰세요.

<details><summary>정답과 해설</summary>

3mA입니다. 수학 계산만으로 연결을 승인하지 않으며 정확한 보드·핀·부품 정격을 확인해야 합니다.

</details>

### 전이 3 · 3교시

이상적 0~3.3V·0~4095 끝점 대응에서 코드 4095와 JSON null의 의미를 각각 쓰세요.

<details><summary>정답과 해설</summary>

4095는 모델의 3.3V, null은 값 없음입니다. 실물 교정이나 섭씨 온도를 직접 뜻하지 않습니다.

</details>

### 전이 4 · 4교시

초기 True, 문턱 28/27.5, 입력 [27.6,27.5,None,28]의 상태를 추적하세요.

<details><summary>정답과 해설</summary>

True,False,False 유지와 no command,True입니다. 결측을 영도로 바꾸지 않고 상태와 측정 유효성을 나눕니다.

</details>

### 전이 5 · 5교시

Serial.println으로 고정 25를 출력했습니다. 센서와 직렬 전송 검증의 상태를 나눠 쓰세요.

<details><summary>정답과 해설</summary>

실제로 보드·포트에서 관찰했다면 고정 문자열 전송만 확인한 것입니다. 센서 측정 정확도는 그 코드에 읽기 단계가 없어 미검증입니다.

</details>

### 전이 6 · 6교시

경계가 28에서 30으로 바뀌었습니다. 새 시험 세 입력과 실물 미확인 항목을 쓰세요.

<details><summary>정답과 해설</summary>

29.9,30.0,30.1 및 결측을 시험하고 기대 상태를 갱신합니다. 보드 신호 전압·센서 오차 등은 별도 실물 확인입니다.

</details>
