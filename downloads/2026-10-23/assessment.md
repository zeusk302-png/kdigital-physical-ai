# 직접 작성과 실행 확인

자기 동작 시퀀스를 만들고 정상·범위 초과·중단을 시험하세요. 실물에서는 준비·가동 범위·정지 확인을 분리합니다.

|---|---:|---|

## 확인 질문

1. PC 모의 실행과 Raspberry Pi 실제 실행은 어떻게 구분하나요?
2. 잘못된 명령이 마지막에 있을 때 앞 명령을 먼저 실행하면 어떤 문제가 있나요?
3. 정지 요청과 실제 모터 정지는 어떻게 나눠 확인하나요?

실제로 실행한 것과 확인하지 못한 것을 나눠 기록합니다. 설치·계정 문제는 기능 이해와 구분합니다.
