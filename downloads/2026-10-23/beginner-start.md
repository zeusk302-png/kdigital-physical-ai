Python 표준 라이브러리로 가상 센서 파일을 읽습니다. 실제 연결·통전·시리얼 포트 열기는 하지 않습니다. .ino 파일은 보드용 코드를 읽는 자료이며, 컴파일하거나 업로드한 결과는 아닙니다.

## 파일과 실행

`examples/course/data`는 읽을 입력, `code`는 완성 시연 코드, `work`는 나의 작성·수정 파일입니다. ZIP을 풀고 폴더 구조를 유지합니다. 터미널은 명령을 실행하는 창이며, 에디터는 파일 내용을 쓰고 저장하는 창입니다. 저장만으로 코드가 실행되지는 않습니다.

1. [용어](glossary.md)에서 낯선 말을 확인합니다.
2. [교안](lesson.md)의 개념과 예를 읽습니다.
3. [활동지](practice-guide.md)의 A01부터 입력을 열고 work 양식에 기록합니다.
4. 코드 실행은 code/line-guide.md의 명령과 조건을 따릅니다.

확인할 것: 전압·전류·저항의 단위를 구별하고, 0·null·문자열이 서로 다른 상태인 이유를 설명해 보세요. 가상 입력에서 확인한 결과와 실제 장비에서 확인할 사항도 구별합니다.

개인 코드 실행에는 Python 3를 사용할 수 있는 PC가 필요합니다. 실제 장비를 사용할 때는 정확한 보드·센서·저항·LED 모델을 먼저 확인하세요. 전원·핀·배선을 추측하여 통전하지 않습니다.
