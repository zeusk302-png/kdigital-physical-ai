# 전자회로·ESP32 예제

이번 수업에서는 실제 연결·통전·시리얼 포트 열기를 하지 않습니다. Python표준 라이브러리로 가상센서 파일을 읽습니다. .ino는 모델 확정 후 실행할 완성 예의 읽기 자료이며,현재컴파일·업로드 결과가 아닙니다.

[활동 전체 안내](activity-guide.md) · [모든 코드와 줄 해설](code/line-guide.md)

data는 원문, work는 학생 기록·수정본, code는 완성 시연 파일입니다. 폴더 구조를 유지합니다. 입력 파일을 덮어쓰지 않고 활동지의 work 파일에 결과를 남깁니다.

실행 환경이 없으면 입력 JSON과 제공 출력을 비교해 기록합니다. 회로 활동은 종이상의 계산·검토이며 실제 장비는 필수가 아닙니다.
