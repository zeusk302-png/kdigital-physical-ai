# 웹 대시보드 쉬운 용어

용어를 말한 뒤 예제의 실제 위치를 함께 짚습니다.

| 용어 | 뜻 |
| --- | --- |
| 대시보드 | 현재 값과 이력을 업무 질문에 맞춰 보여 주는 현황판 |
| 서버 | 요청을 받아 처리하고 응답하는 프로그램 |
| API | 프로그램이 정해진 주소와 자료형으로 요청하는 창구 |
| 요청 | 다른 프로그램에 읽기나 처리를 부탁하는 메시지 |
| 응답 | 요청에 대해 돌려준 상태와 자료 |
| 필터 | 조건에 맞는 기록만 화면에 선택하는 것 |
| 이력 | 시간이 담긴 관찰 기록의 묶음 |
| 최신값 | 정한 시각 기준에 따라 마지막인 관찰값 |
| 평균 | 정의한 값들의 합을 해당 개수로 나눈 요약 |
| 오래됨 | 마지막 기록이 신선도 기준보다 오래 지난 상태 |
| 모의입력 | 실물 측정 대신 준비한 가상 값 |
| 포트 | 한 컴퓨터 안에서 통신 프로그램을 구분하는 번호 |
