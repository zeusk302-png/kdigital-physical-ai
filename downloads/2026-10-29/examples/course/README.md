## 실행

이 course 폴더를 터미널의 현재 위치로 선택합니다. ZIP 안에서 바로 편집하지 말고 먼저 압축을 풉니다. Python이 준비된 환경에서 다음 명령을 사용합니다.

```text
python code/server.py
# 서버 창은 유지하고 다른 터미널에서 실행
python code/send_sample.py
```

[전체 소스·모든 줄·기대 결과](code/line-guide.md)를 읽습니다. 함수·서버·전체 앱을 빈 파일부터 혼자 작성하는 것이 필수 과제가 아닙니다. HTML 예제는 지정 index.html을 브라우저에서 열고, 저장 뒤 새로고침합니다.

기본 화면은 고정 fixture와 고정 확인시각을 사용하는 모의 경로입니다. 로컬 API는 별도 실행하며 메모리에만 저장합니다. 실물ESP32·센서·외부망·인증·지속저장·공개배포는 검증 범위가 아닙니다.

18활동×20분은360분 제작 배정이며 실측 리허설 전입니다. 코드 검증 결과와 실제 수업·장비 검증을 구분합니다.

## 정적 화면과 API 버튼

`code/index.html`은 가상 자료로 바로 열 수 있습니다. **API 다시 읽기**는 위 Python 서버가 실행 중인 `http://127.0.0.1:8780/?source=api` 화면에서 사용합니다. 파일 또는 일반 정적 웹에서 이 버튼을 누르면 API가 없어 수신 실패가 예상됩니다. 기존 표를 유지하면서 실패 문구를 보이는 동작을 확인합니다.
