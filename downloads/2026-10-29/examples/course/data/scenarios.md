# 검수 시나리오

1. 전체: 이력 5건, 장치 4개. 입구 마지막값 22.8, 창고 미측정, 실습실 오래됨, 복도 0과 정지.
2. 입구 필터: 이력 2건, 센서 1개, 평균 22.65.
3. 모의 추가: 입구 23.3 한 건 추가, 화면 메모리에만 저장. 새로고침하면 초기화.
4. 수신 멈춤: 확인 시각 70초 이동, 기존값은 남지만 상태는 오래됨. 미측정·정지는 우선규칙 유지.
5. API 실패: 서버를 종료한 뒤 다시 읽기. 이전값을 유지하면서 실패 문구를 표시.
6. 오류 입력: new_reading.json의 온도를 문자열 또는 51로 보낸다면 400 응답이며 수신 건수는 늘지 않아야 함.
7. 원본 바꾸기: work/fixture.js의 첫 22.5를 25.0으로 수정한 뒤 작업 폴더 화면을 열고 입구 평균 23.90을 확인. 마지막값은 22.8로 유지.
