# 가상 현황판의 표시 규칙

현재 시각은 재현 가능한 실습을 위해 2026-10-29 10:10:00 +09:00으로 고정한다. 실시간 시스템 시계가 아니다. 센서별 마지막 기록은 measured_at이 가장 큰 기록이다. 입력 순서만으로 최신이라고 판단하지 않는다.

온도는 0~50 숫자 또는 미측정 null이다. 상태 우선순위는 입력 오류 → 미측정 → 정지 → 오래됨 → 주의 또는 정상이다. 60초 초과는 오래됨, 정확히 60초는 아직 기준 안이다. 28℃ 이상은 주의다. 모든 기준은 수업용 표시 규칙이며 장비 안전 기준이 아니다.

장소 필터는 이력과 최신 표에 함께 적용한다. 평균은 이력의 기본 형식과 범위가 맞고 확인 시각 이후가 아닌 기록의 숫자만 사용한다. 확인 시각보다 미래인 기록은 입력 오류로 표시하고 평균에서도 제외한다. 오래된 기록과 정지 센서의 유효한 숫자(0 포함)는 평균에 포함하며 null을 0으로 바꾸지 않는다. 단위는 ℃다. 화면에 마지막 기록의 시각과 고정한 확인 시각을 모두 표시한다. 데이터가 없거나 통신에 실패한 상태를 정상 측정값처럼 보이지 않게 한다.
