## 실행 준비

브라우저와 텍스트 편집기가 기본입니다. Python 명령의 현재 폴더는 압축을 푼 course입니다. Windows에서 python 대신 py만 있으면 강사의 확인 아래 py -3로 대체합니다.

```text
python code/server.py
# 서버 창은 유지하고 다른 터미널에서 실행
python code/send_sample.py
```

실행하지 못하면 파일 경로·명령·오류 문구를 기록해 도움을 요청합니다. 코드 상자를 보는 것은 Python 실행이 아닙니다.

기본 화면은 고정 fixture와 고정 확인시각을 사용하는 모의 경로입니다. 로컬 API는 별도 실행하며 메모리에만 저장합니다. 실물ESP32·센서·외부망·인증·지속저장·공개배포는 검증 범위가 아닙니다.


## 수업 전, 이 세 가지부터 확인하세요

앞선 수업을 기억하지 못해도 아래 질문과 풀이부터 다시 읽으면 됩니다. 먼저 자기 말로 답한 뒤 풀이와 비교하세요.

### 기록과 화면

질문: 카드에 28.0이 보이면 지금 온도가 반드시 28.0인가요?

풀이: 그 값의 측정 시각과 수신 시각을 함께 확인해야 합니다. 과거 값이 화면에 남아 있을 수 있습니다.

### 대표값

질문: 최신값과 평균은 같은 뜻인가요?

풀이: 최신값은 정해진 순서에서 마지막 유효 기록, 평균은 선택 범위의 유효 숫자 합을 개수로 나눈 값입니다.

### 실패 표시

질문: 통신 실패를 0도로 보여 주면 괜찮나요?

풀이: 실제 0도와 구별되지 않습니다. 마지막 값, 갱신 시각, 실패 상태를 나눠 표시합니다.
