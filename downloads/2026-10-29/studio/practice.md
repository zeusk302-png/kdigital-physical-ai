# 개인 대시보드 실습

## 목적 → 준비

같은 P01 연결에서 출발해 나만의 사용 목적과 화면을 만듭니다. 개인 키트·PC Chrome/Edge·USB를 준비합니다. 포트 문제가 있으면 연습 데이터로 진행하되 실제 측정과 구별합니다. [실행 안내](kit/uno-dashboard/README.md)를 먼저 읽습니다.

## 순서

1. 1교시: Grafana·Home Assistant 사례를 보고 사용자·판단·행동을 각각 한 줄 적습니다. 잘못된 단위·색·응답 문구를 고칩니다.
2. 2교시: [개인 스케치 양식](kit/uno-dashboard/IDEA-SKETCH.md)에 사용자·문제·실제 입력/출력·화면·실패 상태를 씁니다. 원하면 [Claude 전달문](kit/uno-dashboard/CLAUDE-DESIGN-HANDOFF.md)으로 화면 후보를 비교합니다.
3. 3교시: 연습 데이터 → P01 업로드 → 시리얼 모니터 닫기 → USB 선택 → 입력 변화 → LED 명령·응답·실물 → 자동 기준 → STOP → 중단 표시를 확인합니다.
4. 개인 제작120분: 원본을 보존하고 제목·핵심 정보·배치·색·단위·그래프·제어 피드백을 자기 목적에 맞게 수정합니다. 시간별 단계는 D08을 따릅니다.
5. 자기 점검: 초기·정상·null·중단·명령·자동 모드를 D09 표에 기록합니다. 실제로 못 한 항목은 미확인으로 씁니다.
6. README·스케치·화면·코드를 `이름_작품명.zip`으로 묶어 강사가 안내한 곳에 제출합니다.

## 필수 / 추가 도전

필수: 사용자와 목적, 실제 입력 두 종류, 출력 제어 하나, 이름·단위·정상/실패/연결 상태, 실행 안내와 확인표. 연습 데이터 확인만 했으면 ‘연습 확인, 실물 미확인’으로 적습니다.

추가: CSV 내보내기·그래프 구간 선택·P02/P03 프로파일 어댑터. 아직 제공하지 않는 확장 기능은 직접 구현·시험해야 합니다. P04 모터는 외부전원이 없는 현 키트 조건에서 보류합니다.

## 예상 결과와 오류 해결

실제 입력 변화가 카드·그래프에 보이고, LED 명령을 보낸 뒤 요청번호 응답이 옵니다. 온습도 null은0이 아닌 —, 중단은 현재값 숨김·마지막 정상 수신으로 보입니다. 포트 오류는 다른 연결 프로그램부터 닫고, 화면 수정 오류는 저장·새로고침·DOM id·파일 경로부터 확인합니다. 증거는 화면과 실물 관찰을 구별합니다.
