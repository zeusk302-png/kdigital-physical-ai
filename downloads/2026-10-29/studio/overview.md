# 나의 실제 장치 웹 대시보드

ESP32의 거리·자세 또는 YOLO의 실제 사건을 받아 저장·조회·표시합니다. 임의 데이터가 미리 채워진 화면 대신 빈 화면에서 실제 입력을 연결합니다.

## 오늘의 흐름

|시간|할 일|
|---|---|
|10:00–10:50|사용자·화면 설계·로컬 서버|
|11:00–11:50|실제 수집·API·입력 계약|
|11:50–13:00|중식|
|13:00–13:50|DB·이력·중복·재시작|
|14:00–14:50|React·차트·거리 기준·자기 화면|
|15:00–15:50|센서/서버 중단·복구·개인 기능|
|16:00–16:50|팀 검수·Notion·실행 인수인계|

각 구간 사이 10분 휴식, 16:50–17:00 종료 준비입니다.

[서버 실행과 실제 센서 연결](lessons/B09.md), [화면 구현](lessons/B10.md), [팀 검수와 배포 범위](lessons/B11.md)를 함께 사용합니다. 기존 B01~B08의 API·DB·React·오류 설명도 모두 목차에 있습니다.

## 필수 완성

실제 입력 하나 → API → DB → 화면을 완성하고, 자기 지표나 필터·알림 하나를 추가합니다. 센서 수집 중단과 서버 중단을 각각 재현하고 복구합니다. GitHub Pages는 학생의 로컬 Python 서버를 실행하지 않습니다.
