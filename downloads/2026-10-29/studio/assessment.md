# 개인 결과 확인

화려함·부품 개수보다 사용자 목적·자료 의미·동작·복구 근거를 봅니다. 짝 검수는 없습니다. 설치·계정·장비 조건은 별도 기록합니다.

| 기준 | 배점 | 확인할 결과 |
| --- | ---: | --- |
| 사용자와 정보 설계 | 25 | 스케치·핵심 정보·사례/원칙을 적용한 이유 |
| 입력과 출력 연결 | 30 | 입력 두 종류·출력 하나·명령 응답·확인 근거 |
| 단위·상태·오류 | 25 | raw/물리단위·null/0·현재/이력·중단/미확인 구별 |
| 실행과 설명 | 20 | README·코드 ZIP·실제 확인 범위·제한 |

연습 데이터는 디자인·파서·상태 처리 근거이며 실물 센서·출력의 증거가 아닙니다. 실제 연결을 못 한 경우 설계·코드 성취와 실물 미확인을 각각 기록합니다.

## 자기 점검 질문

1. 내 사용자는 이 화면에서 무엇을 먼저 판단하나요?
2. 밝기320과 온도24.3은 왜 다른 단위로 표시하나요?
3. 센서 실패가0으로 표시되면 어떤 오해가 생기나요?
4. 버튼 누름·보드 응답·실제 LED 점등은 어떻게 구별했나요?
5. USB 중단 뒤 마지막 값을 현재값으로 쓰지 않게 했나요?
6. AI가 만든 코드 중 어떤 파일을 바꿨고 어떻게 확인했나요?
