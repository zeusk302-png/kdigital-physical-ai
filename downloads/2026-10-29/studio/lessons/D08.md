# 개인 제작 120분 · 내 목적의 화면 완성


## 목적과 필수 범위

공통 연결을 바탕으로 2교시에 정한 자기 작품을 만듭니다. 4교시 50분 + 5교시 50분 + 6교시 첫 20분, 총 120분입니다. 마지막 30분은 별도 자기 점검·일부 시연·제출 시간입니다. 완전 자유 주제여도 핵심은 **실제 입력 두 종류 이상 표시, 목적에 맞는 정보 배치, 출력 제어 하나, 상태·오류 표시**입니다. 실제 연결이 막힌 경우 연습 모드로 같은 화면 동작을 만들고 증거 범위를 구별합니다.

## 제작 흐름과 매 구간 결과

| 구간 | 직접 할 일 | 남길 결과 |
| --- | --- | --- |
| 0~15분 | 스케치와 파일 보존, 사용자·핵심 동작 다시 정하기 | 작품명·완료 목표·원본 사본 |
| 15~40분 | 제목·정보 순서·색·글자·간격·반응형 배치 수정 | 초안 화면, 정상값 표시 |
| 40~60분 | 입력 변화·LED 수동 제어·명령 피드백 확인 | 첫 왕복 확인, 미완료 오류 한 가지 |
| 60~85분 | 두 경계 자동 모드 또는 목적에 맞는 설명 기능 추가 | 조건·예상·실제 비교표 |
| 85~105분 | null·연결 중단·좁은 화면·키보드 점검 | 고친 오류와 전후 화면 |
| 105~120분 | 실행 순서·제한·코드 정리 | 개인 README, 제출 ZIP 초안 |

강사는 약 20~30분마다 채팅으로 `완료한 기능 / 지금 막힌 한 가지 / 다음 할 일`을 받습니다. 학생마다 짝을 배정하지 않습니다. 화면 공유는 도움이 필요한 학생·희망자 중심으로 하고, 다른 학생은 자기 작업을 계속합니다.

## 선택 확장과 범위

가장 먼저 사용자 판단을 돕는 문구, 표시 단위, 기준 변경, 변화 설명을 완성합니다. 추가 도전으로 그래프 표시 구간 선택이나 CSV 내보내기를 만들 수 있습니다. 아직 없는 기능이므로 AI에게 구현·검증을 함께 요청합니다. P02 RGB·P03 키패드 확장은 배선 프로파일과 파서를 별도로 바꾸는 도전입니다. 기본 P01 예제를 그대로 사용하면 자동 지원되지 않습니다. P04 모터는 외부전원 없이 구동하지 않습니다.

## AI 사용과 확인

한 번에 ‘전부 만들어 줘’보다 스케치·필드·기존 파일·완료 조건을 줍니다. 디자인 수정과 통신 수정은 변경 범위를 적어 요청합니다. 받은 코드의 실제 실행 위치와 바꾼 파일을 기록하고, 연습 데이터인지 USB인지 화면에 표시합니다. 그럴듯한 랜덤 숫자만 나오는 작품은 실제 연결 작품과 구별합니다.

## 중간 합류와 오류 복구

공통 연결이 늦은 학생은 새 폴더에 원본 예제를 다시 풀어 연습 모드부터 합류합니다. 포트 오류로 15분 이상 멈추면 화면 제작을 먼저 계속하고 강사가 개별 확인합니다. 핵심 동작이 완성되면 기능 수를 늘리기 전에 실패 상태를 점검합니다.
