# Claude Design과 Figma MCP로 빠르게 다듬기


## 도구의 역할

아이디어 스케치는 내가 무엇을 만들지 정하는 과정입니다. AI 디자인 도구는 그 생각을 빠르게 화면 후보로 바꾸는 데 씁니다. 화면이 만들어졌다는 이유로 센서가 연결된 것은 아닙니다. **12분 강사 시연**으로 소개하고, 학생의 계정 생성·MCP 설치를 필수 활동으로 두지 않습니다.

| 경로 | 적합한 일 | 조건·대체 |
| --- | --- | --- |
| Claude Design / 디자인 산출물 | 스케치에서 레이아웃 후보 만들고 문구·여백 수정 | Claude 계정, 사용량·조직 설정 확인. 안 되면 제공된 HTML/CSS 수정 |
| Claude Code의 frontend-design 계열 기능 | 로컬 프로젝트의 실제 화면 구현 | 설치된 도구·플러그인 확인. 이름만으로 자동 사용된다고 단정하지 않음 |
| Figma MCP | Figma 프레임을 읽어 코드에 반영하거나 지원 도구로 캔버스 수정 | Figma 계정·파일 권한·지원 클라이언트·호출 한도 확인. 안 되면 프레임 스크린샷 전달 |

2026-10-28 확인: [Claude 공식 도움말](https://support.claude.com/en/articles/14604416-get-started-with-claude-design)은 디자인 생성·수정 경로와 계정 조건을 안내합니다. 예전 별도 사이트 소개와 현재 화면이 다를 수 있으므로 수업 전 자신의 계정에서 위치를 확인합니다. [Figma 공식 MCP 안내](https://developers.figma.com/docs/figma-mcp-server/)는 디자인 읽기·쓰기 도구를 구별하며 [요금제별 한도](https://developers.figma.com/docs/figma-mcp-server/rate-limits-access/)가 적용됩니다. 학생에게 유료 업그레이드를 요구하지 않습니다.

## 강사 시연 12분

0~3분: ‘공부방이 어두울 때 알려주는 화면’ 스케치와 표시할 값을 보여줍니다. 3~7분: Claude에 아래 요청을 넣어 서로 다른 배치 두 안을 받습니다. 7~10분: 핵심값이 큰 안을 고르고 현재값·연결상태·버튼 피드백의 빠진 부분을 지적합니다. 10~12분: 준비한 Figma 프레임 링크로 디자인을 읽어 기존 화면에 옮기는 과정을 소개합니다. 강사 계정 연결을 미리 준비하고, 연결이 안 되면 화면 캡처와 전달문으로 같은 원칙을 설명합니다. 현장 설치 대기로 시간을 늘리지 않습니다.

요청 예: ‘이 스케치로 작업실 조명 대시보드 두 안을 만들어줘. 밝기 원시값과 LED 상태를 가장 먼저 보이게 하고, 온습도·최근 변화·연결 끊김·명령 대기를 포함해줘. 값은 디자인 예시라고 표시해줘. 아직 USB 코드는 바꾸지 마.’

## 구현 단계의 전달

[도구별 따라 하기](../kit/uno-dashboard/AI-DESIGN-QUICKSTART.md)와 [Claude 디자인 전달 MD](../kit/uno-dashboard/CLAUDE-DESIGN-HANDOFF.md)를 내려받아 사용자·목적·스케치를 채웁니다. 구현 시에는 `index.html`, `style.css`, `dashboard.js`와 함께 줍니다. ‘기존 DOM id, data-command, 115200, P01 JSON, 명령·응답·시간 초과를 유지’라고 명시합니다. Figma로는 페이지 전체 링크보다 선택한 프레임 링크를 주고, 읽어 구현할지 캔버스에 쓸지 방향을 말합니다. MCP가 자동으로 예쁜 디자인이나 실물 연결을 보장하지 않습니다.

## 확인

수정 전후로 정상·센서 실패·USB 중단·명령 대기 화면을 비교합니다. 가짜 숫자를 실제 센서값처럼 심거나 존재하지 않는 팬·모터 제어를 추가했다면 삭제합니다. 선택한 디자인의 이유를 원칙 한 가지와 연결해 자기 말로 설명합니다.
