# B10 사용자 기준·단위·현재값과 연결 상태


대시보드는 숫자를 전부 나열하는 곳보다 사용자가 판단할 순서를 보여주는 화면이어야 합니다. 지금 확인할 것, 최근 변화, 이상 사건, 연결 상태를 나눕니다. 거리 cm와 가속도 m/s²를 한 평균으로 섞지 않습니다. 사람의 추적 ID도 측정값으로 평균내지 않습니다.

## 새로 들어간 거리 기준 입력

한 장치의 distance_cm을 선택하면 ‘거리 판단 기준’에서 입력값을 바꾸며 마지막 측정의 판단을 비교할 수 있습니다. 이 입력은 화면의 기준만 바꾸고 ESP32의 LED 기준까지 바꾸지 않습니다. 장치 설정 변경은 요청·인증·전달·응답을 설계한 별도 기능입니다. 화면에서 바뀌었다는 이유로 실물까지 바뀌었다고 표시하지 않습니다.

## 직접 구현할 기능

현재 거리·마지막 측정 시각·단위가 보이는 카드를 만듭니다. 연결 중단이면 마지막 값은 남겨도 현재 정상처럼 표시하지 않습니다. value:null은 측정 실패, 기록 없음은 아직 입력 없음, 0은 측정 종류에 따라 실제 숫자일 수 있습니다. 코드에서 if(value)만으로 세 상황을 나누지 않습니다.

## 원본을 고치고 화면 확인

```powershell
cd frontend
npm.cmd ci
npm.cmd test
npm.cmd run dev
```

원본은 frontend/src/main.jsx와 measurement.js, 생성 파일은 web/app.js입니다. watch 실행 중에는 저장 뒤 브라우저를 새로고침합니다. 웹 전체를 다시 생성해 달라고 AI에 맡기기 전에 필터·판정·표시 중 어느 책임을 바꿀지 정합니다.

## 검수

정상값, 경계값, null, 오래된 값, 서로 다른 장치, 늦게 도착한 기록을 비교합니다. 한 가지 수치의 자동시험과 전체 브라우저 동작은 다른 확인입니다. 사용자가 경고를 놓치지 않는지 팀원이 실제 화면으로 확인합니다. 색만 바꾸지 말고 상태 문장·단위·시각을 함께 표시합니다.
