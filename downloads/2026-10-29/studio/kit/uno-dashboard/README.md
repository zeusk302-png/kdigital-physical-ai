# 내 책상 환경 대시보드 · P01

## 목적

웹 화면이 USB로 보드의 값을 받고 명령을 보내는 양방향 연결을 확인합니다. 서버·DB·Node 설치 없이 시작합니다. 브라우저의 통신 기능 이름이 Web Serial입니다. 회로는 10/23 P01 그대로입니다.

[디자인 A/B 비교실](design-studio.html) · [개인 작성지와 스케치](workbook.html) · [줄별 코드 설명](CODE-WALKTHROUGH.md) · [실행 확인표](SELF-CHECK.md). 같은 폴더의 파일을 함께 보관하면 오프라인에서도 비교실·작성지·작은 예제를 열 수 있습니다. 실제 USB 연결은 HTTPS/localhost와 지원 브라우저가 필요합니다.

[대시보드 디자인 사례 20선](case-gallery.html)에서 공식 공개 화면과 설계 원칙을 비교합니다. 분야 검색, 참고 사례 선택, 적용 메모, 선택 사례 MD 다운로드를 제공합니다. [20사례 해설](CASEBOOK.md)과 축소 화면은 ZIP에도 포함됩니다. 원본 출처를 여는 경우 인터넷이 필요합니다.

## 준비

- PC용 Chrome 또는 Edge, 데이터 통신 가능한 UNO USB 케이블, P01 회로와 업로드된 코드가 필요합니다. 다른 브라우저·학교 정책·드라이버 조건에서는 연결이 제한될 수 있습니다.
- [P01 전체 배선도](https://zeusk302-png.github.io/kdigital-physical-ai/downloads/2026-10-23/studio/kit/integration/index.html?lab=P01)를 확인합니다. LED D8, 버튼 D2, 가변저항 A0, CdS A1, DHT11 D4, LCD A4/A5입니다. 전원을 끄고 배선을 확인합니다.
- `firmware/P01/P01.ino`를 Arduino IDE에서 엽니다. `.ino`는 보드에 업로드할 코드, `.h`는 같은 폴더의 설정·통신 코드입니다. 세 파일을 함께 둡니다. 라이브러리 관리자에서 DHT sensor library(Adafruit), Adafruit Unified Sensor, hd44780(Bill Perry)를 설치합니다. 보드 Arduino Uno와 실제 포트를 선택해 업로드합니다.
- 업로드 후 시리얼 모니터·플로터·기존 Python serial_check.py·다른 대시보드 탭을 닫습니다. 한 포트를 한 프로그램만 사용합니다.
- USB 전원으로 P01을 진행합니다. 외부전원이 없는 모터 P04는 이 예제에 연결하지 않습니다.

## 실행

가장 빠른 방법은 강의실의 ‘P01 대시보드 열기’를 Chrome/Edge에서 여는 것입니다. HTTPS 공개 화면이어도 USB 데이터는 이 PC 브라우저에서 처리합니다. 이 예제는 원격 서버로 측정값을 보내지 않습니다.

파일을 수정하려면 ZIP을 내려받고 ‘모두 압축 풀기’를 누릅니다. 압축 파일 안에서 직접 실행하지 않습니다. `kit/uno-dashboard` 폴더에서 주소 표시줄에 `powershell`을 입력하고 Enter를 누릅니다. 열린 터미널에 다음을 입력합니다.

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

`python`을 못 찾으면 `py -m http.server 8765 --bind 127.0.0.1`을 사용합니다. Python이 없으면 공개 예제로 연결을 확인하고 코드 편집은 계속합니다. 설치 문제는 학습 실패로 처리하지 않습니다. `http://localhost:8765`를 브라우저 주소창에 입력합니다. 로컬 서버의 종료는 터미널에서 Ctrl+C입니다. 다른 PC의 localhost는 내 PC가 아닙니다.

1. 먼저 ‘연습 데이터 시작’을 누릅니다. ‘실제 측정 아님’ 표시와 값이 보입니다. LED 켜기와 끄기로 화면 피드백을 확인합니다. 연습 데이터는 USB를 열지 않습니다.
2. ‘연결 해제’를 누릅니다. ‘UNO USB 연결’을 누르고 내 UNO 포트를 선택합니다. 포트 선택은 사용자가 직접 허용합니다.
3. 보드가 재시작할 수 있으므로 3~5초 기다립니다. ‘P01 수신 중’과 정상 수신 시각이 보이면 연결되었습니다. P02 같은 다른 프로파일은 제어하지 않습니다.
4. 가변저항 손잡이를 돌리고 숫자가 달라지는지 확인합니다. CdS를 손으로 가렸을 때 밝기 원시값이 줄어드는지 확인합니다. `lux`로 바꾸지 않습니다.
5. LED 켜기 → 보드 적용 응답 → 실제 LED → 보드 보고 상태를 순서대로 봅니다. 누른 즉시 성공 표시를 만들지 않습니다.
6. 켜짐 350·꺼짐 450을 전송하고 ‘자동 모드’를 누릅니다. 손으로 CdS를 가려 LED가 켜지고 밝게 하면 꺼지는지 확인합니다. 실제 환경에서 값이 경계를 지나지 않으면 현재 관측값에 맞춰 기준을 정합니다. 두 기준 사이는 이전 상태를 유지합니다.
7. ‘자동 해제·LED 끄기’를 누른 뒤 USB를 뽑습니다. 수신 종료 또는 4초 이내 오래됨을 표시하는지 확인합니다. **연결 해제 자체는 보드 STOP 명령이 아닙니다.**

## 파일을 하나 바꾸고 확인

`index.html`은 글과 배치, `style.css`는 색·크기·여백, `dashboard.js`는 값 수신과 명령입니다. 세 파일을 같은 폴더에 둡니다. 메모장에서 `index.html`의 ‘내 책상 환경’을 ‘작업실 조명’으로 바꿔 저장(Ctrl+S)하고 브라우저에서 새로고침합니다. 다음으로 CSS의 `--accent` 색을 바꾸고 버튼 글자가 잘 읽히는지 확인합니다. 통신 코드를 바꾸기 전에 Git 또는 별도 폴더로 현재 코드를 보존합니다.

## 예상 결과와 제한

센서 카드는 현재값, 그래프는 최근 밝기 60개, 아래는 마지막 정상 수신 시각입니다. 그래프는 현재 탭의 메모리만 사용하며 새로고침하면 사라집니다. 온습도 실패 `null`은 `—`로 표시합니다. 버튼은 매초 현재 상태라 짧은 누름을 놓칠 수 있습니다. LCD는 보드가 밝기·LED 상태를 표시하며, 화면에서 임의 문장을 보내는 명령은 없습니다. ACK는 프로그램 적용 응답이고 실제 LED 광출력 측정은 아닙니다. P01의 자동 모드는 통신이 끊겨도 계속될 수 있습니다.

## 오류 해결

| 현상 | 확인 순서 | 복구 |
| --- | --- | --- |
| 연결 기능이 없음 | 브라우저·주소·정책 | PC Chrome/Edge, HTTPS 또는 localhost, 연습 데이터로 계속 |
| 포트를 열 수 없음 | 시리얼 모니터·다른 탭·케이블 | 점유 프로그램 닫기, 데이터 케이블, 다시 연결 |
| 숫자가 계속 — | P01 업로드·115200·전원 | 통신 기록의 필드 거절 확인, P01 재업로드 |
| 온습도만 — | 센서 종류·D4·GND·읽기 주기 | 배선 전원 끄고 점검, 센서 안정 대기 |
| LED 응답은 있는데 안 켜짐 | D8·1k 저항·극성·빵판 금속판 | 전원 끄고 P01 그림과 비교 |
| 명령 시간 초과 | USB·보드 재시작·코드 | 적용 여부 미확인으로 기록. 임의 자동 재전송 금지 |
| 자동이 안 꺼짐 | 기준 사이 값인지 확인 | 두 경계 이해, STOP으로 자동 해제 |

## 확인 근거

[Chrome 공식 Web Serial 안내](https://developer.chrome.com/docs/capabilities/serial). 실제 회로·장치 허용창·USB 입출력은 수업 전 강사 PC에서 별도로 확인합니다. 연습 데이터 화면과 자동화의 가짜 통신 시험은 실물 검증과 다릅니다.
