# Claude / Figma 디자인 전달문 · P01

아래 빈칸을 채우고 내 스케치 이미지와 index.html, style.css, dashboard.js를 함께 제공합니다. MD는 글로 쓴 명세이며 파일을 전달하는 것만으로 실제 USB 연결 권한이 생기지 않습니다.

## 내가 정할 것

- 작품명: 작업실 조명
- 사용할 사람: 집에서 공부하는 나
- 해결할 상황: 어두워졌는지 확인하고 LED를 켜고 싶다.
- 가장 큰 정보: 밝기 원시값과 LED 보드 보고 상태
- 추가 표시: 온도 °C, 습도 %, 최근 밝기 변화, 연결 상태·마지막 정상 수신
- 스타일: 밝은 바탕, 짙은 글자, 초록 강조, 여백 충분한 계기판
- 스케치 첨부: 상단 연결 / 가운데 현재값 / 아래 변화·제어

## 처음 요청할 문장

첨부한 스케치로 PC와 휴대폰 폭에서 읽기 쉬운 대시보드 디자인 두 안을 제시해 주세요. 누구에게 어떤 판단을 돕는지 먼저 설명하고, 색·글자·여백·현재값과 이력의 구별을 비교해 주세요. 모든 표시값은 디자인 예시임을 써 주세요. 아직 통신 코드는 바꾸지 마세요. 장식이나 센서 수를 늘리는 것보다 핵심 상태와 제어 결과가 잘 보이게 해 주세요.

## 구현할 때의 요청문

선택한 안을 현재 HTML/CSS에 적용해 주세요. 기존 요소 id, 버튼 data-command, 입력 name/값의 의미, 스크립트 연결을 유지하세요. 보드 핀·115200 통신·JSON 필드·명령 형식은 수정하지 마세요. dashboard.js의 transport/parser/command/timeout 동작을 그대로 두세요. 연결 전·대기·정상·센서 실패·오래됨·명령 대기·명령 거절·응답 미확인 상태를 모두 유지하세요. 현재 없는 센서·모터·LCD 문장 제어·클라우드 API·랜덤 실제값을 만들지 마세요. 바꾼 파일과 확인 순서를 알려주세요. 배경색만 다른 두 안 대신 정보 배치가 다른 안을 비교하세요.

## 보드 계약

P01 UNO: LED D8, 버튼 D2(INPUT_PULLUP), pot A0, CdS A1, DHT11 D4, I2C LCD A4/A5. 핀 재배치는 이 디자인 작업의 범위가 아닙니다. 단품 K코드 9600과 섞지 않습니다. 줄 단위 115200, UTF-8/ASCII 숫자·명령, LF 종료입니다.

수신 상태 예:

```json
{"v":1,"type":"state","profile":"P01","request":0,"ms":5000,"pot_raw":512,"light_raw":320,"button_pressed":false,"led":1,"auto":true,"lcd_ready":true,"temperature_c":24.3,"humidity_pct":48.0}
```

온습도는 `null`일 수 있습니다. light_raw와 pot_raw는 0~1023 원시값이며 물리 단위가 아닙니다. button_pressed는 현재 상태로 누적 횟수가 아닙니다. 최근 60개 그래프는 브라우저 메모리이며 DB 저장이 아닙니다.

명령은 요청번호 1~65535 + 공백 + 명령 + LF입니다. LED 0/1, AUTO 0/1, THRESH low high(0≤low<high≤1023), STOP, STATUS, PING을 지원합니다. 이 화면은 AUTO 1과 STOP을 제공합니다. `1 LED 1`의 응답은 `{"v":1,"type":"ack","request":1,"applied":true}`입니다. 성공은 해당 요청번호의 ACK가 온 뒤 표시하고, 실제 점등은 별도 확인합니다. 응답이 없으면 ‘적용 여부 미확인’이며 자동 재전송하지 않습니다.

## Figma MCP로 전달할 때

내가 접근 가능한 파일의 **선택한 프레임 링크**와 이 문서를 함께 줍니다. ‘이 프레임의 글자·색·여백·컴포넌트 구조를 읽고 기존 화면에 반영하되 위 계약과 DOM id를 유지해 달라’고 요청합니다. 캔버스에 새 디자인을 만드는 도구와 Figma 디자인을 읽어 코드로 구현하는 도구의 방향을 구별합니다. 사용 가능 도구·파일 권한·요금제·호출 한도는 다를 수 있습니다. 연결이 안 되면 프레임 스크린샷과 이 문서로 진행합니다.

## 완료 확인

수정 전후 화면을 나란히 봅니다. 연습 데이터로 null과 제어 피드백을 확인하고, 실제 USB 모드에서는 가변저항 변화·LED·연결 해제를 별도 확인합니다. 실제 연결을 실행하지 못한 결과는 ‘디자인/연습 확인’으로 제출합니다. 보기 좋다는 이유로 실물 성공으로 기록하지 않습니다.
