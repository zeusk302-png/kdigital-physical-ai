# 화면과 코드 연결 · 줄별 읽기

`mini-display.html`은 USB 없는 독립 예제입니다. 압축을 푼 폴더에서 이 파일을 더블클릭해 열 수 있습니다. 메모장이나 코드 편집기로 같은 파일을 열어 수정합니다. 예제 전체는 짧지만 **실제 Web Serial 통신은 포함하지 않습니다.**

## 무엇을 만드는가

처음에는 밝기 입력 320/1023이 보이고, 버튼을 누르면 센서값 없음으로 바뀝니다. 값과 화면 자리를 연결하는 원리를 봅니다. 문서 시작부터 화면과 동작까지 담은 완성 파일입니다.

| 코드 | 쉬운 뜻 |
| --- | --- |
| `<!doctype html>` | 브라우저에 HTML 문서임을 알립니다. |
| `<html lang="ko">` | 문서 언어가 한국어임을 알립니다. |
| `<meta charset="utf-8">` | 한글을 읽을 문자 형식을 지정합니다. |
| `<title>...</title>` | 브라우저 탭 제목입니다. |
| `<p>...</p>` | 한 문단, 꺾쇠 태그 사이가 표시 내용입니다. |
| `<strong id="value">—</strong>` | 값을 보여줄 자리의 이름을 value로 붙입니다. 닫는 태그는 `/`가 있습니다. |
| `<button id="missing">...</button>` | 누를 수 있는 버튼에 missing이라는 이름을 붙입니다. |
| `<script>...</script>` | 안에 JavaScript 동작 코드를 적습니다. |
| `const raw = 320;` | raw라는 이름에 320을 보관합니다. `=`는 넣기, `;`는 문장 끝입니다. |
| `document.getElementById('value')` | 이 문서에서 id가 value인 자리를 찾습니다. 이름과 따옴표가 일치해야 합니다. |
| `function show(value) { ... }` | 값을 받아 표시하는 일에 show라는 이름을 붙입니다. 소괄호는 받을 값, 중괄호는 할 일입니다. |
| `target.textContent = ...` | 찾은 자리의 글자를 바꿉니다. HTML태그를 실행하는 대신 글자로 넣습니다. |
| `value === null` | 값이null인지 비교합니다. `===`는 비교,`=`는 넣기입니다. |
| `조건 ? A : B` | 조건이 맞으면 A, 아니면 B를 고릅니다. |
| `value + ' / 1023'` | 숫자 뒤에 범위 글자를 붙입니다. |
| `addEventListener('click', ...)` | 버튼을 클릭했을 때 할 일을 등록합니다. |
| `() => show(null)` | 클릭하면 null을 전달해 show를 실행합니다. |
| `show(raw);` | 처음에는 raw의 320을 표시합니다. |

## 직접 수정 → 예상 → 실행

1. 파일을 별도 폴더에 복사해 원본을 보존합니다.
2. `const raw = 320;`의 320을 600으로 고칩니다. 예상 표시를 적습니다.
3. Ctrl+S로 저장하고 브라우저에서 새로고침합니다. ‘600 / 1023’인지 확인합니다.
4. 버튼을 누릅니다. 센서값 없음으로 바뀌는지 확인합니다.
5. 첫 값을 0으로 바꾸면 ‘0 / 1023’입니다. null과 달리 실제로 값 0을 표시합니다.

흔한 오류: 파일이 mini-display.html.txt면 글만 보일 수 있습니다. 확장명 표시를 켜고 .html로 저장합니다. id를 고쳤다면 getElementById 안 글자도 맞춰야 합니다. 따옴표·중괄호를 지웠다면 원본과 비교하고 그 부분만 복구합니다. 내가 바꾼 줄부터 확인합니다.

## 큰 예제로 옮기기

실제 dashboard.js는 이 원리 앞에 USB 수신·JSON 검사, 뒤에 명령·요청 응답·시간 초과가 붙습니다. `validState`는 P01인지와 필드를 검사하고, `ingest`는 한 줄 자료를 처리합니다. `render`는 현재 화면, `command`는 명령 전송, `cleanup`은 연결 정리를 맡습니다. 디자인 수정은 HTML/CSS부터 진행하고, 연결 코드를 바꾸면 관련 상태를 다시 확인합니다.
