# A05 · 다시 대입하면 현재 값이 바뀐다

아래 코드에서 첫 출력은 22.5이고, 새 대입 다음 출력은 24.0입니다. 이 순서를 작업 전·작업 후 카드로 나누면 값 변화가 보입니다.

## 전체 시연 코드


```python
temperature_c = 22.5
print(temperature_c)
temperature_c = 24.0
print(temperature_c)
```
