# A10 · 비교 결과는 참 또는 거짓

온도 24.0과 기준 24.0에서 >는 False, >=는 True입니다. 참·거짓은 비교 질문의 답이며 온도 자체가 참이나 거짓이라는 의미가 아닙니다.

## 전체 시연 코드


```python
temperature_c = 24.0
limit = 24.0
print(temperature_c > limit)
print(temperature_c >= limit)
print(temperature_c == limit)
```
