# A04 · 변수는 값에 붙인 이름

location과 temperature_c를 출력하면 이름 자체의 글자가 아니라 그 이름이 가리키는 값이 나옵니다. print("location")처럼 따옴표를 붙이면 이름을 찾지 않고 글자 location을 보여 줍니다.

## 전체 시연 코드


```python
location = "입구"
temperature_c = 22.5
print(location)
print(temperature_c)
print("location")
```
