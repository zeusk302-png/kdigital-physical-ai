# A14 · for로 목록을 한 항목씩 읽기

목록의 첫 22.5가 temperature_c가 되어 출력되고, 다음 차례에는 24.0, 그다음에는 23.5가 됩니다. 반복이 끝난 뒤 들여쓰기 없는 완료가 한 번 출력됩니다.

## 전체 시연 코드


```python
temperatures = [22.5, 24.0, 23.5]
for temperature_c in temperatures:
    print(temperature_c)
print("완료")
```
