# A09 · 연산과 괄호로 작은 계산 만들기

22.5, 24.0, 23.5의 합은 70.0이며 세 값의 평균은 23.333…입니다. round는 표시를 짧게 하는 데 쓰지만 원래 센서가 정확히 두 자리까지 측정했다는 뜻은 아닙니다.

## 전체 시연 코드


```python
total = 22.5 + 24.0 + 23.5
count = 3
average = total / count
print(total)
print(round(average, 2))
```
