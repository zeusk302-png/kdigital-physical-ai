# C10 · 리스트에 여러 값 담기

[개념 목차로 돌아가기](#/sessions/2026-10-14/lesson)

## 무엇이고 왜 필요한가

리스트는 여러 값을 순서대로 보관합니다. 개별 변수를 계속 늘리는 대신 한 목록에 담아 위치로 읽습니다.

## 구성요소와 기호

| 구성요소 | 뜻과 사용 방법 |
|---|---|
| `[ ]` | 리스트를 만드는 대괄호입니다. 안의 값은 쉼표로 구분합니다. |
| `목록[위치]` | 0부터 시작하는 번호로 값을 읽거나 수정합니다. 마지막 위치는 길이보다 1 작습니다. |
| `append(value)` | 목록 끝에 새 값을 추가합니다. append의 반환값으로 목록을 덮어쓰지 않습니다. |
| `copy()` | 이 단원의 숫자 목록을 별도로 복사합니다. 중첩 목록의 복사는 다음 과정에서 다룹니다. |

## 실행 과정 따라가기

[22, 24, 20]에서 0번은 22입니다. 1번을 25로 바꾸고 26을 추가하면 [22, 25, 20, 26]이 됩니다.

```python
# 괄호 ()는 함수에 전달할 값을 묶습니다. 따옴표는 문자열의 범위를 나타냅니다.
# 코드는 위에서 아래로 실행됩니다. 먼저 결과를 예상한 뒤 실행하세요.
# ---------------------------------------------------------------------
# [구성요소]
# [ ]: 리스트를 만드는 대괄호입니다. 안의 값은 쉼표로 구분합니다.
# 목록[위치]: 0부터 시작하는 번호로 값을 읽거나 수정합니다. 마지막 위치는
# 길이보다 1 작습니다.
# append(value): 목록 끝에 새 값을 추가합니다. append의
# 반환값으로 목록을 덮어쓰지 않습니다.
# copy(): 이 단원의 숫자 목록을 별도로 복사합니다. 중첩 목록의 복사는
# 다음 과정에서 다룹니다.
# [실행 과정]
# [22, 24, 20]에서 0번은 22입니다. 1번을 25로 바꾸고 26을
# 추가하면 [22, 25, 20, 26]이 됩니다.
# [직접 확장할 문제]
# 가격 세 개를 리스트에 담고 두 번째 가격을 수정한 뒤 새 상품 가격을
# 추가하세요. 길이도 출력하세요.
# ---------------------------------------------------------------------
temperatures = [22, 24, 20]
print("처음:", temperatures)
print("첫 값:", temperatures[0])
temperatures[1] = 25       # 두 번째 위치의 값을 수정합니다.
temperatures.append(26)   # 끝에 새 값을 추가합니다.
print("변경 후:", temperatures)
print("개수:", len(temperatures))
```
