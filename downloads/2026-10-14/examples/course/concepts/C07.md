# C07 · 문자열 정리

[개념 목차로 돌아가기](#/sessions/2026-10-14/lesson)

## 무엇이고 왜 필요한가

입력에는 공백·대소문자·금액 기호가 섞일 수 있습니다. 메서드는 값 뒤에 점을 붙여 사용하는 기능입니다.

## 구성요소와 기호

| 구성요소 | 뜻과 사용 방법 |
|---|---|
| `strip()` | 양끝 공백을 제거합니다. 중간 공백을 모두 지우는 기능은 아닙니다. |
| `lower()` | 영문 대문자를 소문자로 바꿉니다. 결과는 새 문자열이므로 사용할 변수에 저장합니다. |
| `replace(old, new)` | 지정한 글자를 다른 글자로 바꿉니다. 빈 문자열로 바꾸면 해당 글자를 제거합니다. |
| `순서` | 정리 → 숫자 변환 → 계산 순서입니다. 숫자로 바꿀 수 없는 글자는 예외 단원에서 처리합니다. |

## 실행 과정 따라가기

"  START  " → strip 후 "START" → lower 후 "start"입니다. 처음부터 한 줄로 묶지 않고 단계별 값을 확인합니다.

## 명령 글자 정리

실행 전에 출력 결과를 예상하세요. 주석을 읽고 각 줄의 역할을 설명해 보세요.

```python
# =====================================================================
# C07 · 문자열 정리 / 예제 1: 명령 글자 정리
# =====================================================================
# 무엇을 배우나요? 입력에는 공백·대소문자·금액 기호가 섞일 수 있습니다. 메서드는 값 뒤에 점을 붙여 사용하는 기능입니다.
# 이 파일은 설명과 실행 코드를 함께 읽는 학습용 Python 파일입니다.
# # 뒤의 내용은 주석입니다. 실행되지 않으며 편집기에 따라 색이 다릅니다.
# 저장: course/concepts/C07_01_normal.py · UTF-8 · .py.txt가 아닌 .py
# 실행: course 폴더의 터미널에서 python -X utf8 concepts/C07_01_normal.py
# 터미널 명령과 예상 출력은 이 파일에 붙여 넣지 않습니다.
# 괄호 ()는 함수에 전달할 값을 묶습니다. 따옴표는 문자열의 범위를 나타냅니다.
# 코드는 위에서 아래로 실행됩니다. 먼저 결과를 예상한 뒤 실행하세요.
# ---------------------------------------------------------------------
raw = "  START  "
# 양끝 공백이 보이도록 출력에서 대괄호를 둘러줍니다.
print(f"원본: [{raw}]")
trimmed = raw.strip()
print(f"공백 제거: [{trimmed}]")
command = trimmed.lower()
print(f"소문자: [{command}]")
```

## 금액과 할인율 정리

실행 전에 출력 결과를 예상하세요. 주석을 읽고 각 줄의 역할을 설명해 보세요.

```python
# =====================================================================
# C07 · 문자열 정리 / 예제 2: 금액과 할인율 정리
# =====================================================================
# 무엇을 배우나요? 입력에는 공백·대소문자·금액 기호가 섞일 수 있습니다. 메서드는 값 뒤에 점을 붙여 사용하는 기능입니다.
# 이 파일은 설명과 실행 코드를 함께 읽는 학습용 Python 파일입니다.
# # 뒤의 내용은 주석입니다. 실행되지 않으며 편집기에 따라 색이 다릅니다.
# 저장: course/concepts/C07_02_normal.py · UTF-8 · .py.txt가 아닌 .py
# 실행: course 폴더의 터미널에서 python -X utf8 concepts/C07_02_normal.py
# 터미널 명령과 예상 출력은 이 파일에 붙여 넣지 않습니다.
# 괄호 ()는 함수에 전달할 값을 묶습니다. 따옴표는 문자열의 범위를 나타냅니다.
# 코드는 위에서 아래로 실행됩니다. 먼저 결과를 예상한 뒤 실행하세요.
# ---------------------------------------------------------------------
price_text = "12,000원"
rate_text = "15%"
# 한 번에 연결하지 않고 각 단계 결과를 변수에 저장합니다.
no_comma = price_text.replace(",", "")
digits = no_comma.replace("원", "")
price = int(digits)
rate_digits = rate_text.replace("%", "")
rate = int(rate_digits) / 100
discounted = price * (1 - rate)
print(f"할인 후: {discounted:.0f}원")
```
