# C15 · 잘못된 입력과 예외 처리

[개념 목차로 돌아가기](#/sessions/2026-10-14/lesson)

## 무엇이고 왜 필요한가

예외는 실행 중 계속 진행할 수 없는 상황입니다. 예상한 입력 변환 실패를 처리하면 안내 후 다시 입력받을 수 있습니다.

## 구성요소와 기호

| 구성요소 | 뜻과 사용 방법 |
|---|---|
| `try:` | 실패할 수 있는 변환을 시도하는 코드 묶음입니다. |
| `except ValueError:` | 숫자로 바꿀 수 없는 값 같은 해당 예외만 처리합니다. |
| `입력 오류와 범위 오류` | 문자를 숫자로 변환하는 실패와 숫자가 허용 범위 밖인 문제는 다른 검사입니다. |
| `Traceback` | 마지막 줄에서 오류 종류를 읽고 파일명과 줄 번호로 원인 위치를 확인합니다. |

## 실행 과정 따라가기

abc 입력 → int 변환 실패 → except에서 안내 → continue로 다시 입력합니다. -1은 변환 성공 후 범위 검사에서 거절합니다.

## 한 번 변환 시도

실행 전에 출력 결과를 예상하세요. 주석을 읽고 각 줄의 역할을 설명해 보세요.

```python
# =====================================================================
# C15 · 잘못된 입력과 예외 처리 / 예제 1: 한 번 변환 시도
# =====================================================================
# 무엇을 배우나요? 예외는 실행 중 계속 진행할 수 없는 상황입니다. 예상한 입력
# 변환 실패를 처리하면 안내 후 다시 입력받을 수 있습니다.
# 이 파일은 설명과 실행 코드를 함께 읽는 학습용 Python 파일입니다.
# # 뒤의 내용은 주석입니다. 실행되지 않으며 편집기에 따라 색이 다릅니다.
# 저장: course/concepts/C15_01_normal.py · UTF-8
# · .py.txt가 아닌 .py
# 실행: course 폴더의 터미널에서 python -X utf8
# concepts/C15_01_normal.py
# 터미널 명령과 예상 출력은 이 파일에 붙여 넣지 않습니다.
# 괄호 ()는 함수에 전달할 값을 묶습니다. 따옴표는 문자열의 범위를 나타냅니다.
# 코드는 위에서 아래로 실행됩니다. 먼저 결과를 예상한 뒤 실행하세요.
# ---------------------------------------------------------------------
# [구성요소]
# try:: 실패할 수 있는 변환을 시도하는 코드 묶음입니다.
# except ValueError:: 숫자로 바꿀 수 없는 값 같은 해당 예외만
# 처리합니다.
# 입력 오류와 범위 오류: 문자를 숫자로 변환하는 실패와 숫자가 허용 범위 밖인
# 문제는 다른 검사입니다.
# Traceback: 마지막 줄에서 오류 종류를 읽고 파일명과 줄 번호로 원인
# 위치를 확인합니다.
# [실행 과정]
# abc 입력 → int 변환 실패 → except에서 안내 → continue로
# 다시 입력합니다. -1은 변환 성공 후 범위 검사에서 거절합니다.
# [직접 확장할 문제]
# 300원 자판기에 잘못된 글자나 음수를 넣으면 다시 묻고, 300원 이상이면
# 거스름돈을 출력하세요.
# ---------------------------------------------------------------------
raw = input("정수: ")
try:
    number = int(raw)
except ValueError:
    print("정수로 바꿀 수 없습니다.")
else:
    # else는 try가 예외 없이 끝났을 때 실행합니다.
    print("입력한 수:", number)
```

# ---------------------------------------------------------------------
# [구성요소]
# try:: 실패할 수 있는 변환을 시도하는 코드 묶음입니다.
# except ValueError:: 숫자로 바꿀 수 없는 값 같은 해당 예외만

# 위치를 확인합니다.
# [실행 과정]

# ---------------------------------------------------------------------

    raw = input("수량(0 이상 정수): ")

    if quantity < 0:
        print("0 이상이어야 합니다.")
        continue
    break
print("확정 수량:", quantity)
