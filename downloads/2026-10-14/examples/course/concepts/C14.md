# C14 · while·break·continue

[개념 목차로 돌아가기](#/sessions/2026-10-14/lesson)

## 무엇이고 왜 필요한가

while은 조건이 참인 동안 반복합니다. for처럼 정해진 자료를 읽는 대신 종료 조건과 값 변화가 중요합니다.

## 구성요소와 기호

| 구성요소 | 뜻과 사용 방법 |
|---|---|
| `while 조건:` | 본문 실행 전에 매번 조건을 다시 확인합니다. |
| `값 갱신` | 반복이 끝나도록 재고·횟수 등이 바뀌어야 합니다. 무한 반복은 터미널에서 Ctrl+C로 중지합니다. |
| `break` | 가장 가까운 반복문을 즉시 끝냅니다. |
| `continue` | 이번 반복의 남은 부분을 건너뛰고 다음 조건 검사로 돌아갑니다. |

## 실행 과정 따라가기

재고 3에서 한 번 판매할 때마다 1씩 줄이면 3 → 2 → 1 → 0입니다. 0에서 조건이 거짓이 되어 종료됩니다.

# 판매

# 무엇을 배우나요? while은 조건이 참인 동안 반복합니다. for처럼 정해진

# 터미널 명령과 예상 출력은 이 파일에 붙여 넣지 않습니다.
# 괄호 ()는 함수에 전달할 값을 묶습니다. 따옴표는 문자열의 범위를 나타냅니다.
# 코드는 위에서 아래로 실행됩니다. 먼저 결과를 예상한 뒤 실행하세요.
# ---------------------------------------------------------------------
# [구성요소]
# while 조건:: 본문 실행 전에 매번 조건을 다시 확인합니다.
# 값 갱신: 반복이 끝나도록 재고·횟수 등이 바뀌어야 합니다. 무한 반복은
# 터미널에서 Ctrl+C로 중지합니다.
# break: 가장 가까운 반복문을 즉시 끝냅니다.
# continue: 이번 반복의 남은 부분을 건너뛰고 다음 조건 검사로 돌아갑니다.
# [실행 과정]
# 재고 3에서 한 번 판매할 때마다 1씩 줄이면 3 → 2 → 1 → 0입니다.
# 0에서 조건이 거짓이 되어 종료됩니다.
# [직접 확장할 문제]
# 잔액 1000원에서 300원씩 구매하고 잔액이 부족하면 끝내세요. 마지막 잔액을
# 출력하세요.
# ---------------------------------------------------------------------
stock = 3
# 종료 방법을 먼저 확인하세요. 터미널에서는 Ctrl+C로 중지합니다.
while stock > 0:
    stock = stock - 1
    print("남은 재고:", stock)
print("판매 종료")
# stock 감소 줄을 지우는 오류 실험은 중지 방법을 이해한 뒤에만 합니다.
```

# =====================================================================
# C14 · while·break·continue / 예제 2: 종료 명령까지 입력

# 자료를 읽는 대신 종료 조건과 값 변화가 중요합니다.
# 이 파일은 설명과 실행 코드를 함께 읽는 학습용 Python 파일입니다.
# # 뒤의 내용은 주석입니다. 실행되지 않으며 편집기에 따라 색이 다릅니다.
# 저장: course/concepts/C14_02_normal.py · UTF-8
# · .py.txt가 아닌 .py
# 실행: course 폴더의 터미널에서 python -X utf8
# concepts/C14_02_normal.py
# 터미널 명령과 예상 출력은 이 파일에 붙여 넣지 않습니다.
# 괄호 ()는 함수에 전달할 값을 묶습니다. 따옴표는 문자열의 범위를 나타냅니다.
# 코드는 위에서 아래로 실행됩니다. 먼저 결과를 예상한 뒤 실행하세요.
# ---------------------------------------------------------------------
# [구성요소]
# while 조건:: 본문 실행 전에 매번 조건을 다시 확인합니다.
# 값 갱신: 반복이 끝나도록 재고·횟수 등이 바뀌어야 합니다. 무한 반복은
# 터미널에서 Ctrl+C로 중지합니다.
# break: 가장 가까운 반복문을 즉시 끝냅니다.
# continue: 이번 반복의 남은 부분을 건너뛰고 다음 조건 검사로 돌아갑니다.
# [실행 과정]
# 재고 3에서 한 번 판매할 때마다 1씩 줄이면 3 → 2 → 1 → 0입니다.
# 0에서 조건이 거짓이 되어 종료됩니다.
# [직접 확장할 문제]
# 잔액 1000원에서 300원씩 구매하고 잔액이 부족하면 끝내세요. 마지막 잔액을
# 출력하세요.
# ---------------------------------------------------------------------
while True:
    command = input("명령(start/skip/done): ").strip().lower()
    if command == "done":
        break                  # 반복을 완전히 끝냅니다.
    if command == "skip":
        continue               # 이번 처리와 출력을 건너뜁니다.
    print("처리:", command)
print("종료")
```
