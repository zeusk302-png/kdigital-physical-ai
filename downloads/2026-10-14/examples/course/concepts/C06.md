# C06 · input과 형변환

[개념 목차로 돌아가기](#/sessions/2026-10-14/lesson)

## 무엇이고 왜 필요한가

input은 입력을 기다렸다가 문자열로 돌려줍니다. 숫자 계산을 하려면 필요한 종류로 바꿔야 합니다.

## 구성요소와 기호

| 구성요소 | 뜻과 사용 방법 |
|---|---|
| `input(prompt)` | 안내 글자를 보여 주고 사용자가 Enter를 누를 때까지 기다립니다. |
| `int(text)` | 정수 형태의 문자열을 정수로 바꿉니다. "2.5"나 "천원"은 정수로 변환되지 않습니다. |
| `float(text)` | 소수 입력을 숫자로 바꿉니다. 잘못된 입력 처리 방법은 예외 단원에서 배웁니다. |
| `입력과 출력` | 사용자가 입력한 글자와 프로그램의 출력은 구별합니다. 예상 출력에는 키보드 입력 자체를 생략합니다. |

## 실행 과정 따라가기

첫 입력 3은 문자열 "3"입니다. int로 바꾼 다음 5와 더하면 8입니다. 글자끼리 연결하면 "35"입니다.

## 문자열 연결과 숫자 덧셈

실행 전에 출력 결과를 예상하세요. 주석을 읽고 각 줄의 역할을 설명해 보세요.

```python
# =====================================================================
# C06 · input과 형변환 / 예제 1: 문자열 연결과 숫자 덧셈
# =====================================================================
# 무엇을 배우나요? input은 입력을 기다렸다가 문자열로 돌려줍니다. 숫자
# 계산을 하려면 필요한 종류로 바꿔야 합니다.
# 이 파일은 설명과 실행 코드를 함께 읽는 학습용 Python 파일입니다.
# # 뒤의 내용은 주석입니다. 실행되지 않으며 편집기에 따라 색이 다릅니다.
# 저장: course/concepts/C06_01_normal.py · UTF-8
# · .py.txt가 아닌 .py
# 실행: course 폴더의 터미널에서 python -X utf8
# concepts/C06_01_normal.py
# 터미널 명령과 예상 출력은 이 파일에 붙여 넣지 않습니다.
# 괄호 ()는 함수에 전달할 값을 묶습니다. 따옴표는 문자열의 범위를 나타냅니다.
# 코드는 위에서 아래로 실행됩니다. 먼저 결과를 예상한 뒤 실행하세요.
# ---------------------------------------------------------------------
# [구성요소]
# input(prompt): 안내 글자를 보여 주고 사용자가 Enter를 누를
# 때까지 기다립니다.
# int(text): 정수 형태의 문자열을 정수로 바꿉니다. "2.5"나
# "천원"은 정수로 변환되지 않습니다.
# float(text): 소수 입력을 숫자로 바꿉니다. 잘못된 입력 처리 방법은
# 예외 단원에서 배웁니다.
# 입력과 출력: 사용자가 입력한 글자와 프로그램의 출력은 구별합니다. 예상
# 출력에는 키보드 입력 자체를 생략합니다.
# [실행 과정]
# 첫 입력 3은 문자열 "3"입니다. int로 바꾼 다음 5와 더하면 8입니다.
# 글자끼리 연결하면 "35"입니다.
# [직접 확장할 문제]
# 단가와 수량을 각각 입력받아 금액을 출력하세요. 수량 0일 때 결과도 확인하세요.
# ---------------------------------------------------------------------
first = input("첫 수: ")
second = input("둘째 수: ")
# raw 입력은 둘 다 문자열입니다.
print("문자 연결:", first + second)
first_number = int(first)
second_number = int(second)
print("숫자 합:", first_number + second_number)
```

```

**예상 출력** — 키보드 입력 자체는 제외한 프로그램 출력입니다. input 안내가 줄바꿈 없이 이어지는 경우도 있습니다.

숫자 합: 8
```
