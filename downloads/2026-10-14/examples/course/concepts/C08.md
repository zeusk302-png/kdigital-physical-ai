# C08 · 비교와 참·거짓

[개념 목차로 돌아가기](#/sessions/2026-10-14/lesson)

## 무엇이고 왜 필요한가

비교는 True 또는 False를 만듭니다. 조건문에 들어가기 전에 조건식만 출력해 판단이 맞는지 확인합니다.

## 구성요소와 기호

| 구성요소 | 뜻과 사용 방법 |
|---|---|
| `== / !=` | 같은지·다른지 비교합니다. =는 대입이며 비교와 다릅니다. |
| `> >= < <=` | 초과·이상·미만·이하입니다. 기준값과 같은 값의 포함 여부가 다릅니다. |
| `and / or` | and는 두 조건 모두 참, or는 하나 이상 참이면 참입니다. |
| `not` | 참·거짓을 반대로 만듭니다. True는 따옴표 없는 bool 값입니다. |

## 실행 과정 따라가기

28 > 28은 False이고 28 >= 28은 True입니다. 괄호로 각각의 비교를 묶어 논리 판단을 읽습니다.
