## 무엇이고 왜 필요한가

같은 25라도 숫자 25와 글자 "25"는 다르게 처리됩니다. 자료형은 값의 종류이고 type은 그 종류를 확인하는 함수입니다.

## 구성요소와 기호

| 구성요소 | 뜻과 사용 방법 |
|---|---|
| `int / float` | int는 정수, float는 소수 부분이 있는 수 등을 표현합니다. 3.0도 float입니다. |
| `str / bool` | str은 문자열, bool은 True 또는 False입니다. True와 "True"는 다릅니다. |
| `+ - * /` | 덧셈·뺄셈·곱셈·나눗셈입니다. 여기서 정수의 / 결과도 float입니다. |
| `// % **` | //는 내림 나눗셈, %는 나머지, **는 거듭제곱입니다. float를 쓰면 // 결과도 float일 수 있습니다. |

## 실행 과정 따라가기

125 // 60은 2, 125 % 60은 5입니다. (72 - 32) * 5 / 9는 괄호 속 뺄셈을 먼저 수행합니다.

## 자료형과 연산 비교

실행 전에 출력 결과를 예상하세요. 주석을 읽고 각 줄의 역할을 설명해 보세요.

```python

# C03 · 숫자·자료형·계산 / 예제 1: 자료형과 연산 비교
# =====================================================================
# 무엇을 배우나요? 같은 25라도 숫자 25와 글자 "25"는 다르게 처리됩니다. 자료형은 값의 종류이고 type은 그 종류를 확인하는 함수입니다.
# 이 파일은 설명과 실행 코드를 함께 읽는 학습용 Python 파일입니다.
# # 뒤의 내용은 주석입니다. 실행되지 않으며 편집기에 따라 색이 다릅니다.
# 저장: course/concepts/C03_01_normal.py · UTF-8 · .py.txt가 아닌 .py
# 실행: course 폴더의 터미널에서 python -X utf8 concepts/C03_01_normal.py
# 터미널 명령과 예상 출력은 이 파일에 붙여 넣지 않습니다.
# 괄호 ()는 함수에 전달할 값을 묶습니다. 따옴표는 문자열의 범위를 나타냅니다.
# 코드는 위에서 아래로 실행됩니다. 먼저 결과를 예상한 뒤 실행하세요.
# ---------------------------------------------------------------------
# type의 결과에서 int, float, str, bool이라는 종류 이름을 읽습니다.
print(type(25))
print(type(3.0))
print(type("25"))
print(type(True))
# 숫자 +는 덧셈이지만 문자열 +는 연결입니다.
print(3 + 5)
print("3" + "5")
print(10 / 2)      # 나누어떨어져도 float인 5.0입니다.
print(10.0 // 3)   # 피연산자에 float가 있으므로 결과는 3.0입니다.
print(2 ** 3)      # 2를 세 번 곱합니다.
```
