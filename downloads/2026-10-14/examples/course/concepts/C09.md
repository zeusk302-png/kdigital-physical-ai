# C09 · if·else·elif 조건문

[개념 목차로 돌아가기](#/sessions/2026-10-14/lesson)

## 무엇이고 왜 필요한가

조건문은 판단 결과에 따라 실행할 코드를 고릅니다. 조건식만 출력하던 단계에서 실제 행동을 나누는 단계로 넘어갑니다.

## 구성요소와 기호

| 구성요소 | 뜻과 사용 방법 |
|---|---|
| `if 조건:` | 조건이 참이면 바로 아래 들여쓴 코드가 실행됩니다. |
| `else:` | 앞 조건이 거짓일 때 실행합니다. else 뒤에는 조건을 붙이지 않습니다. |
| `elif 조건:` | 앞 조건이 거짓이면 다음 조건을 검사합니다. 처음 참인 가지 하나를 실행합니다. |
| `들여쓰기` | 같은 묶음은 같은 깊이를 씁니다. 예제에서는 공백 네 칸을 사용합니다. |

## 실행 과정 따라가기

score가 95이면 90 이상에서 A를 선택하고 뒤의 80·70·60 조건을 실행하지 않습니다. 낮은 기준부터 검사하면 잘못 분류됩니다.

## 짝수·홀수

실행 전에 출력 결과를 예상하세요. 주석을 읽고 각 줄의 역할을 설명해 보세요.

```python
# =====================================================================
# C09 · if·else·elif 조건문 / 예제 1: 짝수·홀수
# =====================================================================
# 무엇을 배우나요? 조건문은 판단 결과에 따라 실행할 코드를 고릅니다. 조건식만 출력하던 단계에서 실제 행동을 나누는 단계로 넘어갑니다.
# 이 파일은 설명과 실행 코드를 함께 읽는 학습용 Python 파일입니다.
# # 뒤의 내용은 주석입니다. 실행되지 않으며 편집기에 따라 색이 다릅니다.
# 저장: course/concepts/C09_01_normal.py · UTF-8 · .py.txt가 아닌 .py
# 실행: course 폴더의 터미널에서 python -X utf8 concepts/C09_01_normal.py
# 터미널 명령과 예상 출력은 이 파일에 붙여 넣지 않습니다.
# 괄호 ()는 함수에 전달할 값을 묶습니다. 따옴표는 문자열의 범위를 나타냅니다.
# 코드는 위에서 아래로 실행됩니다. 먼저 결과를 예상한 뒤 실행하세요.
# ---------------------------------------------------------------------
number = 7
# 2로 나눈 나머지가 0이면 짝수입니다.
if number % 2 == 0:
    print("짝수")
else:
    print("홀수")
# 0과 8로 바꿔 다른 가지가 실행되는지 확인하세요.
```

## 점수 등급

실행 전에 출력 결과를 예상하세요. 주석을 읽고 각 줄의 역할을 설명해 보세요.

```python
# =====================================================================
# C09 · if·else·elif 조건문 / 예제 2: 점수 등급
# =====================================================================
# 무엇을 배우나요? 조건문은 판단 결과에 따라 실행할 코드를 고릅니다. 조건식만 출력하던 단계에서 실제 행동을 나누는 단계로 넘어갑니다.
# 이 파일은 설명과 실행 코드를 함께 읽는 학습용 Python 파일입니다.
# # 뒤의 내용은 주석입니다. 실행되지 않으며 편집기에 따라 색이 다릅니다.
# 저장: course/concepts/C09_02_normal.py · UTF-8 · .py.txt가 아닌 .py
# 실행: course 폴더의 터미널에서 python -X utf8 concepts/C09_02_normal.py
# 터미널 명령과 예상 출력은 이 파일에 붙여 넣지 않습니다.
# 괄호 ()는 함수에 전달할 값을 묶습니다. 따옴표는 문자열의 범위를 나타냅니다.
# 코드는 위에서 아래로 실행됩니다. 먼저 결과를 예상한 뒤 실행하세요.
# ---------------------------------------------------------------------
score = 95
# 업무상 허용 범위를 먼저 검사합니다.
if score < 0 or score > 100:
    print("점수 범위 오류")
elif score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")
elif score >= 60:
    print("D")
else:
    print("F")
# 59·60·89·90·100·101을 각각 시험합니다.
```

## 직접 작성할 문제

40시간까지 기본 시급, 초과 시간은 시급의 1.5배로 급여를 계산하세요. 39·40·41시간을 시험하세요.

[연습용 파일 받기](examples/course/concepts/C09_starter.py)에서 TODO를 채운 뒤, 위 문제는 새 파일에 직접 작성하세요. `pass`는 아직 아무 일도 하지 않는 임시 문장입니다. `if False:`·`elif False:`·빈 목록을 읽는 for는 직접 작성하기 전의 자리 표시입니다.
