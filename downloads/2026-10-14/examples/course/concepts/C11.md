# C11 · for와 range 반복

[개념 목차로 돌아가기](#/sessions/2026-10-14/lesson)

## 무엇이고 왜 필요한가

반복문은 같은 동작을 여러 값에 수행합니다. for는 자료에서 값을 하나씩 꺼내 반복 변수에 연결합니다.

## 구성요소와 기호

| 구성요소 | 뜻과 사용 방법 |
|---|---|
| `for 변수 in 자료:` | for는 반복 시작, 변수는 이번 값의 이름, in 뒤는 꺼내 읽을 자료입니다. |
| `반복 본문` | 콜론 아래 들여쓴 코드가 매 값마다 실행됩니다. 들여쓰기를 끝내면 반복 밖입니다. |
| `range(start, stop)` | 시작부터 끝 직전까지 정수 순서를 만듭니다. range(1, 4)는 1·2·3입니다. |
| `반복 안 if` | 매번 꺼낸 값에 조건을 적용할 수 있습니다. 들여쓰기 깊이가 하나 늘어납니다. |

## 실행 과정 따라가기

scores의 첫 값 90이 score로 들어가 판단·출력됩니다. 다음 값 25로 같은 동작을 반복합니다. 마지막 값 뒤 반복이 끝납니다.

## 값마다 합격 판정

실행 전에 출력 결과를 예상하세요. 주석을 읽고 각 줄의 역할을 설명해 보세요.

```python
# =====================================================================
# C11 · for와 range 반복 / 예제 1: 값마다 합격 판정
# =====================================================================
# 무엇을 배우나요? 반복문은 같은 동작을 여러 값에 수행합니다. for는 자료에서
# 값을 하나씩 꺼내 반복 변수에 연결합니다.
# 이 파일은 설명과 실행 코드를 함께 읽는 학습용 Python 파일입니다.
# # 뒤의 내용은 주석입니다. 실행되지 않으며 편집기에 따라 색이 다릅니다.
# 저장: course/concepts/C11_01_normal.py · UTF-8
# · .py.txt가 아닌 .py
# 실행: course 폴더의 터미널에서 python -X utf8
# concepts/C11_01_normal.py
# 터미널 명령과 예상 출력은 이 파일에 붙여 넣지 않습니다.
# 괄호 ()는 함수에 전달할 값을 묶습니다. 따옴표는 문자열의 범위를 나타냅니다.
# 코드는 위에서 아래로 실행됩니다. 먼저 결과를 예상한 뒤 실행하세요.
# ---------------------------------------------------------------------
# [구성요소]
# for 변수 in 자료:: for는 반복 시작, 변수는 이번 값의 이름, in
# 뒤는 꺼내 읽을 자료입니다.
# 반복 본문: 콜론 아래 들여쓴 코드가 매 값마다 실행됩니다. 들여쓰기를 끝내면
# 반복 밖입니다.
# range(start, stop): 시작부터 끝 직전까지 정수 순서를 만듭니다.
# range(1, 4)는 1·2·3입니다.
# 반복 안 if: 매번 꺼낸 값에 조건을 적용할 수 있습니다. 들여쓰기 깊이가
# 하나 늘어납니다.
# [실행 과정]
# scores의 첫 값 90이 score로 들어가 판단·출력됩니다. 다음 값
# 25로 같은 동작을 반복합니다. 마지막 값 뒤 반복이 끝납니다.
# [직접 확장할 문제]
# 온도 [22, 30, 28, 19]를 한 값씩 읽어 28 이상이면 주의,
# 나머지는 정상으로 출력하세요.
# ---------------------------------------------------------------------
scores = [90, 25, 67, 45, 80]
for score in scores:
    # score는 리스트 전체가 아니라 이번에 꺼낸 숫자 하나입니다.
    if score >= 60:
        print(score, "합격")
    else:
        print(score, "불합격")
print("판정 끝")            # 들여쓰기가 없으므로 반복 종료 후 한 번 실행합니다.
```
