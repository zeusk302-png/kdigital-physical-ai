# C17 · 입력부터 요약까지 종합하기

[개념 목차로 돌아가기](#/sessions/2026-10-14/lesson)

## 무엇이고 왜 필요한가

문제를 입력·처리·출력으로 나누고 앞에서 배운 개념을 연결합니다. 종료, 잘못된 입력, 빈 자료도 정상 동작에 포함합니다.

## 구성요소와 기호

| 구성요소 | 뜻과 사용 방법 |
|---|---|
| `입력 규칙` | 숫자를 한 줄씩 입력하고 done으로 끝냅니다. 잘못된 숫자는 안내하고 다음 입력을 받습니다. |
| `저장과 처리` | 숫자를 리스트에 모으고 합계·개수·평균·최댓값을 계산합니다. |
| `빈 자료` | 바로 done이면 계산할 값이 없습니다. 평균과 max를 호출하기 전에 확인합니다. |
| `시험` | 정상 입력·잘못된 입력·숫자 0·바로 종료를 각각 시험합니다. 한 예제 출력만 맞는 것으로 끝내지 않습니다. |

## 실행 과정 따라가기

4 → [4], 5 → [4, 5], bad → 변경 없음, 7 → [4, 5, 7], done → 종료. 숫자 개수는 3이고 평균은 5.33입니다.

## 숫자 입력 함수

실행 전에 출력 결과를 예상하세요. 주석을 읽고 각 줄의 역할을 설명해 보세요.

```python
# =====================================================================
# C17 · 입력부터 요약까지 종합하기 / 예제 1: 숫자 입력 함수
# =====================================================================
# 무엇을 배우나요? 문제를 입력·처리·출력으로 나누고 앞에서 배운 개념을 연결합니다. 종료, 잘못된 입력, 빈 자료도 정상 동작에 포함합니다.
# 이 파일은 설명과 실행 코드를 함께 읽는 학습용 Python 파일입니다.
# # 뒤의 내용은 주석입니다. 실행되지 않으며 편집기에 따라 색이 다릅니다.
# 저장: course/concepts/C17_01_normal.py · UTF-8 · .py.txt가 아닌 .py
# 실행: course 폴더의 터미널에서 python -X utf8 concepts/C17_01_normal.py
# 터미널 명령과 예상 출력은 이 파일에 붙여 넣지 않습니다.
# 괄호 ()는 함수에 전달할 값을 묶습니다. 따옴표는 문자열의 범위를 나타냅니다.
# 코드는 위에서 아래로 실행됩니다. 먼저 결과를 예상한 뒤 실행하세요.
# ---------------------------------------------------------------------
def get_int(prompt):
    """정수로 변환 가능한 입력을 받을 때까지 다시 묻습니다."""
    while True:
        raw = input(prompt)
        try:
            number = int(raw)
        except ValueError:
            print("정수로 입력하세요.")
            continue
        return number         # 함수가 끝나므로 while도 함께 끝납니다.

quantity = get_int("수량: ")
print("받은 값:", quantity)
# 이 함수는 음수도 정수로 받습니다. 업무 범위 검사는 호출한 쪽에 추가합니다.
```

## 측정 숫자 요약 프로그램

실행 전에 출력 결과를 예상하세요. 주석을 읽고 각 줄의 역할을 설명해 보세요.

```python
# =====================================================================
# C17 · 입력부터 요약까지 종합하기 / 예제 2: 측정 숫자 요약 프로그램
# =====================================================================
# 무엇을 배우나요? 문제를 입력·처리·출력으로 나누고 앞에서 배운 개념을 연결합니다. 종료, 잘못된 입력, 빈 자료도 정상 동작에 포함합니다.
# 이 파일은 설명과 실행 코드를 함께 읽는 학습용 Python 파일입니다.
# # 뒤의 내용은 주석입니다. 실행되지 않으며 편집기에 따라 색이 다릅니다.
# 저장: course/concepts/C17_02_normal.py · UTF-8 · .py.txt가 아닌 .py
# 실행: course 폴더의 터미널에서 python -X utf8 concepts/C17_02_normal.py
# 터미널 명령과 예상 출력은 이 파일에 붙여 넣지 않습니다.
# 괄호 ()는 함수에 전달할 값을 묶습니다. 따옴표는 문자열의 범위를 나타냅니다.
# 코드는 위에서 아래로 실행됩니다. 먼저 결과를 예상한 뒤 실행하세요.
# ---------------------------------------------------------------------
def average(numbers):
    """숫자 목록의 평균을 반환합니다. 빈 목록은 None을 반환합니다."""
    if len(numbers) == 0:
        return None
    return sum(numbers) / len(numbers)

numbers = []
while True:
    raw = input("숫자(done 종료): ")
    line = raw.strip().lower()
    if line == "done":
        break
    try:
        number = float(line)
    except ValueError:
        print("숫자가 아니라서 건너뜁니다.")
        continue
    numbers.append(number)

if len(numbers) == 0:
    print("입력된 숫자가 없습니다.")
else:
    mean = average(numbers)
    largest = max(numbers)
    print(f"개수 {len(numbers)}개, 평균 {mean:.2f}, 최댓값 {largest}")
# 숫자 0은 정상 입력입니다. 빈 목록과 혼동하지 않습니다.
# 추가 도전: float('nan')처럼 변환되지만 측정값으로 쓰기 어려운 값을 거절하세요.
# 이 예제는 장비 연결 없이 입력과 집계를 배우는 프로그램입니다.
```
