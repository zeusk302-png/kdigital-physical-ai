# C16 · 함수·매개변수·return

[개념 목차로 돌아가기](#/sessions/2026-10-14/lesson)

## 무엇이고 왜 필요한가

함수는 이름을 붙인 처리 절차입니다. 정의만 하면 실행되지 않고 호출할 때 실행됩니다. return은 결과를 호출한 곳에 돌려줍니다.

## 구성요소와 기호

| 구성요소 | 뜻과 사용 방법 |
|---|---|
| `def 이름(매개변수):` | 함수를 정의합니다. 매개변수는 들어올 값에 붙인 이름입니다. |
| `호출` | 함수 이름 뒤 괄호에 실제 값을 넣습니다. f_to_c(72)가 호출입니다. |
| `return` | 함수 실행을 끝내고 값을 돌려줍니다. 호출 결과를 변수에 저장하거나 계산에 사용할 수 있습니다. |
| `print와 return` | print는 화면에 보여 줍니다. 반환하지 않으면 함수의 결과는 None입니다. None은 0과 다릅니다. |

## 실행 과정 따라가기

f_to_c(72) 호출 → f에 72 → 계산 → return으로 22.22… → result에 저장 → 표시합니다.

## 온도 변환 함수

실행 전에 출력 결과를 예상하세요. 주석을 읽고 각 줄의 역할을 설명해 보세요.

```python
# =====================================================================
# C16 · 함수·매개변수·return / 예제 1: 온도 변환 함수
# =====================================================================
# 무엇을 배우나요? 함수는 이름을 붙인 처리 절차입니다. 정의만 하면 실행되지 않고 호출할 때 실행됩니다. return은 결과를 호출한 곳에 돌려줍니다.
# 이 파일은 설명과 실행 코드를 함께 읽는 학습용 Python 파일입니다.
# # 뒤의 내용은 주석입니다. 실행되지 않으며 편집기에 따라 색이 다릅니다.
# 저장: course/concepts/C16_01_normal.py · UTF-8 · .py.txt가 아닌 .py
# 실행: course 폴더의 터미널에서 python -X utf8 concepts/C16_01_normal.py
# 터미널 명령과 예상 출력은 이 파일에 붙여 넣지 않습니다.
# 괄호 ()는 함수에 전달할 값을 묶습니다. 따옴표는 문자열의 범위를 나타냅니다.
# 코드는 위에서 아래로 실행됩니다. 먼저 결과를 예상한 뒤 실행하세요.
# ---------------------------------------------------------------------
def f_to_c(f):
    """화씨 숫자를 받아 섭씨 숫자를 돌려줍니다."""
    # 첫 문자열은 함수 설명인 docstring입니다.
    return (f - 32) * 5 / 9

result = f_to_c(72)
print(f"변환 결과: {result:.1f}")
print(f"어는점: {f_to_c(32):.1f}")
# 같은 처리 절차를 값만 바꿔 여러 번 사용합니다.
```

## 출력과 반환 비교

실행 전에 출력 결과를 예상하세요. 주석을 읽고 각 줄의 역할을 설명해 보세요.

```python
# =====================================================================
# C16 · 함수·매개변수·return / 예제 2: 출력과 반환 비교
# =====================================================================
# 무엇을 배우나요? 함수는 이름을 붙인 처리 절차입니다. 정의만 하면 실행되지 않고 호출할 때 실행됩니다. return은 결과를 호출한 곳에 돌려줍니다.
# 이 파일은 설명과 실행 코드를 함께 읽는 학습용 Python 파일입니다.
# # 뒤의 내용은 주석입니다. 실행되지 않으며 편집기에 따라 색이 다릅니다.
# 저장: course/concepts/C16_02_normal.py · UTF-8 · .py.txt가 아닌 .py
# 실행: course 폴더의 터미널에서 python -X utf8 concepts/C16_02_normal.py
# 터미널 명령과 예상 출력은 이 파일에 붙여 넣지 않습니다.
# 괄호 ()는 함수에 전달할 값을 묶습니다. 따옴표는 문자열의 범위를 나타냅니다.
# 코드는 위에서 아래로 실행됩니다. 먼저 결과를 예상한 뒤 실행하세요.
# ---------------------------------------------------------------------
def show_double(number):
    # 화면에 출력하지만 호출한 곳으로 숫자를 돌려주지는 않습니다.
    print(number * 2)

def calculate_double(number):
    # 숫자를 반환합니다. 화면 출력은 호출한 쪽에서 정합니다.
    return number * 2

shown = show_double(3)
calculated = calculate_double(3)
print("출력 함수 결과:", shown)
print("반환 함수 결과:", calculated)
print("반환값에 1 더하기:", calculated + 1)
```
