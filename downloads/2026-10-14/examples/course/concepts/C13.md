# C13 · 딕셔너리와 이름으로 찾기

[개념 목차로 돌아가기](#/sessions/2026-10-14/lesson)

## 무엇이고 왜 필요한가

리스트가 위치로 값을 찾는다면 딕셔너리는 키라는 이름표로 값을 찾습니다. 상품 이름과 가격처럼 짝을 저장합니다.

## 구성요소와 기호

| 구성요소 | 뜻과 사용 방법 |
|---|---|
| `{키: 값}` | 키와 값 사이에 콜론, 여러 쌍 사이에 쉼표를 씁니다. 같은 키는 중복 저장되지 않습니다. |
| `menu[item]` | item에 든 키의 값을 읽습니다. 없는 키를 직접 읽으면 KeyError입니다. |
| `get(key, default)` | 키가 없으면 기본값을 돌려줍니다. 재고 0과 미등록을 구별할 때는 None 기본값을 씁니다. |
| `items()` | 키와 값을 한 쌍씩 순회합니다. for name, price in menu.items()처럼 두 이름으로 받습니다. |

## 실행 과정 따라가기

counts.get("볼트", 0)은 처음에는 0입니다. 1을 더해 저장하면 다음 볼트에서 1을 읽고 2를 저장합니다.

## 메뉴 가격표와 주문 합계

실행 전에 출력 결과를 예상하세요. 주석을 읽고 각 줄의 역할을 설명해 보세요.

```python
# =====================================================================
# C13 · 딕셔너리와 이름으로 찾기 / 예제 1: 메뉴 가격표와 주문 합계
# =====================================================================
# 무엇을 배우나요? 리스트가 위치로 값을 찾는다면 딕셔너리는 키라는 이름표로 값을 찾습니다. 상품 이름과 가격처럼 짝을 저장합니다.
# 이 파일은 설명과 실행 코드를 함께 읽는 학습용 Python 파일입니다.
# # 뒤의 내용은 주석입니다. 실행되지 않으며 편집기에 따라 색이 다릅니다.
# 저장: course/concepts/C13_01_normal.py · UTF-8 · .py.txt가 아닌 .py
# 실행: course 폴더의 터미널에서 python -X utf8 concepts/C13_01_normal.py
# 터미널 명령과 예상 출력은 이 파일에 붙여 넣지 않습니다.
# 괄호 ()는 함수에 전달할 값을 묶습니다. 따옴표는 문자열의 범위를 나타냅니다.
# 코드는 위에서 아래로 실행됩니다. 먼저 결과를 예상한 뒤 실행하세요.
# ---------------------------------------------------------------------
menu = {"커피": 3000, "차": 2500}
menu["물"] = 1000       # 새 키와 값을 추가합니다.
menu["차"] = 2000       # 이미 있는 키의 값을 바꿉니다.
orders = ["커피", "차", "커피"]
total = 0
for item in orders:
    total = total + menu[item]
print("주문 합계:", total)
print("미등록:", menu.get("주스", None))
```

## 품목별 개수

실행 전에 출력 결과를 예상하세요. 주석을 읽고 각 줄의 역할을 설명해 보세요.

```python
# =====================================================================
# C13 · 딕셔너리와 이름으로 찾기 / 예제 2: 품목별 개수
# =====================================================================
# 무엇을 배우나요? 리스트가 위치로 값을 찾는다면 딕셔너리는 키라는 이름표로 값을 찾습니다. 상품 이름과 가격처럼 짝을 저장합니다.
# 이 파일은 설명과 실행 코드를 함께 읽는 학습용 Python 파일입니다.
# # 뒤의 내용은 주석입니다. 실행되지 않으며 편집기에 따라 색이 다릅니다.
# 저장: course/concepts/C13_02_normal.py · UTF-8 · .py.txt가 아닌 .py
# 실행: course 폴더의 터미널에서 python -X utf8 concepts/C13_02_normal.py
# 터미널 명령과 예상 출력은 이 파일에 붙여 넣지 않습니다.
# 괄호 ()는 함수에 전달할 값을 묶습니다. 따옴표는 문자열의 범위를 나타냅니다.
# 코드는 위에서 아래로 실행됩니다. 먼저 결과를 예상한 뒤 실행하세요.
# ---------------------------------------------------------------------
items = ["볼트", "너트", "볼트", "볼트"]
counts = {}
for item in items:
    previous = counts.get(item, 0)
    counts[item] = previous + 1
# 출력 순서는 이 예제에서 키가 처음 추가된 순서입니다.
for name, count in counts.items():
    print(name, count)
```

```text

너트 1
```
