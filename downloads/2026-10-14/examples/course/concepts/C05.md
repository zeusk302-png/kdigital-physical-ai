# C05 · 문자열과 출력 형식

[개념 목차로 돌아가기](#/sessions/2026-10-14/lesson)

## 무엇이고 왜 필요한가

문자열은 글자를 순서대로 모은 값입니다. 일부 글자를 꺼내거나 여러 문자열을 연결하고 값이 들어간 안내문을 만들 수 있습니다.

## 구성요소와 기호

| 구성요소 | 뜻과 사용 방법 |
|---|---|
| `len(text)` | 문자열의 길이를 셉니다. 이 예제의 한글도 글자별 위치를 확인할 수 있습니다. |
| `text[0]` | 첫 글자를 읽습니다. 위치 번호는 0부터 시작합니다. 없는 위치를 읽으면 IndexError입니다. |
| `text[0:2]` | 0번부터 2번 직전까지 읽습니다. 슬라이스의 끝 위치는 포함하지 않습니다. |
| `f"...{value}"` | 앞의 f와 중괄호 안 변수로 값을 문자열에 넣습니다. :.1f는 소수 한 자리 표시입니다. |

## 실행 과정 따라가기

"S01"의 위치는 0:S, 1:0, 2:1입니다. 길이는 3이고 [0:2]는 "S0"입니다.

## 길이와 위치

실행 전에 출력 결과를 예상하세요. 주석을 읽고 각 줄의 역할을 설명해 보세요.

```python
# =====================================================================
# C05 · 문자열과 출력 형식 / 예제 1: 길이와 위치
# =====================================================================
# 무엇을 배우나요? 문자열은 글자를 순서대로 모은 값입니다. 일부 글자를 꺼내거나 여러 문자열을 연결하고 값이 들어간 안내문을 만들 수 있습니다.
# 이 파일은 설명과 실행 코드를 함께 읽는 학습용 Python 파일입니다.
# # 뒤의 내용은 주석입니다. 실행되지 않으며 편집기에 따라 색이 다릅니다.
# 저장: course/concepts/C05_01_normal.py · UTF-8 · .py.txt가 아닌 .py
# 실행: course 폴더의 터미널에서 python -X utf8 concepts/C05_01_normal.py
# 터미널 명령과 예상 출력은 이 파일에 붙여 넣지 않습니다.
# 괄호 ()는 함수에 전달할 값을 묶습니다. 따옴표는 문자열의 범위를 나타냅니다.
# 코드는 위에서 아래로 실행됩니다. 먼저 결과를 예상한 뒤 실행하세요.
# ---------------------------------------------------------------------
sensor = "S01"
print("길이:", len(sensor))
print("첫 글자:", sensor[0])
print("앞 두 글자:", sensor[0:2])
# 문자열 +는 두 글자를 이어 붙입니다.
print("장치-" + sensor)
```

## 값을 넣은 안내문

실행 전에 출력 결과를 예상하세요. 주석을 읽고 각 줄의 역할을 설명해 보세요.

```python
# =====================================================================
# C05 · 문자열과 출력 형식 / 예제 2: 값을 넣은 안내문
# =====================================================================
# 무엇을 배우나요? 문자열은 글자를 순서대로 모은 값입니다. 일부 글자를 꺼내거나 여러 문자열을 연결하고 값이 들어간 안내문을 만들 수 있습니다.
# 이 파일은 설명과 실행 코드를 함께 읽는 학습용 Python 파일입니다.
# # 뒤의 내용은 주석입니다. 실행되지 않으며 편집기에 따라 색이 다릅니다.
# 저장: course/concepts/C05_02_normal.py · UTF-8 · .py.txt가 아닌 .py
# 실행: course 폴더의 터미널에서 python -X utf8 concepts/C05_02_normal.py
# 터미널 명령과 예상 출력은 이 파일에 붙여 넣지 않습니다.
# 괄호 ()는 함수에 전달할 값을 묶습니다. 따옴표는 문자열의 범위를 나타냅니다.
# 코드는 위에서 아래로 실행됩니다. 먼저 결과를 예상한 뒤 실행하세요.
# ---------------------------------------------------------------------
name = "홍길동"
quantity = 3
price = 2000
total = quantity * price
# 중괄호 안 표현식을 계산해 문자열에 넣습니다.
print(f"{name}님, {quantity}개 주문 금액은 {total}원입니다.")
temperature = 22.222222
print(f"온도: {temperature:.1f}도")
# 자리수 표시는 출력 형식입니다. 원래 temperature 값 자체는 바꾸지 않습니다.
```
