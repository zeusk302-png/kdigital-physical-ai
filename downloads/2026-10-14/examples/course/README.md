# Python 기초 · 값과 실행 흐름

2026-10-14 · Python 기초

10/8에 읽었던 온도와 식별자를 Python 값으로 옮깁니다. 파일 저장과 실행을 구별하고 변수·자료형·연산·조건·반복을 짧은 코드에서 확인한 뒤 수업용 점검표를 완성합니다.

**360분 상세 운영을 위한 제작 배정이며 실제 학습자 리허설 전입니다.** 원본을 보존하고 work의 지정한 부분을 수정합니다. 계정이나 실제 장비 없이 합성 자료로 진행합니다.

## 폴더

- data: 활동별 실제 입력과 오류 비교 카드
- code: 완성 시연 코드
- work: 직접 수정·작성하는 사본과 답칸

[18활동 안내](activity-guide.md)와 [모든 줄 해설](code/line-guide.md), [평가 기준](assessment.md)을 사용합니다.

실행은 course 폴더에서 안내 명령을 사용합니다. 코드 폴더와 현재 위치를 구별하고 수정본의 경로가 work인지 확인합니다. 자료를 원본과 작업본으로 나누는 것은 변경 근거를 남기기 위해서입니다. 유료 서비스·계정·실제 장비는 필요하지 않습니다.

Python 실행이 준비되지 않았다면 코드와 출력 예를 직접 추적하고 개인 실행 여부를 별도로 적습니다. 자료 검증과 실제 수업 리허설은 다릅니다.


## Windows · 처음 실행할 위치 만들기

제작 가정: Windows 탐색기와 PowerShell을 사용합니다. 다른 OS는 강사의 해당 환경 안내를 따릅니다. 설치 문제는 개념 평가와 따로 기록합니다.

1. 예제 ZIP을 우클릭 → **모두 추출** → **추출**합니다. ZIP 안을 보는 창에서 실행하지 않습니다.
2. 탐색기로 압축을 푼 곳의 `course` 폴더를 엽니다. 안에 `data`, `code`, `work` 세 폴더가 실제로 보이는지 확인합니다. 폴더가 한 겹 더 있으면 그 안으로 들어갑니다.
3. 탐색기 위 주소 표시줄을 클릭해 `powershell`을 입력하고 Enter를 누릅니다. 현재 폴더에서 PowerShell 창이 열립니다. 편집기에서 파일을 연 것만으로 실행 위치가 정해지지는 않습니다.
4. 아래 명령을 한 줄씩 입력하고 Enter를 누릅니다. 앞의 `PS ...>` 문구는 입력하지 않습니다.

```powershell
Get-Location
Get-ChildItem -Directory
Test-Path .\work\A02_print.py
```

`Get-Location`은 지금 실행할 폴더의 실제 경로를 보여 줍니다. 끝이 `course`인지 확인합니다. `Get-ChildItem` 목록에는 `data`, `code`, `work`가 보여야 합니다. 마지막 명령은 파일이 있는지 확인하며 정상 결과는 `True`입니다. 내 실제 경로: _____ / 확인 결과: _____.

5. `work/A02_print.py` 첫 print 문구를 `오늘의 점검 시작`으로 고치고 저장합니다. 같은 PowerShell 창에서 실행합니다.

```powershell
python -X utf8 work/A02_print.py
```

예상 두 줄은 다음과 같습니다.

```text
오늘의 점검 시작
S01 22.5
```

- `False`, `can't open file`, `No such file`: 실제 폴더를 탐색기로 다시 열고 2~4단계를 반복합니다. 파일 이름이 `.py.txt`가 아닌지 탐색기의 **보기 → 표시 → 파일 확장명**에서 확인합니다.
- 첫 줄이 `Python 점검 시작`: 수정 파일을 저장했는지, 실행 명령이 `code/`가 아닌 `work/`를 가리키는지 확인합니다.
- `python`을 찾지 못하거나 Store 안내가 뜸: 강사에게 설치 상태를 확인받습니다. 설치를 혼자 진행하지 말고 예상·제공 출력 비교로 합류하고 **개인 실행 미완료**를 적습니다.

실행 위치 확인 → 파일 저장 → 명령 입력 → 실제 출력 기록을 서로 다른 행동으로 확인합니다.
