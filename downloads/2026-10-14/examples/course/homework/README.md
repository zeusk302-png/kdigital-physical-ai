# Python 기초 · 제출 과제 3개

단원 실습과 별도로 제출하는 과제입니다. HW01 → HW02 → HW03 순서로 계산·조건 집계·순서에 따른 상태 변화를 연습합니다. 초등부 정보올림피아드 입문을 향한 준비 문제이며 공식 기출의 난도 전체와 같다고 보지는 않습니다. 세 문제 모두 이 수업을 위해 작성한 창작 문제입니다.

## 파일 이름과 제출

파일 이름은 `김철수_HW01.py`처럼 **수강생이름_과제번호.py**로 저장합니다. 학생 로그인은 사용하지 않습니다. 과제마다 파일 하나씩 올립니다. 같은 과제를 다시 올리면 이전 제출과 함께 기록합니다. 파일명에 적힌 이름을 제출자로 기록하며 신원 확인을 대신하지는 않습니다.

입력 안내 문구나 풀이 설명을 출력하지 않고 문제의 출력만 표시하세요. 풀이 설명은 코드의 주석으로 적습니다. `input()`에 안내 문구를 넣으면 채점용 출력과 달라집니다.

## HW01 · 타이머 표시

**배운 개념:** 입력·형변환·몫·나머지

전체 초를 시·분·초로 나누세요. 분과 초는 각각 0~59 범위로 표시합니다.

**입력:** 정수 S 하나가 주어집니다. 0 ≤ S ≤ 1000000.

**출력:** 시 분 초를 공백 하나로 구분해 한 줄 출력합니다.

예시 입력:

```text
3671
```

예시 출력:

```text
1 1 11
```

[답안 작성 파일](HW01.py)을 받아 파일명을 자신의 이름으로 바꾸세요.

## HW02 · 측정값 집계

**배운 개념:** 반복·조건·누적

여러 측정값에서 기준 이상인 값의 개수와 전체 측정값의 합을 구하세요. 기준 이상 합계가 아니라 모든 값의 합계입니다.

**입력:** 첫 줄 N(0 이상 1000 이하), 둘째 줄 기준 T(-1000 이상 1000 이하), 다음 N줄에 정수 측정값(-1000 이상 1000 이하)이 하나씩 주어집니다.

**출력:** 기준 이상 개수와 전체 합계를 공백 하나로 구분해 출력합니다.

예시 입력:

```text
4
28
22
30
28
19
```

예시 출력:

```text
2 99
```

[답안 작성 파일](HW02.py)을 받아 파일명을 자신의 이름으로 바꾸세요.

## HW03 · 상자에 순서대로 담기

**배운 개념:** 반복·조건·상태 변화

물건을 주어진 순서대로 상자에 담습니다. 현재 상자 용량을 넘으면 그 상자를 닫고 새 상자에 현재 물건을 넣습니다. 물건 순서를 바꾸거나 물건을 나눌 수 없습니다. 필요한 상자 수를 구하세요.

**입력:** 첫 줄 상자 용량 C(1 이상 10000 이하), 둘째 줄 물건 수 N(0 이상 1000 이하), 다음 N줄에 무게 W(1 이상 C 이하)가 하나씩 주어집니다.

**출력:** 사용한 상자 수를 출력합니다. 물건이 없으면 0입니다.

예시 입력:

```text
6
5
2
4
3
3
1
```

예시 출력:

```text
3
```

예시 흐름: 첫 상자 2+4, 둘째 상자 3+3, 셋째 상자 1입니다. 용량을 정확히 채우는 것은 허용됩니다.

[답안 작성 파일](HW03.py)을 받아 파일명을 자신의 이름으로 바꾸세요.
