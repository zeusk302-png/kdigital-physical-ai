# Python 기초 · 제출 과제 3개

단원 실습과 별도로 제출하는 과제입니다. 트리 출력 → 좌석 예약 → 측정값 분석 순서로 배운 문법을 조합해 프로그램을 직접 만듭니다. 공식 정보올림피아드 기출은 아닙니다. 세 문제 모두 이 수업을 위해 작성한 창작 문제입니다.

## 파일 이름과 제출

파일 이름은 `김철수_HW01.py`처럼 **수강생이름_과제번호.py**로 저장합니다. 학생 로그인은 사용하지 않습니다. 과제마다 파일 하나씩 올립니다. 같은 과제를 다시 올리면 이전 제출과 함께 기록합니다. 파일명에 적힌 이름을 제출자로 기록하며 신원 확인을 대신하지는 않습니다.

입력 안내 문구나 풀이 설명을 출력하지 않고 문제의 출력만 표시하세요. 풀이 설명은 코드의 주석으로 적습니다. `input()`에 안내 문구를 넣으면 채점용 출력과 달라집니다.

## HW01 · 별표로 크리스마스트리 만들기

**배운 개념:** 입력·조건·반복·문자열·예외·함수

높이에 맞춰 가운데 정렬된 트리와 기둥을 만드세요. 모양을 고정 문자열로 미리 적지 말고 반복문으로 공백과 별 개수를 계산하세요. 높이 입력 함수와 출력 함수를 나누고, 공백과 별 개수를 계산한 이유를 주석으로 설명하세요.

**입력:** 정수 높이 H를 한 줄에 입력합니다. 3~15만 허용합니다. 글자·소수·범위 밖 정수는 높이 오류를 출력한 뒤 다시 입력받습니다.

**출력:** 잘못된 입력마다 높이 오류를 출력합니다. 정상 높이면 잎 H줄과 기둥 1줄을 출력하고 종료합니다. 잎은 위에서부터 별 1, 3, 5, …, 2H-1개입니다. 기둥은 | 하나입니다. 왼쪽 공백으로 가운데를 맞추며 오른쪽 공백과 빈 줄은 출력하지 않습니다.

**필수 구현:**

- 높이 입력 함수와 트리 출력 함수를 작성한다.
- 공백과 별 개수를 반복문에서 계산한다.
- 잘못된 높이를 다시 입력받는다.

예시 입력:

```text
4
```

예시 출력:

```text
   *
  ***
 *****
*******
   |
```

예시 입력:

```text
abc
2
3
```

예시 출력:

```text
높이 오류
높이 오류
  *
 ***
*****
  |
```

**더 해보기:** 잎에 사용할 문자와 기둥 높이를 입력받아 보세요. 확장은 필수 채점에 포함하지 않습니다. 확장은 필수 점수를 대신하지 않습니다.

## HW02 · 좌석 예약 프로그램

**배운 개념:** 리스트·인덱스·조건·반복·함수·상태 관리

좌석 5개를 가진 예약 프로그램을 만드세요. 처음에는 모두 빈 좌석입니다. 예약·취소 결과는 다음 명령에서도 유지됩니다. 현황 표시·예약·취소 중 최소 두 동작을 함수로 나누세요. 사람의 좌석 번호와 리스트 위치가 어떻게 다른지 주석으로 설명하세요.

**입력:** 명령을 한 줄씩 입력합니다. 1: 현황 보기, 2: 예약, 3: 취소, 0: 종료입니다. 2와 3 다음 줄에는 좌석 번호 1~5를 입력합니다. 잘못된 명령은 메뉴 오류, 잘못된 번호는 좌석 오류를 출력하고 다음 명령을 받습니다.

**출력:** 현황은 빈 좌석 O, 예약 좌석 X로 표시하고 1:O 2:O 3:O 4:O 5:O 형식으로 출력합니다. 예약 성공은 예약 완료, 중복 예약은 이미 예약, 취소 성공은 취소 완료, 빈 좌석 취소는 빈 좌석을 출력합니다. 0이면 종료를 출력합니다. 오류 시 상태를 바꾸지 않습니다.

**필수 구현:**

- 리스트에 좌석 상태를 저장한다.
- 현황·예약·취소 중 최소 두 동작을 함수로 분리한다.
- 중복 예약·빈 좌석 취소·잘못된 번호를 처리한다.

예시 입력:

```text
1
2
3
2
3
1
3
3
0
```

예시 출력:

```text
1:O 2:O 3:O 4:O 5:O
예약 완료
이미 예약
1:O 2:O 3:X 4:O 5:O
취소 완료
종료
```

예시 입력:

```text
2
6
3
1
x
0
```

예시 출력:

```text
좌석 오류
빈 좌석
메뉴 오류
종료
```

**더 해보기:** 남은 좌석 수를 표시하고 두 좌석을 함께 예약해 보세요. 하나라도 이미 예약되어 있으면 두 좌석 모두 변경하지 않게 해 보세요. 확장은 필수 점수를 대신하지 않습니다.

## HW03 · 측정값 분석 프로그램

**배운 개념:** 리스트·반복·예외·누적·함수·경계값

측정값을 반복 입력받아 목록에 저장하고 개수·합계·평균·최댓값·최솟값·기준 초과 개수를 출력하세요. 기준 입력·측정값 수집·요약을 함수로 분리하세요. 합계와 초과 개수 중 하나 이상은 반복문으로 직접 계산하세요. 빈 목록은 따로 처리하세요.

**입력:** 첫 줄에 정수 기준을 입력합니다. 잘못되면 기준 오류를 출력하고 다시 묻습니다. 다음 줄부터 정수 측정값을 입력하고 done으로 끝냅니다. 명령의 공백과 대소문자는 무시합니다. 잘못된 값은 입력 오류를 출력하고 저장하지 않습니다. 기준과 측정값은 -1000~1000만 허용합니다.

**출력:** 값이 없으면 측정값 없음만 출력합니다. 값이 있으면 개수 N, 합계 S, 평균 A, 최댓값 M, 최솟값 m, 기준 초과 K를 각각 한 줄 출력합니다. 평균은 소수점 둘째 자리까지 표시합니다. 기준과 같은 값은 초과에 포함하지 않습니다.

**필수 구현:**

- 입력·수집·요약 함수를 작성한다.
- 값을 리스트에 저장하고 잘못된 입력을 제외한다.
- 빈 목록·음수·중복·기준과 같은 값을 처리한다.

예시 입력:

```text
5
4
5
bad
7
done
```

예시 출력:

```text
입력 오류
개수 3
합계 16
평균 5.33
최댓값 7
최솟값 4
기준 초과 1
```

예시 입력:

```text
0
done
```

예시 출력:

```text
측정값 없음
```

**더 해보기:** 정렬한 목록에서 중앙값을 구하세요. 개수가 짝수면 가운데 두 값의 평균을 사용합니다. 확장은 필수 점수를 대신하지 않습니다.
