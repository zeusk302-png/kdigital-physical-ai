# Python 기초 · 복사해서 실행하고 오류 고치기

오늘 할 일의 필수 활동부터 진행하세요. 나머지는 함께 보는 예 또는 추가 연습입니다. **오류 코드가 실패하는 것은 이 연습의 정상 과정입니다.**

## 먼저 준비하세요

1. 내 작업 폴더 안에 `work` 폴더를 만듭니다. 폴더는 파일을 모아 두는 곳이고, `.py`는 Python 코드 파일의 이름 끝부분입니다.
2. 편집기에서 새 파일을 열어 정상 코드 상자의 **복사**를 누르고 붙여넣습니다. `work/A02_normal.py`처럼 아래에 적힌 이름으로 UTF-8 저장합니다. `.py.txt`가 아닌지 확인합니다.
3. work의 상위 폴더에서 터미널을 엽니다. 터미널은 실행 명령과 결과를 보는 창입니다. 아래 명령을 입력하고 Enter를 누릅니다. 코드와 실행 명령은 서로 다른 곳에 입력합니다.
4. 웹의 코드 상자는 실행기가 아닙니다. 정상 코드와 오류 코드는 각각 별도 파일에 저장하세요. Python을 찾지 못하면 강사에게 환경 확인을 요청하세요.

```text
python --version
```

버전 확인은 환경 준비입니다. 문법 오류를 고치는 학습과 따로 확인합니다. 오류 내용은 Python 버전에 따라 조금 다를 수 있으므로 아래의 오류 종류와 파일·줄 번호를 먼저 확인하세요.


## A01 · 코드는 위에서 아래로 실행됩니다

**목적:** 정상 결과와 잘못된 결과를 비교하고, 무엇을 고쳤는지 자기 말로 설명합니다.

### 1. 정상 코드를 복사하고 실행하세요

저장할 파일: `work/A01_normal.py`. 아래 Python 코드만 편집기에 붙여넣습니다.

```python
print("입고")
print("검사")
print("출고")
```

| 줄 | 읽는 방법 |
| --- | --- |
| 1 | 괄호 안의 값을 화면에 표시합니다. 따옴표는 글자, 따옴표 없는 이름은 그 이름의 현재 값입니다. |
| 2 | 괄호 안의 값을 화면에 표시합니다. 따옴표는 글자, 따옴표 없는 이름은 그 이름의 현재 값입니다. |
| 3 | 괄호 안의 값을 화면에 표시합니다. 따옴표는 글자, 따옴표 없는 이름은 그 이름의 현재 값입니다. |

터미널에서 실행합니다.

```text
python -X utf8 work/A01_normal.py
```

예상 출력:

```text
입고
검사
출고
```

### 2. 오류 코드를 다른 파일에 저장하세요

저장할 파일: `work/A01_broken.py`. 실행하기 전에 정상 코드와 달라진 줄을 찾아 표시하세요.

```python
print("출고")
print("입고")
print("검사")
```

```text
python -X utf8 work/A01_broken.py
```

실행은 끝나지만 결과가 틀립니다. 예상과 비교할 실제 출력:

```text
출고
입고
검사
```

### 3. 원인을 찾고 직접 고치세요

1. 실제 출력 또는 오류 마지막 줄을 그대로 적습니다.
2. 오류가 가리킨 줄과 앞줄을 정상 코드와 비교합니다.
3. 잘못된 기호·이름·순서를 먼저 짚고, 오류 파일을 `work/A01_fixed.py`로 따로 저장합니다.
4. 필요한 부분을 직접 고쳐 저장한 뒤 다시 실행합니다. 정상 예상 출력과 같아야 합니다.

```text
python -X utf8 work/A01_fixed.py
```

**내 기록:** 예상 _____ / 실제 _____ / 고친 줄 _____ / 고친 이유 _____.
