# Python 기초 쉬운 용어

| 용어 | 뜻 |
| --- | --- |
| 코드 | 컴퓨터가 할 일을 정해진 문법으로 적은 내용 |
| 실행 | 저장한 코드의 명령을 컴퓨터가 수행하는 과정 |
| 변수 | 프로그램 안에서 값에 붙인 이름 |
| 문자열 | 글자의 순서를 값으로 다루는 자료형 |
| 조건문 | 참·거짓 결과에 따라 실행할 부분을 선택하는 문장 |
| 반복문 | 묶음의 항목마다 같은 부분을 실행하는 문장 |
| 들여쓰기 | 같은 작업 안에 속한 줄을 공백으로 묶는 표기 |
| None | 현재 값이 없음을 나타내는 Python 값 |

용어 이름만 외우기보다 활동의 값·파일·출력에서 무엇을 가리키는지 짚습니다. 같은 숫자 모양이라도 의미와 저장 자료형을 구별합니다.
