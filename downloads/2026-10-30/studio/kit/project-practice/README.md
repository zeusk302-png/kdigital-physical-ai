# 프로젝트 실무 자료 사용하기

index.html은 한 페이지 전체 해설입니다. 브라우저에서 열고 목차로 이동하거나 Ctrl+F로 찾습니다. 로그인 없이 오프라인에서도 본문을 읽을 수 있습니다. PROJECT-HANDBOOK.md는 같은 내용의 글 파일입니다.

project-artifacts.zip에는 templates의22개 양식과 examples의22개 작성 예가 있습니다. 하나의 예시 프로젝트가 요구·설계·작업·시험·인계로 이어집니다. 모든 실제 시험의 상태는 NOT_RUN이며 실제 고객·승인·성능·실물 결과가 아닙니다.

ZIP을 모두 푼 뒤 templates의 필요한 .md 파일을 새 작업 폴더에 복사합니다. .md는 텍스트 문서이므로 VS Code·메모장 등에서 열고 [작성]을 자신의 내용으로 바꿉니다. 처음에는 여덟 묶음으로 시작하고 필요에 따라 분리합니다.22개 전체가 개인 수업의 필수 제출물은 아닙니다.

표준은 공식 공개 설명을 근거로 범위와 개념을 소개합니다. 유료 표준 본문 전체의 번역·조항별 심사·인증 자료가 아닙니다. 회사·계약·산업의 실제 요구가 있으면 적용 범위를 별도로 확인합니다.
