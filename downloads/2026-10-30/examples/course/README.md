# 프로젝트 기획 예제

개인 또는 팀 역할로 같은 활동을 수행할 수 있습니다. 팀원 수가 정해지지 않았으므로 역할은 이름 대신 기능으로 적습니다. 코드 비교는 Python3만 필요하며 실제 제품 구현이나 계정 개설은 하지 않습니다.

[활동 전체 안내](activity-guide.md) · [모든 코드와 줄 해설](code/line-guide.md)

data는 원문, work는 학생 기록·수정본, code는 완성 시연 파일입니다. 폴더 구조를 유지합니다. 입력 파일을 덮어쓰지 않고 활동지의 work 파일에 결과를 남깁니다.

계산은 손으로 하고 화면은 종이에 그려도 됩니다. 데이터·기대값·미확인을 같은 양식에 남기면 기본 목표를 달성할 수 있습니다.
